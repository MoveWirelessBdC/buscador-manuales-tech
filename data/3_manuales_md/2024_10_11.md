# Release Version: 24.10.11\_\_stable\_\_0.131.0

### Release Date: 11/10/2024

## Updates

### Feature Updates

* We have updated integration with Square payment method. Now, the prepopulated data (email and phone number) collected in the Flow is passed to the Square payment gateway.

### System Updates

* We have enhanced alerting and monitoring to ensure up-to-date system visibility.
* We have updated Docker build tools for improved consistency and performance.
