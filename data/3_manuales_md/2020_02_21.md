# Release Version: 20.02.21\_\_stable\_\_0.10.0

### Release Date: 02/21/2020

## New Features

* We have added the following permissions:

| Permission Name | Description |
| --- | --- |
| setAccessibleNetworkFlowTokenGroup | Allows a user to set up an Accessible Network in a Token Group |
| setValidityTimeFlowTokenGroup | Allows a user to set up Network Parameters in a Token Group |
| ruckusCustomSip | Allows a user to set up and preview the Ruckus Custom SIP. |
| ruckusCustomSipMap | Allows a user to set up and preview the Ruckus Custom SIP Map |

## Updates

* We have added the **Access Limits** step in the Token group Creator which enables you to select the Network which can be accessed via Tokens, and specify the validity period of Tokens.
* We have expanded the **Participation Rates** and **Devices per Type** tables in the WiFi Users statistics by the additional columns; their display can be adjusted in the table options.

## Bug Fixes

* We have fixed sorting issues in the **Participation Rates** and **Devices per Type** tables in the WiFi Users statistics.
* The calculation of data displayed in the **Average User Count per Hour** table in the WiFi Users statistics has been improved, and the table now shows data as expected.
* We have also resolved problems with data display in the **WiFi Users** table in the *Raw Data*\* statistics.
