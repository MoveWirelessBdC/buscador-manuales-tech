# Release Version: 24.07.19\_\_stable\_\_0.125.0

### Release Date: 19/07/2024

## New Features

* We have added a new payment method for the login via Payment plans - **Stripe** payment gateway.
  For the proper operation of the Stripe payment gateway, the following properties must be set in the organisation:

| Property name | Description |
| --- | --- |
| stripeEnableIntegration | Enables the option of Stripe payment in the Payment Method component. |
| stripeApiKey | Defines the API key for the Stripe gateway. |

## Updates

### System Updates

* We have improved security and stability when operating with Access Points that do not support the secure passing of temporary RADIUS credentials. Now, temporary IDs are used in session processing when downgrading from HTTPS communication. This required adding a new cookie and session storage key, "downgradedId," in addition to the existing "flowSessionId."
* We have introduced default values `[a-zA-Z0-9]{4}` for Organisation properties - emailVerificationCodeRegex and phoneVerificationCodeRegex, which reflect their previous behaviour when not set.
* We have changed Grandstream integration by disable validation for AP MAC param.
  Also fixed reading parameters for Grandstream.

## Resolved Issues

### System Fixes

* We have fixed a slow leak that occurred in the dashboard statistics computation. Previously, this issue could have led to increased internal communication load due to the lack of cleanup of unused organisation data and after changes in timezones.
* We have added detection of HSTS on the parent domain. Instead of causing an infinite loop, a warning will be displayed to the user, but the login process may proceed.
