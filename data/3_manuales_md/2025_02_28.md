# Release Version: 25.02.28\_\_stable\_\_0.141.0

### Release Date: 28/02/2025

## New Features

* We have introduced an improved Advert management feature extending Collect media statistics. This feature adds a new Ad element, which can be applied to multiple Portals and offers dedicated management views and statistics.
  For more information, please visit our What’s New February 2025 Update: ["Introducing Advanced Ads Campaigns"](../../whats_new/2025/02.html).

## Updates

### Feature Updates

* We have updated integrations for Social Media login, including improvements in the alignment of components with their branding guidelines.

### System Updates

* We have updated the libraries that had newly reported security issues, though our platform was not vulnerable to them.

## Resolved Issues

### Feature Fixes

* We have fixed the handling of the TunaiPay payment callback.

### GUI Fixes

* We have fixed an issue where rapidly clicking the "Next" button in multi-step editors could cause undefined behaviour. The navigation logic now correctly handles fast consecutive clicks, ensuring a smooth and predictable transition between steps.

### System Fixes

* We have improved how the UAM shared secret is managed for devices. The platform now supports configuring it per organisation.
