# Release Version: 24.04.26\_\_stable\_\_0.119.0

### Release Date: 26/04/2024

## New Features

* We have introduced a new login option using **OpenID**
* We have added a new payment method for the login via Payment plans - **TunaiPay** payment gateway.   
  For the proper operation of the TunaiPay payment gateway, the following properties must be set in the organisation:

  | Property name | Description |
  | --- | --- |
  | tunaiPayEnableIntegration | Enables the option of TunaiPay payment in the Payment Method component. |
  | tunaiPayApiHost | Defines the url for the TunaiPay gateway. |
  | tunaiPayApiUser | Defines the api user for the TunaiPay gateway. |
  | tunaiPayApiKey | Defines the api key for the TunaiPay gateway. |
  | tunaiPayPaymentMethod | Defines the payment method for the TunaiPay gateway. |

## Resolved Issues

### GUI Fixes

* Refreshing the page while in the User editor (Portal management > Structure > Users) no longer results in a blank screen. Structure view now restores the previously selected Organisation when exiting editors for Organisation, Venue, Users, Devices after a page refresh.
