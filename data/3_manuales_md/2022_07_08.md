# Release Version: 22.07.08\_\_stable\_\_0.72.0

### Release Date: 07/08/2022

## New Features

* We have added the possibility to **search** the organisation tree in the **main navigation bar** and in **Portal Management** > **Structure** using the **Organisation ID**.

## Updates

### Feature Updates

* We have added a **spinner** to the payment selection portal which is displayed after clicking the **submit** button. This has been done in order to handle the situation where the user could start the payment process multiple times. The payment methods other than the selected one are disabled.
* We have expanded the **PMS (Property Management System)** acronym in selected sections of the **Platform** for better clarity.

### GUI Updates

* We have redesigned the **organisations editor** in **Portal Management** > **Structure** > **Organisations** into a full screen step editor.
* The **Date** and **Date Range** pickers have been replaced by new components throughout the whole **Platform**.

## Resolved Issues

### System Fixes

* We have fixed the **Area Density Alerting**, now events will only be generated in organisations connected to **Density Alerting**.
