# Configuring an Internet Access Node

You can configure your WiFi by setting up limits to time, speed, and data of internet connection.

To do this, go to the desired Internet Access Node in the Page Flow, and click the **More** option. Then, select **Edit Parameters** from the menu.

![configuring internet access node](../images/page_flows/configure_internet_access_1.png)

In the **Network Parameters** window, you can set up:

* The **Time Limit** is the period in which a user is logged in to the WiFi regardless of the number of connections which they establish;
* The **Download Speed Limit** option limits the speed with which the user’s device downloads data; to set up this option, turn the switch **ON**,
* The **Upload Data Limit** option limits the amount of data that the user’s device can send; to set up this option, turn the switch **ON**,
* The **Download Data Limit** option limits the amount of data that the user’s device can load; to set up this option, turn the switch **ON**;.

![configuring internet access node](../images/page_flows/configure_internet_access_2.png)

To confirm your changes, click **Save** in the top right corner.
