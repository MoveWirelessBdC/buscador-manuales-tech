# Email Customisation

The **Email Customisation** feature allows you to adjust email messages generated by the Platform. Those emails include: user administration, e.g. password reset messages, and licence notifications.

To access it, go to the **Portal Management > Sending Centre** section and select the **Email Customisation** tile. At the top, you can find two tabs: **Content** and **Format**. The **Content** tab enables you to modify texts of each email message on the list, and the **Format** tab allows you to adjust visual templates for those messages.

![email customisation](images/email_customisation/email_customisation_2.png)

## Sending Test Emails

Before you start customising an email message, you can preview its current look by sending a test message to an email address of your preference.

1. To do this, click the **More** option in the top right corner of the desired message panel, and select **Send Test Message** from the dropdown list.

   ![email customisation](images/email_customisation/email_customisation_5b.png)
2. Next, in the pop-up box:

   * From the **Message Language** dropdown list, choose a language in which you would like to preview the message
   * Into the **Email Address** field, enter an email address to which the test message should be delivered.

   Then, in the bottom right corner, click **Send**.

   ![email customisation](images/email_customisation/email_customisation_10.png)
3. The test message should now have been sent to the designated email address. Below, you can see an example of a password reset message.

   ![email customisation](images/email_customisation/email_customisation_12.png)

## Customising Email Content

The **Email Customisation** feature allows you to modify texts of all email messages according to your preferences.

1. To begin the customisation, go to the **Content** tab, and choose an email message which you would like to edit from the list. Then, click the **More** option in the top right corner of the message panel and select **Edit** from the dropdown list.

   ![email customisation](images/email_customisation/email_customisation_5.png)
2. In the first step, you can select language versions in which the message would be generated. To do this, select the desired option from the **Version Type** toggle button.

   ### Default Language Versions

   The **Default** option sets the language versions configured in the Platform, which are English and Polish. You can send a test message to the designated email address to preview its content and appearance by clicking the **Send Test Message** button and re-following the steps from the **Sending a Test Message** subchapter.

   To finish setting up the default language versions, click **Save** in the top right corner of the window.

   ![email customisation](images/email_customisation/email_customisation_6.png)

   **Note:** If your Organisation is a Sub-Organisation, you will see different options in the toggle button: **Inherited** and **Own**. The **Inherited** option allows you to set languages which you have inherited from your parent Organisation. The **Own** section enables you to add other language versions for your Organisation.

   ![email customisation](images/email_customisation/email_customisation_18.png)

   ### Custom and Own Language Versions

   The **Custom** (**Own** for Sub-Organisations) toggle button option allow you to set up language versions of your preference.

   1. To add a custom language version, click the **Add Language Version** button.

      ![email customisation](images/email_customisation/email_customisation_7.png)

      **Note:** If your Organisation is a Sub-Organisation, select the **Own** option from the toggle button, and click the **Add Language Version** button to add a preferred language.

      ![email customisation](images/email_customisation/email_customisation_18.png)
   2. Now, in the **Add Language Version** pop-up box:

      * From the **Select Language** dropdown list, select the desired language
      * Into the **Message Title** field, enter the message title
      * In the **Message Content** field, customise the text of the message.  
        **Note:** Customising the message content requires basic knowledge of HTML.

      After you have finished customising the content, click **Add** in the bottom right corner of the pop-up box to add the language version to the list.

      ![email customisation](images/email_customisation/email_customisation_8.png)

      **Note:** To change the Organisation name displayed for the `$product_name` tag, you can set up the `platformName` property to the name of the desired Organisation. This way, the Organisation name can be automatically replaced in titles and footers of all email messages.
   3. To add another language version, re-follow the steps 1-2.

      ![email customisation](images/email_customisation/email_customisation_9.png)
   4. To edit or remove a language version from the list, click the **More** option on the right side of the desired language panel, and select the preferred option.

      The **Edit** option will open the **Add Language Version** pop-up box for you to make the desired changes. The **Remove** option will remove the selected language from the list.

      **Note:** To retrieve a removed language version, you should add it to the list and customise it once again.

      ![email customisation](images/email_customisation/email_customisation_11.png)
   5. After you have finished setting up the custom language versions, you should select a default language version from the **Default Language Version** list.

      The default language version of the message would be sent to users who use the Platform in other languages than those versions which you have set up.

      To finish setting up custom language versions and save the configuration, click **Save** in the top right corner.

      ![email customisation](images/email_customisation/email_customisation_9.png)

## Formatting Email Messages

The **Email Customisation** feature enables you to modify templates of email messages in the **Format** tab.

![email customisation](images/email_customisation/email_customisation_2.png)

1. Before you start editing a template, you can preview its formatting by sending a test message. To do this, click the **More** option on the preferred template, and select **Send Test Message** from the dropdown list.

   ![email customisation](images/email_customisation/email_customisation_13.png)
2. Now, in the pop-up box:

   * From the **Message Type** dropdown list, select the type of message which you would like to preview
   * From the **Message Language** dropdown list, choose the language of the message
   * Into the **Email Address** field, enter the desired email address.

   ![email customisation](images/email_customisation/email_customisation_14.png)
3. The test message should now have been sent to the designated email address. Below, you can see an example of a password reset message.

   ![email customisation](images/email_customisation/email_customisation_12.png)
4. To edit a message template, choose the type of messages which you would like to adjust (either User Accounts, or Licences), and click the **More** option in the top right corner of the panel. Then, select **Edit** from the dropdown list.

   ![email customisation](images/email_customisation/email_customisation_15.png)
5. In the new window, you can select the format style of messages from the **Style** toggle button.

   The **Default** option sets up the default Platform template. You can preview it by sending another test message.

   ![email customisation](images/email_customisation/email_customisation_16.png)

   The **Custom** option provides you with an HTML editor where you can change the template’s configuration.

   **Note:** Modifying the message template requires basic knowledge of HTML.

   After you have adjusted the template according to your preferences, click **Save** in the top right corner to save the configuration.

   ![email customisation](images/email_customisation/email_customisation_17.png)
