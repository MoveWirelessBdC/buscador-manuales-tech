# Release Version: 24.06.21\_\_stable\_\_0.123.0

### Release Date: 21/06/2024

## New Features

* We have integrated a new type of device with the Platform - **Edgecore**.

## Updates

### Feature Updates

* We have added support for disconnect message in UniFi Network 7.4+

### System Updates

* We have implemented library updates to enhance system security and mitigate potential vulnerabilities.

## Resolved Issues

### GUI Fixes

* We have fixed the User traffic chart under Reporting > Location > Venue - now it shows the date and hour when Hour granularity is selected, similar to all other charts of this type. Previously only the hour was shown, which could lead to ambiguity if viewing data from several days or longer.

### System Fixes

* We have enhanced session data for Returning user condition in the Flow by including the identifiers used in the primary session.
