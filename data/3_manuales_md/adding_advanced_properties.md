# Advanced Properties

You can modify the default Platform settings by configuring Advanced Properties for your Organization.

## Configuring Advanced Properties

1. Go to **Portal Management > Properties > Advanced**.
2. In the Advanced Properties section, you will see a table with all available properties.
3. To edit a property, locate the desired key in the table or use the search option to find it quickly.
4. Once you’ve found the property, use the context menu on the row to access a popup for editing the value.
