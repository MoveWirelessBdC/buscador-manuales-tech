# Release Version: 23.01.20\_\_stable\_\_0.86.0

### Release Date: 20/01/2023

## New Features

* Added brute force blocking on Flow Components. After defined by property maxNumberOfTriesPerSessionIn5Minutes (default no value = no blocking) failed attempts user needs to wait 5 minutes counting from first try. Components with blocking: Token, Password, Captcha, User Account, Phone and Email Verification.
* Added skip permission flags to user settings. Those flags disable permission applications for the selected user, while still allowing management of this permission - for roles and other user management. Currently, there are two such flags - disable REST API and anonymize personal data. Configuration of those flags requires disabledPermsFlagSetting permission.

## Updates

### GUI Updates

* Updated design of Licence Packages and Licences editor
* Added option to show/hide and copy the password in the summary step of platform user creator
* Added anonymization and blurring of device ids to Troubleshooting and Manual CoA views

### System Updates

* Better anonymization of user data in application logs
* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| disabledPermsFlagSetting | Allows the user to manage flags that disables application of specific permissions |
