# Release Version: 22.03.18\_\_stable\_\_0.64.0

### Release Date: 03/18/2022

## New Features

* We have integrated the **Samsung** AP with the Platform.

## Updates

* We have cleaned up the **logging** process which allowed us to **reduce** the number of logs by **20%**.
* We have added support for**TPlink Omada V5 Controller**.
* We have integrated **Arista** with the Platform’s Location Engine.

### System Updates

* We have added the following permission to the Platform:

| Permission Name | Description |
| --- | --- |
| sensitiveDevicesPropertiesViewing | Allows the user to preview sensitive values in Devices and Controllers |

## Resolved Issues

### System Fixes

* We have fixed the issue with displaying the duration of the sublicense when there are length limitations, and the end date of the licence package.
* We have added **encrypted** fields in the **NAS** and **Controllers** view/editor for **sensitive data**.
