# Release Version: 23.03.17\_\_stable\_\_0.90.0

### Release Date: 17/03/2023

## New Features

* We have implemented a new template for Reports within the Email Customisation feature of the Sending Centre. This update will significantly enhance the visual appeal of Reports. In the next release, this template will be integrated with the Report Manager to provide a more user-friendly customization process for our clients.

## Updates

### Feature Updates

* Removed possibility to use old tokens in Flows
* Support for CradlePoint AP added

### GUI Updates

* The appearance of the report list is refreshed

### System Updates

* Fixed behaviour of **Network** REST API when no organisation has been provided. Removed dependency on GUI permission for that API. Now new permission **readNetworkData** is needed to use this API.
* **Forms** REST API no longer uses GUI permissions to anonymise personal data.

## Resolved Issues

### Feature Updates

* Fixed **Activity stream** search to find User's activity by login and ID
