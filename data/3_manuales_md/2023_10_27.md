# Release Version: 23.10.27\_\_stable\_\_0.106.0

### Release Date: 27/10/2023

## New Features

* We have integrated Cisco with Catalyst WC with Platform.

## Updates

### Feature Updates

* User Behaviour-based Filtering: We've enhanced the Target Groups filtering based on user behaviour. This enables
  better targeting of audiences based on their activity within the organisation.
* WiFi User Profiles in Marketing Campaigns: We've refined the statistics related to WiFi user profiles targeted in
  Marketing campaigns.

### System Updates

* To enhance system performance and maintain up-to-date security standards, we've updated our Java libraries following
  the migration to Java 11. However, users should be aware that these updates may introduce changes in the generated
  Swagger documentation.

## Resolved Issues

### Feature Fixes

* Campaign Send Process fixes:
  + WiFi User Profile identification now utilises the WUP ID instead of the MAC address.
  + Data displayed in the "Campaign Sent Details" section is now correctly matched to the WiFi User Profile using the
    WUP ID, rather than the device ID.
  + We have minimised the chances of sending multiple messages to a single user.
