# Release Version: 25.07.04\_\_stable\_\_0.150.0

### Release Date: 04/07/2025

## New Features

* We have developed a new internal tool that significantly accelerates integration with new access points, reducing
  integration time and improving overall efficiency as we expand our supported device ecosystem.

## Updates

### Feature Updates

* We have added the **Every time** option for consent frequency in both Service Documents and Marketing Categories.

### System Updates

* We have split the **addMessageAuthenticatorAttribute** property into two separate properties:
  **addAuthMessageAuthenticatorAttribute** for authentication requests and
  **addAccountingMessageAuthenticatorAttribute** for accounting requests.
* We have upgraded the platform runtime to the latest Java 21 LTS release.
* We have enforced a maximum password length of 72 bytes across the platform and unified validation rules to ensure
  consistent system-wide enforcement. Passwords must now be 8-72 characters long and include at least one lowercase
  letter, one uppercase letter, one digit, and one special character.
