# Release Version: 22.06.10\_\_stable\_\_0.70.0

### Release Date: 06/10/2022

## New Features

* We have added two new tabs in **User Enrollment** > \*\* Access methods **>** Payment Plans **section:** For Sessions **and** For User Accounts\*\*.

  + In the **For Sessions** tab you may **create** new, and **edit**, **export**, or **delete** the existing **Payment Plans** for single sessions (same as before).
  + In the **For User Accounts** tab we have added a new table in which you may create Payment Plans (only in organisations that are configured to store User Accounts), edit and delete. This table also displays information about the available plans for the given **User Account** such as:
    - **Name** - name of the plan
    - **Price** - price of the plan
    - **Duration** - the length of the plans duration
    - **Transfer quota** - the initial amount of data
    - **Created in** - in which organisation the plan was created
    - **Action** - allows you to edit or delete the plan
* In **User Enrollment** > \*\* Access methods **>** User accounts **we have added two new tabs:** User Accounts **and** Notifications\*\*.

  + In the **Notifications** tab it is now possible:
    - edit, delete and create notifications
    - send the notifications either by SMS, Email or both
    - set the threshold when the notification will be sent either by remaining data or percentage.
    - These \*\* notifications \*\* are sent to the \*\* User Accounts \*\* after using the transfer that was set in the notification section.
* In **User Enrollment** > **User journey** > **Portal** > **Portal editor** section we have added a few new features:

  + We have added the possibility to create a User Account **Phone number** type by logging in to the Captive Portal. This is possible with the multi-step login component **Phone number registration**. First use the Portal with the **User registration** component (Phone number with password), and then the Portal with the **Phone number verification** component.
  + In the **User Registration** component for each form of registration we have added the possibility to enable **Notifications**. If this is enabled, users will be informed about the transfer they have used after they register.
  + The **Payment Plans** component (first step in Payment Plans multi-step login) has gained the possibility to choose as well **For User Accounts** as **For Sessions**. It is now possible to use them in the **Captive Portal**.
  + We have added the ability to use new **$accountQuotaLeft**, **$accountQuotaValidity** tags on **Captive Portals** showing the amount and the expiry date of remaining data on the logged in customer's account. This is possible in the **Multimedia** > **Text component**.
* When importing / exporting **Portals**, we took into account new components of **Payment Plans** for **User Accounts**.
* When moving the organisation in the tree, we have implemented a check whether the transferred **organisation** will not lose access to **Payment Plans** (for sessions and for accounts) used in **Captive Portals**.
* We have added the option to preview the **Platform** as a different user. This is available in **Portal management** > **Structure** > **Users** > **Option** > **View as user**.

## Updates

* The translations for **Payment Plans** have been made more consistent in all locations.
* We have **blocked** the possibility to change the **existing controller type** so as not to cause errors.
* In **Portal management** > **Sending Centre** > **Sending Configuration** a new category, **System**, has been added. This category includes **password reset**, **new user welcome**, **licences**, **reports**, **billing**, **calibration**.

### GUI Updates

* In **Portal management** > **Structure** we have made the **Organisations** tab more consistent and added additional information. Now you can view the settings for:
  + Data Administrator
  + Account holder (set via properties)
  + Email sending administrator
  + SMS sending administrator
  + Time zone
  + Additional settings (set via properties): Service name, Country code, Default language, Currency

### System Updates

* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| userAccountPaymentPlanManager | Allows the user to access the Payment Plan Manager for User Accounts |
| userAccountNotifications | Allows the user to access the notification tab view in User Accounts |
| setDataTransferNotifications | Allows the user to set and edit Data Transfer notifications |
| viewAsUser | Allows the user to view the Platform as a different user |
| editSystemTarget | Allows the user to access the System section in the Sending Centre Properties |
| readChangeOrgAccountHolder | Allows the user to display and change the Account Holder |
