# Release Version: 22.05.13\_\_stable\_\_0.68.0

### Release Date: 05/13/2022

## New Features

## Updates

* We have added a new condition which checks if a transfer is available on the account of the logged in user. Also the option to disable the **transfer limit validation** in **User Login** component in **Portals** has been added. This component allows the user to log in without an available transfer, go through the condition and direct through the appropriate path, and if the **Internet Access Node** is reached the internet connection will not be established anyhow.
* We have added **localisation** support based on Bluetooth data for **Arista**.

### System Updates

* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| accountUserTransferCondition | Allows the user to add Data Transfer condition to Page Flows |
| userLoginDisableTransferValidation | Allows the user to access the Disable transfer limit validation in User Login component in Portal editor |

## Resolved Issues

### GUI Fixes

* We have fixed an issue where it was not possible to enter the **Location Management** > **Management** > **Engine** view, where you select Engine configuration mode, if a **venue** was previously running without calibration mode.

### System Fixes

* We have fixed the issue in the **Licence Package Creator** where the **date picker** (licence start and end) has been changed to the new **Duration selector**.
