# Release Version: 25.03.14\_\_stable\_\_0.142.0

### Release Date: 14/03/2025

## New Features

* We have added a new payment method for the login via Payment plans - **Fiuu** payment gateway.
  To properly configure the Fiuu gateway, the following properties must be set in the organisation:

| Property name | Description |
| --- | --- |
| fiuuEnableIntegration | Enables the Fiuu payment option in the Payment Method component. |
| fiuuApiHost | Defines the URL for the Fiuu gateway. |
| fiuuMerchantId | Defines the Merchant ID for the Fiuu gateway. |
| fiuuVerifyKey | Defines the Verify Key for the Fiuu gateway. |
| fiuuSecretKey | Defines the Secret Key for the Fiuu gateway. |
| fiuuExtendedPaymentVerificationFormat | Enables the extended format for Verify Payment for the Fiuu gateway. |
| fiuuInstantPaymentNotification | Enables Instant Payment Notification for the Fiuu gateway. |

## Updates

### GUI Updates

* We have modified the structure of Ad components in Portal editor and renamed **Ad Display settings** to **Viewing
  Requirements**.
* We have added information about Flow or Portal deletion dates in Ad statistics.

### System Updates

* We have updated the libraries used by the platform's web application.
