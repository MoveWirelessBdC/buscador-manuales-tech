# Release Version: 25.03.28\_\_stable\_\_0.143.0

### Release Date: 28/03/2025

## Updates

### System Updates

* We have optimised the handling of dashboard trends computation.

## Resolved Issues

### GUI Fixes

* We have fixed incorrect calculation of available weekdays for time zones with a negative UTC offset (such as those in
  the Americas).

### System Fixes

* We have restored logs gathering for a few additional services, ensuring that logs are now retained for a longer
  period.
* We have fixed a syslog receiving issue that could cause a service restart.
