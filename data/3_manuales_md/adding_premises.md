# Adding premises

Now that you have named the categories of premises in your venue, it is
time to add premises and assign them to their categories.

To add premises:

1. Go to **Location Management → Navigation**.
2. Next to the name of your venue, click **Premises management**.
3. To add premises by importing a CSV file together with a zip file:

   a) Click **Import from CSV**.

   b) Select the CSV file and click **Open**.

   Note

   * The CSV file must follow a specific order:

   Name; floor; description; file name with logo; file name with background photo; category name.  
   For example:

   *Shop 1; 0; Shop 1 is a leading company in the fashion industry; 1\_logo.png; 1\_background.png; Fashion*

   * Each information should be separated by semicolons (;).
   * For assigning one premises to different categories, separate the
     names of categories with a hat (^). For example, to assign a shop
     to categories Fashion, Home, and Design, you would type:
     *Fashion^ Home^ Design*.
   * The images of the logo and of the background must have the same
     name as their names in the zip file.
   * The file will not upload unless all categories mentioned in it are
     created in the **Edit categories** menu. However, the
     assignment is optional.

   c) To upload a zip file with images of logos and backgrounds, click **Import images**.

   d) Select the file and click **Open**. As a result, the images have been added to the premises.
4. To add a single premises manually:

   a) Click **Add premises**.

   b) In the **Edit/Add premises** window, upload the logo and background images by clicking ![pencil](images/image227.png) and add details of the premises.

   Note

   Only the fields with \* are obligatory.
   To assign the place to a given category, in the **Categories** section, next to the name of the category, click ![](images/image234.png).

   Tip

   You can assign premises to many categories.

   ![Add premises panel](images/image235.png)

   c) Click **Save**. As a result, the premises is added to the **Premises Management** panel.

   d) Repeat the step for all the premises of your venue.

   ![premises list](images/image236.png)

   Note

   * Two-floor places must be added as two separate places.
   * The grey marker point in the **Bind area** column means that the premises is not assigned to any particular area in the plan. After
     the premises is assigned, the marker point changes its colour to blue.
