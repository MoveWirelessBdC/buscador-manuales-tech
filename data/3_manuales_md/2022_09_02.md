# Release Version: 22.09.02\_\_stable\_\_0.76.0

### Release Date: 09/02/2022

## Updates

* In order to improve blocking when incorrectly entering the **two-factor authentication** code, we have added a **property** which defines the **maximum** number of consecutive **incorrect logins** after which the username will be **blocked** permanently.
