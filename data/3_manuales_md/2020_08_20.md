# Release Version: 20.08.20\_\_stable\_\_0.23.0

### Release Date: 08/20/2020

## New Features

* We have introduced the integration with the new type of devices - the **Terabee People Counting L** cameras. These camera devices allow you to monitor user entries and exits between different areas at your venue, and gather statistics which can be displayed in the **What do you know about user traffic?** section of the Location statistics.  
  **Note:** To display the collected data, you must have your Venue set up in the Location mode.
