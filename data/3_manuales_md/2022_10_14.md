# Release Version: 22.10.14\_\_stable\_\_0.79.0

### Release Date: 14/10/2022

## New Features

* We have added an integration with the SMS **Cequens** gateway.

## Updates

### Feature Updates

* We have added the option to edit condition nodes with existing connections, so that they don't get deleted while editing a node. It is possible to add or remove conditions, which results in changing existing connections, so before saving a Flow, you need to make sure it is built correctly. Changing the condition type deletes all existing connections and requires connecting the condition from scratch.

### GUI Updates

* We have introduced new columns: **Brand**, **Model**, **Operating System**, **Operating System version**, **Browser** and **Browser versions** to the device-related part of the User Sessions table in **Reporting > Statistics > Raw Data**.
* A new pie chart **Device Brands** has been added to **Reporting > Statistics > Wi-Fi Users**. It presents the percentage breakdown of the device brands with which users connect to the WiFi.
* We have removed the COVID-19 badge for **Density alerting** from the left menu.

### System Updates

* Due to a stricter security policy, our API no longer accepts cross-origin requests. See <https://web.dev/cross-origin-resource-sharing/> for a thorough explanation of the topic.
* We have added mechanisms that clean up leftover WiFi User data when an organisation is deleted.

## Resolved Issues

### GUI Fixes

* We have fixed the wrong colour of the toggle button in **Portal editor > Multi-step login > Payment Plans**.

### System Fixes

* We have fixed the Internet access node custom URL redirect for URLs containing unicode characters.
