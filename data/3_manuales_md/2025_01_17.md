# Release Version: 25.01.17\_\_stable\_\_0.138.0

### Release Date: 17/01/2025

## Updates

### System Updates

* We have removed processing for the previous version of the campaign feature. Going forward, only the [new version of
  campaigns](../../whats_new/2024/04.html) will be processed. This change improves system performance and ensures greater
  efficiency.

## Resolved Issues

### Feature Fixes

* We have fixed the Location Campaign being sent to users localised outside the selected area.

### System Fixes

* We fixed an issue with login request processing for Cambium devices.
