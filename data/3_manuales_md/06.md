# What’s New in June 2020

## Density Alerting

We have introduced the new **Density Alerting** tool that allows you to define limitations to the number of customers at your venue and set SMS, email, or endpoint notifications on when those limits are exceeded. It may be beneficial to monitor and maintain social distance in traffic places like shopping malls.

To access it, go to the **Location Management** section in the left menu, and select the **Density Alerting** option from the dropdown list.

## Form Condition Updates

The **Form Condition** now enables you to direct your WiFi users to specific Flows based on their responses to open questions. To use it, add a Form Condition Node to a Page Flow, and select the desired Form.

![form condition](images/form_condition_questions_1.png)

## Customising Tokens Print View

From now on, you can customise the print view of Tokens using HTML and CSS. To do this, display the Tokens list and click the **Display Tokens print view** icon in the top right corner. Then, select the **Custom** option from the toggle button in the top bar and adjust the print view to your preferences.

## Permissions

We have added several new permissions to the platform. Be sure that you accordingly update them for all your platform users.

| Permission name | Description |
| --- | --- |
| createFlowLoyalty | Allows a user to create Loyalty Programs |
| editFlowLoyalty | Allows a user to edit Loyalty Programs |
| deleteFlowLoyalty | Allows a user to remove Loyalty Programs |
| flowTokenFormatter | Allows a user to create a custom Tokens print view |
| verifyFlowLoyaltyToken | Allows a user to verify tokens in Loyalty Programs |
