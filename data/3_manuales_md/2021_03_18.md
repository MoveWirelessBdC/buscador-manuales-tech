# Release Version: 21.03.18\_\_stable\_\_0.38.0

### Release Date: 03/18/2021

## New Features

* We have implemented time zone support for Licenses, which makes them more precise and allows you to manage them more accurately.
* We have integrated a new type of device with the Platform - **TP-Link**.

## Updates

### GUI Updates

* We have updated how the remaining time is displayed in Licence Package and Sublicence panels, so it gives you clear information on licence validity.
* We have modified the **Users** and **Devices** tables in the **Structure** section to contain all the necessary data.

### Feature Updates

* We have continued modifying the Licence notifications that now allow you to edit the list of contacts as well.

## Resolved Issues

### GUI Fixes

* When entering an inappropriate number of digits into the Token field on a Captive Portal, users might have encountered an unnecessary error. We have fixed it, and it should not cause any further issues.

### System Fixes

* We have improved the way Licence data transfer is counted for sessions that last through midnight. They are now divided into appropriate periods to ensure counting correctness.
* Users would not recover their passwords if their email addresses contained the `+` character. We have corrected this error, and the character should not return errors anymore.
* We have fixed an issue where end users would see a warning at the end of a page flow about their data being sent over an insecure connection.

  This problem occurred if the captive portal was accessed over HTTPS, but the final communication with the Access Point to give user internet access had to be done using HTTP.

  Please note that this warning was needlessly alarming as the data being sent did not include any user's personal or sensitive information.
