# Checking activity stream

Activity stream enables you to check what changes were applied in the
platform, who applied them and when.

To check an activity stream:

1. Go to **Portal Management → Activity stream**.
2. Select a filter. You can choose:

   * **User login** – shows changes applied by a user.
   * **Organisation** – shows changes applied within an organisation.
   * **Single entity** – shows changes applied in a selected type of actions, such as captive portal edition.
   * **Entity group** – shows changes applied in a group of actions, such as organisation’s structure edition.
3. From the calendars, select a **Start date** and an **End date**.
4. Into the **Search for phrase** field, type a searched phrase.
5. Click **Show**. As a result, you can see all the
   changes applied.
