# Release Version: 21.06.25\_\_stable\_\_0.45.0

### Release Date: 06/25/2021

## New Features

* We have added the disconnect option for **Ruckus Cloud** and **Meraki**.
* We have implemented an algorithm to calculate the granularities available for a given venue on the heat map.

## Updates

* Fine-grained permissions which hide personal data in the **Dashboard > Sessions > Raw data** tables have been added. If there is a lack of **“Access User Personal Data”** permission the data is blurred.

| Permission Name | Description |
| --- | --- |
| statisticsFirstNameAccess | Allows the user to display first names. |
| statisticsLastNameAccess | Allows the user to display last names |
| statisticsAddressAccess | Allows the user to display addresses |
| phoneNumberAccess | Allows the user to access phone numbers |
| emailAddressAccess | Allows the user to display email addresses |
| macAddressAccess | Allows the user to display MAC addresses |
| attachFlowNetwork | Allows the user to attach Page Flow |

### Feature Updates

* We have introduced a notification settings option with the appropriate permission to the **UserAccount API** and to the **CSV import**.
* We have added a separate permission to **attachFlowNetwork** from **editFlowNetwork** which allows you to connect the network to flow.

## Resolved Issues

### System Fixes

* We have fixed the issue with old captive portals, where the initial page sends the user to the captive portal and shows its source in plain text to the end-user if proxied through an **Aruba** access point
