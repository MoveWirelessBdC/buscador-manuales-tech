# Creating a Target Group

The platform allows you to create a Target Group according to your preferences.

In the **Campaign Editor**, proceed to the **Target Group** step, and click **+** in the bottom right corner.

1. In the **Edit Target Group** window:

   * Select the preferred picture by clicking the **Back** and **Next** arrows, or upload a new picture by clicking a **Pen** icon,
   * In the **Target Group Name** field, type the group name.
   * From the **Gender** dropdown, select the users’ gender,
   * On the **Age** slider, define the users' age range.  
     Note: If you select 0-100, all of the users of the specified gender will be included in the target group.
   * From the **Customer Type** toggle button, select the type of the user: **New**, **Returning**, or **All**,  
     Note: If you select **Returning**, you should specify the number of visits In the **Number of Visits** field.
   * In the **Time Span** section, select the time range.

   When you have finished providing the details, click **Save** at the bottom to create the target group. You can now use it in your campaigns.
