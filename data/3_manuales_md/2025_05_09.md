# Release Version: 25.04.28\_\_stable\_\_0.145.0 & 25.05.09\_\_stable\_\_0.146.0

### Release Date: 09/05/2025

Note: This release includes both the 25.04.28\_\_stable\_\_0.145.0 and 25.05.09\_\_stable\_\_0.146.0 release versions.

## New Features

* We have added a new Ad type to the Portal Editor - Splash Ad, which is displayed over the rest of the page until the user closes it.
* We have introduced a new internal feature to support better analysis of client login issues, including cases related to AP configuration.

## Updates

### System Updates

* We have introduced the **addMessageAuthenticatorAttribute** property, which controls whether the Message-Authenticator (80) attribute is added to the encoded message. This property is effective only for supported message types and is enabled by default (set on true).
* We have removed support for accessing WiFi User Profiles with Accounting Session cursors.
* We have reworked internal configuration for microservices start-up to make it more resilient and to ensure more consistent start-up behaviour.

## Resolved Issues

### GUI Fixes

* We have fixed an issue in the Portal Editor that caused portal components to display incorrectly because styles and assets were loading at the wrong time.
