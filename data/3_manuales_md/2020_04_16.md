# Release Version: 20.04.16\_\_stable\_\_0.14.0

### Release Date: 04/16/2020

## New Features

* Videos and images used in Portals are now connected with the Ad Server statistics and allow you to gather the video and image statistics.
* We have implemented the new troubleshooting feature, which allows you to track Device configuration issues.
* We have also introduced the new **Phone Number Condition** that you can add to Page Flows. It allows you to differentiate end-users based on phone number digits, and redirect them to designated Page Flows.
* The User registration section of the Portal editor has been expanded with the **Password Security** option, which enables you to set up the complexity of the password which your users must provide while registering to your WiFi.
* You can now search User Accounts by device MAC addresses.
* We have added the following permissions:

| Permission Name | Description |
| --- | --- |
| benuController | Allows a user to add a Benu Controller device |
| phoneNumberCondition | Allows a user to add the Phone Number Condition in the Flow |
| passwordSecuritySection | Allows a user to configure password in the User Registration component in the Portal editor |
| questionnaireCondition | Allows a user to add the Form Condition in the Flow |

* We have also added a new property, which enables the newly updated Tokens feature:

| Property Name | Description |
| --- | --- |
| enableFlowTokens | Enables the new Tokens feature |

## Updates

* You can now compare two roles and permissions sets that they contain in the Roles and Permissions section.
* The Token codes and the User accounts can now be exported into the CSV file.
* We have added the regular expression options in the Form editor and the Phone Number Condition.
* From now on, you can provide names of each image which you add to Portals.
* User accounts can now be filtered by their registration type.

## Bug Fixes

* The Platform login component now displays appropriately and should not cause any issues.
* The Advanced Search in the Structure section has not allowed you to search for MAC addresses that contained special characters. We have resolved this problem, and the Search now works as supposed.
* We have fixed padding issues in Portal layouts, and the padding numbers should now display as expected.
