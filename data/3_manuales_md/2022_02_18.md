# Release Version: 22.02.18\_\_stable\_\_0.62.0

### Release Date: 02/18/2022

## New Features

* In **User Enrollment** > **User journey** > **Portal** we have implemented a new feature that allows the user to import previously exported Portals from the **Platform**. We have also added the ability to **rename** imported entities - including single renaming as well as adding a **prefix** to all names.

## Updates

### Feature Updates

* The **Users Now** table on the **Dashboard** has been changed to **Sessions Now** so that it shows data about individual active sessions, and not about sessions grouped by their profiles.

### System Updates

* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| importFlowResource | Allows the user to import resources |
| exportFlowResource | Allows the user to export resources |

## Resolved Issues

### System Fixes

* When importing **Accounts**, the IDs of SSIDs to which the account can log in are now checked whether they are in the same organisation.
* We have fixed the incorrect requirement of **access Organisations** permission in order to create platform users.
* We have fixed an issue with several **multi-step** editors where a user using the browser's **back button** would not be asked for confirmation before discarding unsaved changes.
* You can now change the **case** of the letters when changing the name of **Roles**.
* The method of calculating **average connection** duration on the **Dashboard** has been corrected - now sessions going through **midnight** will be taken into account correctly.
