# Release Version: 20.06.10\_\_stable\_\_0.18.0

### Release Date: 06/10/2020

## New Features

* We have introduced the new **Density Alerting** tool that allows you to define limitations to the number of customers at your venue and set SMS, email, or endpoint notifications on when those limits are exceeded.
* The Domain Customisation feature now contains the **GDPR** section which allows you to customise the GDPR configuration for your Organisation.

## Updates

* We have updated the Tokens print view, which allows you to easily adjust Tokens' print look to your preferences.
* We have updated the **Roles Manager** section which is now consistent with the rest of the system look. We have also made an update to the **Permission Tree** and grouped all permissions into folders that reflect the system structure.
* We have added the following permissions to the Platform:

| Permission name | Description |
| --- | --- |
| loyaltyComponent | Allows a user to add Loyalty Program to a Portal |
