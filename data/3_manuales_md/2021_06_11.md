# Release Version: 21.06.11\_\_stable\_\_0.44.0

### Release Date: 06/11/2021

## New Features

* We have introduced some enhancements to bulk updates of WiFi User account notification settings for data transfer.

## Updates

### Feature Updates

* We have added a new implementation of the historical heatmap that makes it consistent with the current dashboard view and data aggregation model.

### System Updates

* We have disabled some unused aggregates in the analytics module to reduce system load and free up disk space.
* We have added the following permission to the Platform:

| Permission Name | Description |
| --- | --- |
| usersLocationStatistics | Allows the user to access the Where were your users? section in the Venue statistics |

## Resolved Issues

### Feature Fixes

* Creating and editing venues would not work correctly due to wrong validation. We have therefore fixed the **Add** and **Edit** options for all types of venues to make them work as expected.

### System Fixes

* We have introduced security improvements for the legacy captive portal in old AP integrations.
