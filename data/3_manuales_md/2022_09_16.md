# Release Version: 22.09.16\_\_stable\_\_0.77.0

### Release Date: 09/16/2022

## New Features

* We have overhauled the **Social Media** feature which now allows to create multiple configurations in an organisation in **User Enrollment** > **Access methods** > **Social Media** as well as added new options in the **Portal Editor**.
* Social Media manager:

  + two tabs have been added:
    - **All configurations** - shows all (own and parent organisations), allows to create new, edit existing and delete
    - **Primary configurations** - shows which configurations are automatically used to log in on the **Captive Portal**, you may choose **own** or leave **original** setting
  + you may **expand** each configuration to show all the details (details are dependant on the type of Social Media)
  + the **Create new**, **Edit** and **Delete** options have been added
    - **Create new** - In order for the configuration to be automatically applied as Primary in the Captive Portal, it must be set manually by going to the Primary tab.
    - **Edit** - You cannot change the Social Media platform for the existing configuration
    - **Delete** - You cannot delete a configuration which is used as **Custom** on the **Captive Portal** or is set as the **Primary**
  + In the **Social Media** component in **Portal Editor** we have added:

    - a **toggle button** which enables the user to choose which configuration will be applied in the Captive Portal during logging in: **Primary** or **Custom**
    - the option to choose which configuration to use from the **dropdown list**

    Note

    For proper operation of logging in with the **Social Media** component, it must be configured.

    - We have added the possibility to import and export Social Media configuration settings in the Captive Portal.
* We have added the option to edit licences in **Portal Management** > **Licences and roles** > **Licence manager**.
* The following options are now editable:
  + Licence Order number
  + Plan
  + Description
  + Validity time
  + AP Capacity
* Modification of **Transfer limits** is unavailable during editing.

## Updates

* We have removed the **Social Media** properties from the **REST API** as they are no longer properties. Using the previous names of properties for **Social Media** they will be treated by the methods of this **API** as the name of a **dynamic property**.
* We have **blocked** the moving of **organisations** if:
  + a **Primary** configuration is selected in the **subtree**, which will not be available after the transfer
  + there is a **Portal** in the **subtree** with a selected **Custom** configuration that will not be available after the transfer
* The **internal alert** for comparison of the historical load of the **Platform** has been improved by changing the comparison from “the previous day” to “from a week ago” and adding **support** for real use hours of the installation which allowed to improve **thresholds** and detect potential problems earlier.
* We have cleaned up the processing logs for **user profiles**.

### Feature Updates

* We have removed all the old **Social Media** configuration views.
