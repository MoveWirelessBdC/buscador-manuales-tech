# Release Version: 24.01.19\_\_stable\_\_0.112.0

### Release Date: 19/01/2024

## New Features

* We have added a new payment method for the login via Payment plans - **Klix** payment gateway.
  For the proper operation of the Klix payment gateway, the following properties must be set in the organisation:

| Property name | Description |
| --- | --- |
| klixEnableIntegration | Enables the option of Klix payment in the Payment Method component. |
| klixApiHost | Defines the url for the Klix gateway. |
| klixBrandId | Brand id for the Klix gateway. |
| klixSecretKey | Defines the secret for the Klix gateway. |
| klixDefaultLanguage | Defines the default language for the Klix gateway website. |
| klixAvailablePaymentMethods | Defines the available payments methods for the Klix gateway. No value means default methods defined in Klix app. All available methods: <https://portal.klix.app/api/#/Purchases/purchases_create> |

## Updates

### Feature Updates

* We have added 2 new columns to the Wi-Fi Users table - **Version ID** of accepted Marketing categories and Service documents. Additionally, it is also possible to filter by this data.

### GUI Updates

* We have changed the order of predefined Target Groups and added a new sorting strategy: "Predefined first".
* We have continued to further standardise the appearance of the system.

### System Updates

* We have updated Grafana to new version
