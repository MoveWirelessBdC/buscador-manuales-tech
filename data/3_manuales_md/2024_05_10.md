# Release Version: 24.05.10\_\_stable\_\_0.120.0

### Release Date: 10/05/2024

## Updates

### GUI Updates

* We have upgraded to a new version of our UI library, which underwent a significant overhaul. The entire Platform has been converted behind the scenes over the past 6 months, without disrupting development of new features.   
  The new version changes the overall appearance of the Platform to more closely align with the Material Design specification, and features many improvements to accessibility.
* We have updated the statistics view for our Marketing Campaigns. This redesign introduces a more intuitive layout, improving the clarity and efficiency of campaign performance analysis.

### System Updates

* We have extended enhanced radius validation for most of Ruckus devices modes except Standalone one. Please note that scope of additional verification depends on access point mode.
* We have improved the performance of parsing data streams for Linkyfi Location Engine for some device types, mostly concerning Aruba. Please note that due to how Aruba sends its stream it involves high bandwidth UDP traffic being sent from devices.

## Resolved Issues

### Feature Fixes

* We have fixed WhatsApp Business via **TapTalk** integration.   
  For proper operation one new property needs to be set in the organisation:

  | Property name | Description |
  | --- | --- |
  | tapTalkWhatsAppPhoneNumberId | Phone Number ID to send the message from used for TapTalk WhatsApp Business. |
