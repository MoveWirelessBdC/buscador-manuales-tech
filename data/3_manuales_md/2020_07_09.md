# Release Version: 20.07.09\_\_stable\_\_0.20.0

### Release Date: 07/09/2020

## New Features

* The Loyalty Programs feature now allows you to verify token codes that users receive after having collected the designated number of stamps

## Updates

* We have also implemented the new condition for the **Multiple Choice** option in the **Form Condition**; it allows you to check if the user selected all of the designated answers
* We have added the following permissions to the Platform:

| Permission name | Description |
| --- | --- |
| navigationLandingPage | Allows a user to set the Indoor Navigation as the landing page in a Page Flow |
