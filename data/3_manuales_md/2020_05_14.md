# Release Version: 20.05.14\_\_stable\_\_0.16.0

### Release Date: 05/14/2020

## Updates

* We have updated the Permissions tree, which is now more functional and allows you to select permissions more easily.
* We have extended the Ruckus VSZ setup with the VSZ Port field, which enables you to configure this type of device even more accurately.
* We implemented the much-needed notification that informs you when you change organisations.
* We have added the following permissions to the platform:

| Permission name | Description |
| --- | --- |
| createSingleToken | Allows a user to create single Tokens |
| readSingleToken | Allows a user to view single Tokens |
| deleteSingleToken | Allows a user to remove single Tokens |
