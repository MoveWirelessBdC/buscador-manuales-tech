# Publishing a Page Flow

Note: To publish a Page Flow, you should attach it to **Access Settings**. If you want to learn how to create Access Settings, read the [Creating Access Settings](../create_access_settings.html) chapter.

1. In the **Network Manager**, click the **More** option. Then, from the dropdown list, select **Attach Flow**.

   ![internet access node creating](../images/page_flows/publish_page_flow_1.png)

   ![internet access node creating](../images/page_flows/publish_page_flow_2.png)
2. On the **Page Flows Available** page, select the option which you would like to attach to the Access Settings. In the upper right corner, click **Select** to confirm.

   ![internet access node creating](../images/page_flows/publish_page_flow_3.png)
3. The Page Flow is now published. You can find it in the **Network Manager**, in the **Attached Flow** section.

   ![internet access node creating](../images/page_flows/publish_page_flow_4.png)
