# Release Version: 24.08.16\_\_stable\_\_0.127.0 & 24.08.30\_\_stable\_\_0.128.0

### Release Date: 30/08/2024

Note: This release includes both the `24.08.16__stable__0.127.0` and `24.08.30__stable__0.128.0` release versions.

## New Features

* We have added a **disable answer validation** checkbox for Social Media login components.
* We have added a new **Day of the week** condition to the User journey configuration. It enables selecting the specific days within which the user will be directed along a specific path to the next stage of the flow.

## Updates

### GUI Updates

* We have added support for the **Portuguese** language to the Platform.

### System Updates

* We have updated internal communication to improve efficiency, mostly in preparing emails scope.
