# Release Version: 22.05.27\_\_stable\_\_0.69.0

### Release Date: 05/27/2022

## New Features

## Updates

* The **Notification settings** have been removed from **User Accounts** to the organisation level, and now it is only possible to enable or disable notifications for each account.
* We have added a new **Notification** tab in **User Enrollment** > **Access methods** > **User accounts** section. The table has a default notification set for each Account Holder and it is now possible to create, edit and delete these notifications.
* We have added a new **phone number** type to the **WiFi User Account** and the creation is only available in the **Platform’s GUI**. A new login type has also been added to the **User Login** component in **Portals**, which allows you to login to accounts with phone numbers in **Captive Portals**.
* The presentation of the **User Account** table has been changed to make it consistent with other views. It now shows **User Account** data defined only in the current organisation (excluding those from the sub-organisation). It also speeds up the loading of this table in organisations with a large number of sub-organisations.

### System Updates

* We have blocked the Platform application from indexing in search engines.
* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| userAccountNotifications | Allows the user to access the notification tab view in User Accounts |
| setDataTransferNotifications | Allows the user to set and edit Data Transfer notifications |

## Resolved Issues

### System Fixes

* We have added support for **Chilli** based devices with the nochallenge library option enabled in the firmware. Before the update, this affected **Altai** Access Points with the latest firmware.
* We have fixed the price display in **Payment Plans** in **Captive Portal**.
* We have fixed the **Disconnect Message** for **Aruba Central** access point.
