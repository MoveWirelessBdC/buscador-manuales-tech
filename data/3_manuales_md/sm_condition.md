# Configuring the Social Login User Conditions

The Social Login User Conditions enable you to create a different Page Flow based on the user’s choice to sign in to the WiFi network with the Social Login.

1. Add the Condition Node. To learn how to do this, read the [Adding a Condition Node](../adding_condition.html) chapter.
2. In the **Condition Editor**, select **Social Login User**. In the upper right corner, click **Next**.

   ![internet access node creating](../../images/adding_nodes/condition_node_social_login_1.png)
3. Now, define the Social Login User by confirming their registration through an additional login attempt, and designate when this second attempt should occur in the pop-up box. Then, click **Save** to confirm the changes.

   ![internet access node creating](../../images/adding_nodes/condition_node_social_login_2.png)
