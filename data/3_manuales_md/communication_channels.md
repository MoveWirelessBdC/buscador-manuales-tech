# Creating, Editing and Deleting a Communication Channel

The **Communication Channels** function allows you to ask users about their preferred method of receiving marketing offers.

1. Go to the **User Enrollment → User Agreements** section and select the **Communication Channels** option.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_1.png)
2. In the bottom right corner of the window, click the **+** button to add a new Communication Channel.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_2.png)
3. In the first step:

   * Type the Communication Channel name in the \*\*Communication Channel name \*\* field
   * [Optional] Allow users to edit the initially chosen preferences in their GDPR panel by turning the **Allow Users to Edit** switch **ON**

   Then, click **Next** to proceed.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_3.png)
4. In the following step:

   * Compose both the **Consent**and the **Selection** texts
     The **Selection Text** appears at the top of the list of Communication Channels available for selection. Then, click **Next** to continue.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_4.png)
5. Now, select Communication Channels which you would like to offer to users for selection. You can choose the predefined ones by selecting the **Predefined** option from the toggle button, or select the **Custom** option to add additional ones.

   To remove options, click the **Bin** button next to the desired channel. You can also specify the default status of these methods to **selected by default** by turning the switches **ON** and **OFF**.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_5.png)
6. In the last step, you can review the summary of selected settings and preview the Communication Channels by clicking the **Preview Communication Channel** button.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_6.png)

   ![creating marketing consent](../images/user_agreements/create_communication_channel_7.png)
7. The document has now been created as a **Draft**.

   **Note:** You should note that to add the Marketing Category to the Portal, you must first publish it. To learn how to publish User Agreements, read the [Publishing a User Agreement Document and Adding It to the Portal](publish_document.html) chapter.

   ![creating marketing consent](../images/user_agreements/create_communication_channel_8.png)

## Editing a Communication Channel

To edit a Communication Channel, click the **More** option on the preferred Channel and select **Edit** from the dropdown menu. Then, modify the Channel according to your preferences, and save it to confirm changes.

You can view all the changes in the **Versions** section. To know more about Versions, read the [Previewing User Agreement Versions](checking_document_version.html) chapter.

![creating marketing consent](../images/user_agreements/create_communication_channel_9.png)

## Deleting a Communication Channel

To delete a Communication Channel, click the **More** option on the chosen Channel and select **Delete** from the dropdown menu. Then, confirm deleting the Channel in the pop-up box.

![creating marketing consent](../images/user_agreements/create_communication_channel_10.png)
