# Release Version: 23.12.22\_\_stable\_\_0.110.0 & 24.01.05\_\_stable\_\_0.111.0

### Release Date: 05/01/2024

Note: This release includes both the 23.12.22\_\_stable\_\_0.110.0 and 24.01.05\_\_stable\_\_0.111.0 release versions.

## New Features

* We have added a new display type - **Spatial** to the Traffic Map in Dashboard > Behaviour which displays a 2D heatmap instead of a grid of squares.
  Availability of both the old Grid type and the added Spatial type is controlled by organisation property "heatmapTypes".

## Updates

### GUI Updates

* We have slightly updated the appearance of importer and result views under Portal Management > Licences and roles > User roles, to be more in line with the rest of the platform.
* We have updated appearance of the following views:
  + Customise landing page in Page Flows
  + Form Condition in Page Flow Editor
  + Tags settings in Portal Editor
  + Troubleshooting
  + Organisation subtree manager
