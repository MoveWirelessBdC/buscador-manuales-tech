# Release Version: 21.10.01\_\_stable\_\_0.52.0

### Release Date: 10/01/2021

## New Features

* We have added 2 new payment methods for the login method using **Payment plans**:
* **Paystack**: When going through the **Flow** with the option of paying via **Paystack** and after paying, if the user does not return from the payment section(due to network problems or closing the browser) and re-enters the login, he will **not** be credited with the payment that has already been made.
* **Vodafone Cash**: an **API** for creating transactions has been added as well as a condition with **Success/Error/Pending** in one **API Payment** condition tile.
* We have added a new **A2P** SMS gateway.

## Updates

* We have **significantly** increased the speed of **Analytics** initialisation start-up time.

### Feature Updates

* The **Search** option has been improved in **Device Mapper** on **Dashboard** > **Behavior**. Now, searching by **MAC** or **name** takes into account all floors. The device will be searched for no matter what level it is currently on.
* We have improved the overall visuals for **2 Factor-Authentication** and added **return to previous page/login page** buttons.
* The setting *defaultLocale* property now affects the **default user** notification language in Emails.

### System Updates

* We have added the following permission to the Platform:

| Permission Name | Description |
| --- | --- |
| apiVodafoneCashCondition | Allows the user to add the API Vodafone Cash Condition to Page Flows |

## Resolved Issues

### System Fixes

* An issue which prevented **test messages** from being sent for **campaigns** has been fixed.
* The filter **Areas** in **Traffic Map** is now working properly when the floor doesn’t have the areas defined.
* It is now possible to export or import **Ruckus VSCG Cloud** NAS type **API password** property.
