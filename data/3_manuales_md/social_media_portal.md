# Adding a Social Media configuration to a Portal

1. Create or enter the editor of an already existing **Portal**, and from the left menu, select the **Social Media** category. Then, drag the desired **Social Media** platform tile into the **Portal** workspace.

   ![create user account](../images/Social%20Media/Social_Media_14.png)
2. Choose either **Primary** or **Custom** using the toggle button which enables the user to select which configuration will be applied in the **Captive Portal** during logging in. For proper operation of logging in with the **Social Media** component, it must be configured.

   ![create user account](../images/Social%20Media/Social_Media_11.png)
   -

   Important

   If the organisation that the WiFi users log in to does not have a **Primary** configuration available, the login will fail.

   * If the **Custom** option is chosen, the configuration must be selected from the dropdown list.
     ![create user account](../images/Social%20Media/Social_Media_12.png)
3. Save the **Portal** to confirm the changes.

   ![create user account](../images/Social%20Media/Social_Media_13.png)
