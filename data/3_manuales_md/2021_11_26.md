# Release Version: 21.11.26\_\_stable\_\_0.56.0

### Release Date: 11/26/2021

## New Features

* In the **Forms manager**, the "Export" option has been added to the tile menu. When clicked, it should download a JSON file with the name of the form, containing the exported form and questions.
* We have added the option to configure **allowed** characters and **omit** ambiguous characters in the **token codes** generated for the **Token group** in the **Configuration** step.
* We have integrated the **Vodafone Cash C2B** single stage payment gateway.
* We have added a **search** by **token code** feature to the **Token group** manager.

## Updates

### Feature Updates

* We have added missing **organization name** to all default license emails. In addition, default license emails have been made more consistent.
* After receiving a redirection indicating processing error from **Ruckus SZ** family, a white labeled logo error page is now displayed instead of a blank page.
* Users who logged in through **2-step phone verification** where the phone number was previously verified and remembered for the device are shown with login type **Phone number (R) \*\* instead of** Phone number\*\*.

### System Updates

* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| setTokenCodeConfigurationFlowTokenGroup | Allows the user to configure allowed characters and omit ambiguous characters in the token codes of a given Token group |
| exportQuestionnaire | Allows the user to export Forms |

## Resolved Issues

### System Fixes

* We have fixed the issue with incoherent validation of the title length of **Support documents** in **Service documents**. Now the information that an unknown error has occurred is displayed. This applies to all user agreements.
