# Configuring the Age Conditions

The Age Condition option enables you to differentiate end users based on their age and redirect them to specific Page Flows. You can set up numerous age conditions and design a distinct Page Flow for each one.

You should note that this Condition works properly only if the age data is collected in the login process. You can collect it by using the **Forms** or the **Social Media Login** feature in the captive portal.

1. Add the Condition Node. To learn how to add the Condition Node, read the [Adding a Condition Node](../adding_condition.html) chapter.
2. In the **Condition Editor**, first select the **Age** option. Then, in the upper right corner click **Next**.

   ![internet access node creating](../../images/adding_nodes/condition_node_age_1.png)
3. In the **Age Condition Editor**, click **+** in the lower right corner.

   ![internet access node creating](../../images/adding_nodes/condition_node_age_2.png)
4. In the pop-up box, define the conditions for the users’ age, either by range or the exact value. Click **Save** to confirm.

   ![internet access node creating](../../images/adding_nodes/condition_node_age_3.png)
