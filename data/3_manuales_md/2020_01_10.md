# Release Version: 20.01.10\_\_stable\_\_0.7.0

### Release Date: 01/10/2020

## New Features

* The Devices options now allow you to preview Device settings in the Read-Only mode.
* We have implemented the **Preview Time Interval** option in the Condition Nodes which use Time Interval; it allows you to preview the Condition’s Time Interval setup from the Page Flow Editor.
* We have added the following new permissions to the platform:

| Permission Name | Description |
| --- | --- |
| blockUser | Allow a user to block other users in the Structure panel |
| structureReadDevices | Allow a user to preview list of Devices, and download them into a CSV file |
| structureWriteDevices | Allow a user to add, edit, and remove Devices, and import them from a CSV file |

## Updates

* The User Roles have been updated and now view hierarchically to the sub-organisations; they also can be managed by appropriate permissions.
* We have improved the platform login process; from now on, a user who logs in to the platform for the first time must change their password and accept Platform Terms and Conditions before gaining platform access.
* We have removed the following permissions from the platform:

| Permission Name | Description |
| --- | --- |
| structureOrganizationDevices | it has been replaced by two permissions: structureReadDevices and structureWriteDevices |

## Bug Fixes

* The indicators in the **WiFi Users**, **Users Now**, **Average Connection Duration**, and **Impressions** tables in the Dashboard have been fixed.
