# Creating Access Settings

The Access Settings feature represents your WiFi network and allows you to configure a WiFi network for your venue. You may set up the network’s name and connect it to the Page Flow.

With these settings, you may also create several networks at your venue; for instance, to distinguish a “public” network which should be used by your visitors from a “private” one, which should be used by your staff. You can do this by creating different Access Settings for each network. There is no limit to the number of networks which you may create.

## Creating Access Settings

1. Go to the **User Enrollment → User Journey** section and select the **Access Settings** option.

   ![access settings](images/uj_access_settings.png)
2. In the bottom right corner, click **+**.

   ![add new access settings](images/uj_access_settings_add_new.png)
3. On the **Settings** page, type the name of your network. In the top right corner, click **Save** to finish.

   NOTE: **The name of the network must be exactly the same as the name in the Access Point**. To learn more about Access Points, read the [Adding Devices](../portal_management/adding_a_device.html) chapter.

   ![add new access settings 2](images/uj_access_settings_add_name.png)
