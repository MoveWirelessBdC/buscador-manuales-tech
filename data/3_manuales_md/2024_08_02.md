# Release Version: 24.08.02\_\_stable\_\_0.126.0

### Release Date: 02/08/2024

## Updates

### Feature Updates

* We have added support for Meraki Scanning API Version 2.1 and 3.0 for Linkyfi Location Engine processing.

### GUI Updates

* We have updated the user guide interface.

### System Updates

* We have improved the system by removing outdated libraries and replacing them with efficient alternatives. This update
  enhances performance, maintainability, and code quality.
* We have removed outdated questionnaire views and Vaadin charts dependencies. This update reduces maintenance and
  phases out unused features.
