# Configuring the API M-PESA Conditions

The **API M-PESA** conditions enable the creation of different paths based on the information collected by M-PESA API.

Note: This condition is available only to those clients who are using M-PESA API.

1. Add the Condition Node. To learn how to do this, read the [Adding a Condition Node](../adding_condition.html) chapter.
2. In the **Condition Editor**, select the **API M-PESA** option. Then, in the upper right corner click **Next**.
