# What’s New in August 2020

## User Traffic Statistics

With the newly introduced **Terabee People Counting L** devices which enable the monitoring of user entries and exits between different areas at your Venue, you can gather traffic data and display them in the Location Statistics.

To do this, go to the **Reporting > Location** section in the main menu, and select the **Venue** tile. Then, in the **What Do You Know About User Traffic?** section, you can find two new tables: **User Traffic**, and **Traffic per Camera**.

In the **User Traffic** bar chart, you can view the number of users broken by who entered and exited the Venue, displayed per day or week. The **Traffic per Camera** table shows the list of all devices by their IDs with the number of entries and exits that have been registered.

**Note:** To display the collected data, you must have your Venue set up in the Location mode.

## PayPal Payments

You can now set up confirmation emails in the **Payment Methods** component of the **Portal Editor** which would be sent to users when the payment is registered. Such emails can be configured per each Page Flow.
