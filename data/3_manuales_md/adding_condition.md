# Adding a Condition Node

The **Condition Node** allows you to specify the conditions that will determine which particular Flow path users will be directed to.

Note: This kind of node is not an essential part of the Page Flow. If not used, the Flow will still work correctly.

## Adding a Condition as the **First** Node

1. On the **Condition Editor** page, select your preferred conditions for the Page Flow. Then, click **Next** in the upper right corner to confirm.

   ![internet access node creating](../images/adding_nodes/condition_node_4.png)
2. In the **Condition Editor**, select a condition. In the upper right corner, click **Next** to confirm.

   ![internet access node creating](../images/adding_nodes/condition_node_2.png)
3. The Condition is now added to the Page Flow.

   ![internet access node creating](../images/adding_nodes/condition_node_5.png)

## Adding a Condition Node as the **Follow-Up** Node

1. In the **Condition Editor**, select the desired condition. In the upper right corner, click **Next** to confirm.

   ![internet access node creating](../images/adding_nodes/condition_node_1.png)
2. In the **Condition editor**, select a condition. In the upper right corner, click **Next** to confirm.

   ![internet access node creating](../images/adding_nodes/condition_node_2.png)
3. To finish, save the Page Flow by clicking **Save** in the upper right corner.

   **Note: The Page Flow must be completely finished before it is saved and all nodes must be fully configured in order to conclude the process.**
