# Release Version: 21.01.07\_\_stable\_\_0.33.0

### Release Date: 01/07/2021

**Note:** This release includes both the 20.12.24\_\_stable\_\_0.32.0 and 21.01.07\_\_stable\_\_0.33.0 release versions.

## Updates

### Feature Updates

* We have added a new permission for the **Call Authentication** Portal component that allows you to determine the scope of phone number editing access. You can find it in the below Permissions table.
* You can now determine a specific day of week or month when the data transfer for a User Account should be reset and counted again.
* For Sublicences with a defined data transfer reset, you can now display the history of the base data transfer with which they had been initially created.

### System Updates

* We have introduced a new language version of the Platform, and you can now use it in **French**.
* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| callAuthenticationCustomDisplayedNumber | Allows the user to customise the phone number displayed on the Portal in the Call Authentication component |
| licenceDataRequestReceive | Allows the user to access received requests in the Licence Manager |
| licenceDataRequestSend | Allows the user to access sent requests in the Licence Manager |
| licenceDataPackageRequest | Allows the user to request additional Data Transfer for Sublicences |

## Resolved Issues

### System Fixes

* We have fixed issues affecting the **Inherited** option in Sublicences.
* We have also resolved problems that have caused Platform issues when modifying Licences.
