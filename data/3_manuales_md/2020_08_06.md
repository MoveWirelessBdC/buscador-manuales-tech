# Release Version: 20.08.06\_\_stable\_\_0.22.0

### Release Date: 08/06/2020

## Updates

* The **Sending Centre** feature has been moved to the **Portal Management** section
* We have updated the drag-and-drop function in the Portal and Form editors, and now it should work even better than before
* We have added the following permissions to the Platform:

| Permission name | Description |
| --- | --- |
| sendingConfigurations | Allows the user to access the Sending Configuration |
