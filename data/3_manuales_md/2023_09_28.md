# Release Version: 23.09.28\_\_stable\_\_0.104.0

### Release Date: 28/09/2023

## Updates

### Feature Updates

* We have updated predefined Target Groups for Marketing Campaigns.

### GUI Updates

* We have added a new organisation property "rushHourPalette" that allows setting the colour palette of the Rush Hour chart.
* We have added a new organisation property "otherGender" that allows to enable and disable "Other" gender option from Forms and TargetGroups

### System Updates

* We have improved the security of uploading files.
