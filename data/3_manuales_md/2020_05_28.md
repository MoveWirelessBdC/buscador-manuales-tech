# Release Version: 20.05.28\_\_stable\_\_0.17.0

### Release Date: 05/28/2020

## New Features

* We have introduced the brand new Dashboard, which is now divided into two sections: **Users** and **Behaviour** and displays live insights about your users. To know more about it, go to the [What’s New in May 2020](../../whats_new/2020/05.html) chapter.

## Updates

* We have updated the **Roaming User Condition** that now allows you to differentiate Returning Users based on the type of login method which they have selected to log in to your WiFi.
* In all Conditions which use time intervals, you can now select intervals for minutes, hours, and days.
* We have also updated the Permissions Tree which now reflects the feature structure more accurately and, by that, allows you to easily select desired permissions.
* The **Custom Code** option in the Portal Editor has now a new **Code Editor**; it allows you to create and edit the custom code in a full window view, and use tags to personalise its content.
