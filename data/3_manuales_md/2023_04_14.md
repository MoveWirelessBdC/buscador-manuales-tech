# Release Version: 23.04.14\_\_stable\_\_0.92.0

### Release Date: 14/04/2023

## Updates

### Feature Updates

* Changes to report generation and scheduling to ensure users do not receive broken links. The whole process has been rewritten to improve performance and make error handling more robust
* Improved Report Mail content for Outlook, Windows Mail and iPhone Mail
* Improved Report Email user experience in dark mode

### GUI Updates

* Improved personal data access logging for searching in data tables - all search parameters are now logged
* Improved UI consistency (card components) in Platform
