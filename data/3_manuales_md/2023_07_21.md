# Release Version: 23.07.21\_\_stable\_\_0.99.0

### Release Date: 21/07/2023

## Updates

### Feature Updates

* We have updated licensing to apply to location computation as well as to Captive Portal login.

### System Updates

* We have improved the performance of obtaining additional token parameter in REST API V1 and made it consistent with the raw statistics token table column.
* We have optimised the performance of licence checking for captive portal processing.
* We are continuing further removal of code related to deprecated features, including the old loyalty editor.
