# Managing User Roles

User Roles are sets of permissions which you can assign to Platform Users to determine their scope of Platform access.

## Creating a User Role

1. Go to the **Licences and Roles** section in the main menu, and select the **User Roles** tile. Then, click the **+** button in the bottom right corner.

   ![user roles](images/user_roles/user_roles_0.png)

   ![user roles](images/user_roles/user_roles_1.png)
2. In the first step of the User Role Creator:

   * Into the **Name** field, enter the name of the User Role
   * In the **Description** field, type the description of the Role (optional).

   Then, click **Next** in the top right corner to continue to the next step.

   ![user roles](images/user_roles/user_roles_2.png)
3. In the second step, determine Platform access by selecting the desired permissions from the dropdown sections.

   ![user roles](images/user_roles/user_roles_3.png)

   ![user roles](images/user_roles/user_roles_4.png)
4. In the last step, you can review the User Role setup and preview the set of permissions by clicking the **Show List** button.

   To finish creating the Role, click **Save** in the top right corner.

   ![user roles](images/user_roles/user_roles_5.png)

## Editing a User Role

To modify a User Role’s scope of access, click the **More** option on the preferred User Role, and select **Edit** from the dropdown list.

Then, follow the steps from the **Creating a User Role** sub-chapter, and make the desired changes.

![user roles](images/user_roles/user_roles_15.png)

## Deleting a User Role

To delete a User Role, click the **More** option on the preferred User Role, and select **Delete** from the dropdown list.

![user roles](images/user_roles/user_roles_16.png)

If the User Role is assigned to Platform Users, in a popup-box, you can select another Role which will be assigned to them, or select the **Do Not Assign Another Role** option.

Note

Selecting the **Do Not Assign Another Role** option will leave the assigned Users with **no Platform access**.

![user roles](images/user_roles/user_roles_19.png)

## Previewing the User Role Usage

You can see the number of Platform Users assigned to a Role by checking the **Number of Assigned Users** label in the User Role’s panel. You can also preview the full list of assigned Users.

1. To preview the User Role usage, click the **More** option on the preferred User Role, and select **Preview Usage** from the dropdown list.

   ![user roles](images/user_roles/user_roles_17.png)
2. In the new window, you can see the list of Platform Users assigned to this Role. To go back, click the **<** icon in the top left corner.

   ![user roles](images/user_roles/user_roles_18.png)

## Previewing Permissions

User Role panels allow you to preview the full list of permissions selected for Roles.

To do this, click the **More** option on the desired Role panel, and select **Preview Permissions** from the dropdown list. Then, in the next window, you can see the full list of permissions selected for that Role.

![user roles](images/user_roles/user_roles_6.png)

![user roles](images/user_roles/user_roles_7.png)

## Comparing User Roles

You can compare sets of permissions selected for two different User Roles.

1. Choose a Role which you would like to compare with, and click the **More** option on its panel. Then, select **Compare Roles** from the dropdown list.

   ![user roles](images/user_roles/user_roles_13.png)
2. In the following window, click the **Add Role To Compare** button at the top of the blank column.

   ![user roles](images/user_roles/user_roles_8.png)
3. Next, in the pop-up box, you can select a Role from the already created ones, or import a Role from a CSV file.

   ![user roles](images/user_roles/user_roles_9.png)

   ![user roles](images/user_roles/user_roles_10.png)
4. You can now review the differences between the two User Roles.

   ![user roles](images/user_roles/user_roles_11.png)

To compare another Role, click the **More** option in the top right corner of the table, and select **Edit Selection** from the dropdown list. You can also export the differences to a CSV file by selecting the **Export differences to CSV** option.

![user roles](images/user_roles/user_roles_12.png)
