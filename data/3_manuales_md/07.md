# What’s New in July 2020

## Verifying Tokens in Loyalty Programs

The Loyalty Programs feature now allows you to verify token codes that users receive after having collected the designated number of stamps.

To carry out the Loyalty Programs token verification, go to the **User Enrollment > Loyalty Programs** section, click the **More** option of the desired Program, and from the dropdown menu, select **Verify Token Codes**.

![loyalty programs token verification](images/loyalty_programs_1.png)

Next, in the **Verify Token Code** window, enter the Loyalty Program token code into the **Token Code** field and click the **Verify** button.

![loyalty programs token verification](images/loyalty_programs_2.png)

## New Flow Diagram

We have introduced a new Flow Diagram in the Location Statistics, which gives you insights on how your users move between Areas at your Venue.

To access it, go to the **Reporting > Location** section, and select the **Areas** tile.

![flow diagram](images/flow_diagram.png)

## Permissions

We have added several new permissions to the platform. Be sure that you accordingly update them for all your platform users.

| Permission name | Description |
| --- | --- |
| navigationLandingPage | Allows a user to set Indoor Navigation as the landing page in a Page Flow |
| behaviourDashboard | Allows the user to access the Behaviour dashboard |
| displayDeviceMapper | Allows the user to display the Device Mapper table |
| displayRawMacs | Allows the user to display MAC addresses in the device Mapper table |
| locationStatistics | Allows the user to access the Location statistics |
| venueLocationStatistics | Allows the user to access the Venue statistics |
| flowTabLocationStatistics | Allows the user to view the Flow Diagram in the Location statistics |
