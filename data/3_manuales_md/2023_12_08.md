# Release Version: 23.12.08\_\_stable\_\_0.109.0

### Release Date: 08/12/2023

## New Features

* We have added two new endpoints to REST API for obtaining **defined areas** in venues and obtaining **passer-by and visitors timeline per area**.
* We have integrated the new device **Ruckus One** with Platform.

## Updates

### Feature Updates

* We have updated Access Points CSV import/export to reflect the current state of APs fields by adding three missing columns. Please note that previously exported CSVs need to have those three columns added to be properly parsed.

### GUI Updates

* We have continued adjustments to the appearance of specific editors and views to better align them with the overall design of the Platform. These changes are implemented in the following areas:
  + User Enrollment > User journey > Form
  + User Enrollment > User journey: Page Flow, Portal, Access Settings, Form
  + User Enrollment > User journey > Loyalty Programs
