# Release Version: 21.04.29\_\_stable\_\_0.41.0

### Release Date: 04/29/2021

## New Features

* We have introduced the new feature in the **Portal Management** section - the **Organisation Subtree Manager**. It allows you to reposition the selected Organisation in the Organisation Tree.  
  For more information on this feature, see our [What’s New in April 2021](../../whats_new/2021/04.html) release.
* We have integrated a new gate with the system to use for SMS messaging - the **Plasgate**.

## Updates

### GUI Updates

* For Data Transfer requests that have been rejected by the system, you can now preview what type of error it was by clicking the question mark icon next to the **Rejected** status.
* We have added a new login component you can use on captive portals that enables your users to log in automatically with the **WeChat** app.  
  Note that it is only partially supported. Currently, the authorisation process requires scanning a QR code shown on the user’s screen with the WeChat mobile app, which makes this login method suitable only for logging in on PCs or other devices.

### System Updates

* We have fixed spotted XSS vulnerabilities to ensure the system’s security.
* From now on, when a Sublicence gets suspended, the system automatically disconnects the currently logged-in ones.
* We have also added the following user permissions:

| Permission Name | Description |
| --- | --- |
| weChatComponent | Allows the user to add the WeChat login component to Portals |
| moveOrganizationSubtree | Allows the user to access the Organisation subtree manager in the Portal Management section |

## Resolved Issues

### System Fixes

* The Returning User Condition would not work correctly with the PMS login type. We have fixed this while also adding new Microsoft and ECB login types to the Condition.
* The Area Location statistics would have problems displaying data when overloaded. We have fixed it, and they should cause no future issues.
