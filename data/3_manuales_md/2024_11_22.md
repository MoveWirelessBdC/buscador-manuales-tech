# Release Version: 24.11.22\_\_stable\_\_0.134.0

### Release Date: 22/11/2024

## Updates

### Feature Updates

* We have updated our integration with [TP-Link Omada Controller](../../device_configuration/tp_link_controller.html)
  to support versions 5.3.1 and above, including the
  **Omada Cloud-Based Controller**. Existing devices had their type renamed to `TP-Link Controller 4.1.5 to 5.3.0`.

### GUI Updates

* We have updated and redesigned the mobile application for performing calibrations of the Location Engine.

### System updates

* We have modified the MongoDB configuration to prevent multiple instances from attempting to run on the same node.
