# Release Version: 24.09.27\_\_stable\_\_0.130.0

### Release Date: 27/09/2024

## New Features

* We have added a new payment method to the login via Payment Plans using the **Square** payment gateway. For proper
  operation of the Square payment gateway, the following properties must be configured in the organisation settings:

| Property name | Description |
| --- | --- |
| squareEnableIntegration | Enables the option to use Square (ver. 2024-08-21) as a payment method. |
| squareAccessToken | Defines the Access Token for the Square gateway. |
| squareEnvironment | Specifies the environment for the Square gateway: either production or sandbox. |
| squareLocationId | Defines the Location ID for the Square gateway. |

* We have added support for **domain verification** with Apple Pay. Domain customisation now allows uploading a
  domain-verification file which is checked by Apple during merchant registration.

## Updates

### System Updates

* We have enhanced the security of Captive Portal media management.

## Resolved Issues

### Feature Fixes

* We have fixed an issue where the most restrictive selected payment plan was applied, even when the user cancelled
  their first payment selection and chose to pay for a higher plan.

### System Fixes

* We have implemented a filter to ignore unrealistic data usage that exceeds 1Gbps.
* We have fixed the issue with statistics counting for the video component, where incomplete video views might not be
  tracked correctly.
