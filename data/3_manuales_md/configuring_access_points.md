# Configuring access points

Before gathering calibration data all access points need to be
specifically configured for that process. Perform the configuration according to
the appropriate manual. In case when there is no manual for your device, perform
the following procedure.

Warning

Without this step data gathered by the calibration will be incorrect and will significantly worsen the accuracy of the location.

To configure the device:

1. For both channel bands, 2.4 GHz and 5 GHz, set all access points to
   work on the same single Wi-Fi channel.

   Note

   Due to the country-specific radio regulations, working on all access points on a particular Wi-Fi channel can be impossible, even if explicitly set. For example, in the countries regulated by the FCC, due to weather radar systems avoidance regulations, for the channel band 5 GHz, it can be impossible to have all access points working on single channel 100 and above.
2. Create two independent SSIDs/networks: one for the channel band 2.4
   GHz and the second for the channel band 5 GHz. Calibration of each
   point must be performed for both channel bands consecutively using a
   device connected to the SSID dedicated to the specific channel band.
