# Release Version: 23.09.01\_\_stable\_\_0.102.0

### Release Date: 01/09/2023

## Updates

### Feature Updates

* We have implemented performance improvements for the additional data in white-labeling configuration, enabling the
  retrieval of this information from cache whenever possible.

### GUI Updates

* We have updated the appearance of charts in Statistics and Dashboard views.
  The cards containing each chart are now more consistent with cards in the rest of the Platform.

### System Updates

* We have completed the removal of deprecated captive portal features and all associated dependencies, resulting in:
  Simplified Maintenance, Enhanced Security, and Improved Troubleshooting.
* We have implemented library updates to enhance system security and mitigate potential vulnerabilities.
* We have limited the possibility of creating extremely short sessions lasting only a few seconds, ensuring that in such
  cases, processing is promptly moved to the next step.
* We have moved property defining new/returning timespan to appropriate property group.

## Resolved Issues

### Feature Fixes

* We have fixed a bug that could lead to media resources removal from the database when modifying its configuration on
  the saved portal.
