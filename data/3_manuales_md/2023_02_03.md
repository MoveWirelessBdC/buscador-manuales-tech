# Release Version: 23.02.03\_\_stable\_\_0.87.0

### Release Date: 03/02/2023

## Updates

### GUI Updates

* The MAC addresses in the raw data and dashboard tables are blurred for users lacking personal data access permission. The export of blurred columns to CSV is improved. Filtering by blurred columns is not possible
* A new permission, locationDeviceIdentifiers, is now required to view the MAC address and device name on the Device Mapper
* The user now requires the locationDeviceIdentifiers permission to access the Named Devices view
* Without the locationDeviceIdentifiers permission, the user cannot create or edit geofencing with the Devices Triggered set to "selected”
* The appearance of dialog windows throughout the entire application has been updated to have a more consistent look
* The security of the Organisation card and Domain Customization panel has been improved by hiding organisation names that are not accessible

### System Updates

* The permission displayRawMacs has been replaced with locationDeviceIdentifiers, providing the user with access to end device identifiers

## Resolved Issues

### Feature Updates

* The personal data access logs are now displayed in the Activity Stream view

### System Fixes

* The performance of confirming the email address through the link sent in the email login method has been improved
