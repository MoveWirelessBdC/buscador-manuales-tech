# Release Version: 24.05.24\_\_stable\_\_0.121.0

### Release Date: 24/05/2024

## New Features

* We have introduced the new **Session Push API**, which sends accounting data to an external server at the start and
  end of each session. This feature enables clients to integrate more easily with external providers.
* We have added the option to select **month** granularity for statistics charts.

## Resolved Issues

### Feature Fixes

* We have fixed the calculation of the first data point for weekly granularity statistics, which could incorrectly
  display zeroes.
* We have fixed a bug that caused errors when saving a Location-based campaign under certain delivery settings.

### GUI Fixes

* We have fixed an issue in Portal Management > Structure with keyboard navigation inside the Advanced search field.
  It's now possible to navigate inside the panel using the Tab key, which previously closed when the search field lost
  focus.
