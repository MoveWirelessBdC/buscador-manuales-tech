# Configuring the Account User Conditions

The **Account User** conditions enable you to differentiate those users who log in with user accounts from those who do not.

1. Add the Condition node. To learn how to do this, read the [Adding a Condition Node](../adding_condition.html) chapter.
2. On the **Condition Editor** page, select the **Account User** option. Then, in the upper right corner, click **Next**.

   ![internet access node creating](../../images/adding_nodes/condition_node_account_user_1.png)
3. In the pop-up box, define the Account user by designating when they should log in an additional time in order to confirm system registration. Click **Save** to confirm.

   ![internet access node creating](../../images/adding_nodes/condition_node_account_user_2.png)
