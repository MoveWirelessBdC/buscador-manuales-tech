# What’s New in December 2020

## Topping Data Transfer Up for Sublicences

We have continued introducing our last month’s top-up option to other Platform features, and from now on, **Administrators** can top up Sublicences as well.

To top up a Sublicence’s data transfer, click the **More** option in the top right corner of the desired Sublicence panel, and select **Shop Top-Ups** from the dropdown menu. Then, click the **+** button in the bottom right corner, and specify the top-up details in the pop-up box.

**Note:** The topped-up data is derived from the data transfer of a Licence Package from which the Sublicence is distributed. If this Licence Package uses up or distributes all of its data transfer, it is impossible to top up any Sublicence derived from it.

## Data Transfer Packages

In the upper bar of the **Licences** feature, you can now find a new tab - **Data Transfers**. It allows you to create and manage Data Transfer Packages for your Organisation which can later be distributed to Sublicences as additional data transfers.

To create a new Data Transfer Package, select the desired Organisation from the Organisation Tree on the left. Then, click the **+** button in the bottom right corner to enter the Data Transfer Package Creator.

![data transfer packages](images/12/data_transfer_packages.png)

## Permissions

We have added new permissions to the Platform. Be sure that you accordingly update them for your Platform users.

| Permission Name | Description |
| --- | --- |
| callAuthenticationCustomDisplayedNumber | Allows the user to customise the phone number displayed on the Portal in the Call Authentication component |
| licenceDataRequestReceive | Allows the user to access received requests in the Licence Manager |
| licenceDataRequestSend | Allows the user to access sent requests in the Licence Manager |
| licenceDataPackageRequest | Allows the user to request additional Data Transfer for Sublicences |
