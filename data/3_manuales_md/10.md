# What’s New in October 2020

## Brand New Licences

We have introduced the long-awaited update to the **Licences** feature which is now visually consistent with the rest of the Platform. We have also reviewed and redesigned the licencing mechanism, so it’s more user-friendly and allows you to manage your Licences more efficiently.

The new **Licences** allow you to create **Licence Packages** which contain Access Points that can be further distributed among your clients as **Sublicences**. It also provides a smart overview of your Licences with a quick view on AP capacity and time left for them to expire.

You can also set up email notifications on Licences, such as expiry, removal, or updates, and manage their sending details.

To learn how to manage Licences, go to the **User Guide > Licences and Roles** section.

## Importing User Accounts from a CSV File

You can now upload User Accounts to the Platform in one bulk instead of creating them one by one by importing them from a CSV file.

To do this, go to the **User Accounts** feature, click the **+** button in the bottom right corner, and select the **Upload from CSV file** option in the popup-box.

![user account csv](images/10/user_acc_csv_1.png)

![user account csv](images/10/user_acc_csv_2.png)

## Printing User Accounts Details

Additionally, you can now print User Account details in the form of tokens and customise their look according to your preferences. To do this, select the **Display Account Print View** from the **More** option’s dropdown menu.

You should note that to enable this option, you must set up the `allowWifiUserAccountPasswordRetrieval` property which determines how User Account passwords are saved in the Platform.

**Note:** Customising the print view requires basic knowledge of HTML and CSS.

## Data Top-Up

The **User Accounts** feature now allows you to **top data transfer up** for User Accounts.

To do this, click the **More** option on the desired user, and select **Show Top-Ups** from the dropdown list. In the new window, click the **+** button in the bottom right corner, and specify the quota and validity time in the pop-up-box.

![data transfer top-up](images/10/data_top_up_2.png)

## Permissions

We have added new permissions to the Platform. Be sure that you accordingly update them for your Platform users.

| Permission name | Description |
| --- | --- |
| topUpUserAccountTransferLimit | Allows the user to top up data transfer for User Accounts |
| sublicenceWrite | Allows a user to create a Sublicence |
| licencePackageWrite | Allows a user to create a Licence Package |
| sublicenceDelete | Allows a user to delete a Sublicence |
| licencePackageDelete | Allows a user to delete a Licence Package |
| areaLocationStatistics | Allows the user to access the Area statistics |
| licenceCustomPlanSelection | Allows the user to select a custom Plan for Licences |
| licencePackageRead | Allows the user to access Licence Packages |
| sublicenceRead | Allows the user to access Sublicences |
| userTemplates | Allows the user to customise content and formats of the User Account messages |
| licenceTemplates | Allows the user to customise content and formats of Licence messages |
| callAuthentication | Allows the user to add Call Authentication components to Portals |
