# Release Version: 24.07.05\_\_stable\_\_0.124.0

### Release Date: 05/07/2024

## New Features

* We have added the possibility that allows the user to delete roaming user data for specific Page Flow. This function is available with new permission **deleteFlowLoginData** and is placed as a new option in the context menu for every Page Flow.

## Updates

### Feature Updates

* We have eliminated additional HTTP redirects for Ruijie Cloud and UniFi Network devices.

### System Updates

* We have enhanced the overall ecosystem by implementing updates, improving performance and security, and ensuring better maintainability and stability across various components.
