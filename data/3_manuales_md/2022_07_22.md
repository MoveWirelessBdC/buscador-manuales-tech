# Release Version: 22.07.22\_\_stable\_\_0.73.0

### Release Date: 07/22/2022

## New Features

## Updates

* We have **migrated** old licence permissions to the new **Licence view**. Users who had access to the old **Licence view** will now be able to use only the new **Licence panel**.
* **Time** type notifications have been added to the **WiFiUserAccount** notifications settings. **WiFi** users can now be informed appropriately that their transfer will **expire**.

### Feature Updates

* In the **Organisation editor** we have added the ability to set additional options (**Currency**, **Country Code**, **Locale**, **Platform Name**, **Account Holder**) which until now were only available to be set in the **Properties Management** view.

### GUI Updates

* We have changed the **colour** of values in the **key-value** lists.
