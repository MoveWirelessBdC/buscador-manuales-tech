# Topping-Up a Licence (for Representatives)

If a Licence uses up all of its dedicated data transfer, it is possible to increase it by topping it up. As a rule, this can be executed by Representatives or other users, provided they have appropriate permission to do so.

## Creating a Top-Up

1. In the **Licence Manager**, select the desired Organisation from the left menu, and choose a Licence which you would like to top up. Then, click the **More** option on the Licence’s panel, and select **Show Top-Ups** option from the dropdown menu.

   ![sublicence top-up](images/licences/topup_1.png)
2. In the new window, click the **+** button in the bottom right corner to add a top-up to the Licence.

   ![sublicence top-up](images/licences/topup_2.png)
3. In the pop-up box, select how you would like to top up the data transfer from the **Data Transfer** toggle button:

   * The **Custom** option allows you to specify the amount of data according to your preferences.  
     To determine it, enter the desired value in the **Data** field, and select the appropriate data unit from the dropdown list.

   ![sublicence top-up](images/licences/topup_3.png)

   * The **Predefined** option enables you to top up data from the previously created Data Transfer Packages.  
     To use a predefined Package, select the desired one from the **Data Transfer Package** dropdown list. Below the list, you can preview the Package details which may include the data transfer limit and/or the Package price.

   ![sublicence top-up](images/licences/topup_5.png)

   When you have specified the top-up details, click the **Top Up** button in the bottom right corner of the pop-up box to finish.
4. The top-up is now created and the data transfer of this Licence has been increased.

   ![sublicence top-up](images/licences/topup_4.png)

## Editing and Deleting a Top-Up

It is impossible to edit and delete a top-up in the Platform. To modify it, you should contact your Administrator for assistance.
