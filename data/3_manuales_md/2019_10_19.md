# Release Version: 19.10.22-0.1.1

### Release Date: 10/19/2019

## New Features

* We have added the **Export CSV** function to the **Devices** section. It enables the export of a CSV file which now contains the list of all the devices defined in the organisation.
* The **Add Display** feature has been added to the **Portal Editor**. It allows the configuration of the video advertisement, and the time limit in which the site cannot be skipped.

## Updates

* The **Main Menu** and the **Navigation top bar** have been updated.
* We have also updated the statistic descriptions in the **Engagement Statistics** diagrams.

## Bug Fixes

* When a **Form** is filled incorrectly by a user and does not pass the validation process via the Submit Button, the user is now directed to the appropriate field which must be changed.
