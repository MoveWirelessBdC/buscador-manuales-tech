# Release Version: 20.01.24\_\_stable\_\_0.8.0

### Release Date: 01/24/2020

## New Features

* We have introduced new features in the **Token Group** section:
  + The **Token Group counter** has been added to the Token Groups tiles for an easy preview of the Token codes current usage,
  + We have implemented the **Token Group Details** list which comprises a detailed list of the Token codes which this Group contains,
  + In the Token Groups creator, you may now set up **Network parameters** which apply to all Tokens in a given Token Group.
* From now on, you can also set up the **Network parameters** for each user in the **User Accounts** section,
* We have also expanded the search options in the **Structure** section with the **Advanced Search** which allows you to filter results by specific categories,
* We have added the following permissions to the platform:

| Permission Name | Description |
| --- | --- |
| organizationTreeAdvancedSearch | Allow a user to access the advanced search in the organisation tree |
| rawDataUserSessionsTableSearch | Allow a user to access the search option in the User Sessions table in the Raw Data statistics |
| accessMethodsNetworkParameters | Allow a user to set up the Network Parameters when creating or editing the Access Methods |
|  | allows a user to access the test API |
| radiusVendorSpecificAttributes | Allow user to access and configure the RADIUS attributes in the Network Parameters |
| displayInheritedFlows | Enable the display of inherited Page Flows in the Page Flow Manager |
| displayInheritedNetworks | Enable the display of inherited Networks in the Network Manager |
| displayInheritedPortals | Enable the display of inherited Portals in the Portal Manager |
| displayInheritedQuestionnaires | Enable the display of inherited Forms in the Form Manager |

## Updates

* The **Customise Landing Page** option can now be also accessed from the **Own** section in the Portal Manager,
* We have expanded the search option in the **RawData Statistics** which now can be filtered by the Device ID.

## Bug Fixes

* We have fixed the issue which appeared in the **Licences** section, and the **Used Licences** section now displays correct values.
