# Report Manager

The **Report Manager** allows you to create daily, weekly or monthly reports that can be delivered to designated recipients. It is a useful solution to regularly notify the latest statistics to people who may be interested in them.

## Creating a Report

1. Go to the **Reporting** section and select the **Report Manager**. In the bottom right corner, click **+** to create a new Report.

   ![report manager](images/report_manager/create_report_1.png)
2. In the **Settings** step, type the name of the Report, and from the toggle button, select the frequency with which you would like to receive it: **Monthly**, **Weekly**, or **Daily**.

   Then, select the **Time Zone** in which your organisation is located. Afterwards, click **Next** in the top right corner to proceed to the next step.

   ![report manager](images/report_manager/create_report_2.png)
3. In the **Email Message** step, you can format a default email message which will be delivered to the designated recipients. From the **Report Language** dropdown list, select the language in which the statistics will be generated. Then, type the subject of the report message in the **Email Title** field, and format the Report message in the **Email Text** editor.

   Note: You may also leave the default title and text of the message.

   ![report manager](images/report_manager/create_report_3.png)
4. In the **Sections** step, from the checkbox list, select the kind of statistics which you would like to generate. Click **Next** to confirm your choice and proceed further.

   ![report manager](images/report_manager/create_report_4.png)
5. In the **Report Delivery** step, you can add email addresses to which the report should be delivered. Type the address into the **Email Addresses of Receivers** field and click **+** to add it to the list.

   After you have finished adding the addresses, click **Next** in the top right corner to proceed further.

   ![report manager](images/report_manager/create_report_5a.png)

   ![report manager](images/report_manager/create_report_5b.png)
6. In the **Summary** step, you can preview the Report details before it is saved. If you need to make corrections to the Report's settings, click the **Back Arrow** in the top left corner to go back to the desired step. To finish the configuration process, click **Save** in the top right corner.

   ![report manager](images/report_manager/create_report_6.png)
7. The Report is now created.

   ![report manager](images/report_manager/create_report_7.png)

## Editing and Removing the Report

To edit or remove the Report from the list, click the **More** option of the designated report and select the appropriate action.

![report manager](images/report_manager/create_report_8.png)
