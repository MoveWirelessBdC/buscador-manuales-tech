# Release Version: 24.12.06\_\_stable\_\_0.135.0

### Release Date: 06/12/2024

## Updates

### Feature Updates

* We have added functionality to handle unregistered phone numbers during WhatsApp Business verification.

### GUI Updates

* We have added a [guide for configuring Cisco with Catalyst WC access points](../../device_configuration/cisco_catalyst.html).
* We have updated the list of devices in the help dialogue for Upload and Download data limits. The names in the list are now consistent with the device labels found in Portal Management > Structure > Devices.

### System Updates

* We have enhanced the security of database connections.
* We have updated Java to a newer Long-Term Support (LTS) release.
* We have improved the detection of DNS failures for installation monitoring.
