# Configuring FortyTwo Gateway

The **FortyTwo Gateway** is one of the servers used for sending SMS campaigns. For this gateway to work as expected, you must configure it in both systems: the **FortyTwo**, and **This** platform.

## Configuring FortyTwo Gateway on **FortyTwo Platform**

1. Go to the **Client Control Panel** and select the **SMS-MT** tab,
2. In the **Tokens** section, generate a token and **save it**, or **write it down** as you will need it during the configuration process.
3. Now, go to the **IM** tab.
4. In the **Tokens** section, generate another token and **save it**, or **write it down** as you will need it during the configuration process.

## Configuring FortyTwo Gateway on This Platform

1. Go to the **Portal Management > Properties** section, and continue to the **Sending Centre**.
2. In the **SMS Settings** section, click the **Pen** icon to edit the details.
3. From the **Gateway List**, select the **FortyTwo** gateway.
4. Into the **FortyTwo SMS Token** field, paste the token which you had generated on the FortyTwo platform. Then, click **Save** to finish the configuration process.
