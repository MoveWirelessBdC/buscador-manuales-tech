# Release Version: 20.10.15\_\_stable\_\_0.27.0

### Release Date: 10/15/2020

## New Features

* We have introduced the long-awaited update to the **Licences** feature which is now visually consistent with the rest of the Platform and provides a smart creation and overview of Licence Packages and Sublicences.
* Due to a close connection of User Roles with Licence Plans, we have moved the **Role Manager** to a new **Licences and Roles** section in the main menu.
* You can now upload User Accounts to the Platform in one bulk instead of creating them one by one by importing them from a CSV file.
* We have introduced a new **Call Authentication** Portal component which is integrated with the **Vonage** (formerly **Nexmo**) sending gate and allows you to create a two-step login flow where users would authenticate their internet access by calling a specific phone number.
* We have integrated the **SMPP 3.4** protocol with the Message Sender.
* We have enabled storing User Account password **unhashed** to allow you to print them on the User Account tokens.

## Updates

* You can now set up time zones offset from UTC by incomplete hours for Organisations.
* We have added the following permissions to the Platform:

| Permission name | Description |
| --- | --- |
| topUpUserAccountTransferLimit | Allows the user to top up data transfer for User Accounts |
| showRetrievableUserAccountPasswords | Allows the user to display passwords in the List of User Accounts table and to preview and print them on User Account tokens (requires the setup of the 'allowWifiUserAccountPasswordRetrieval' property which determines how User Account passwords are saved in the Platform) |
| sublicenceWrite | Allows a user to create a Sublicence |
| licencePackageWrite | Allows a user to create a Licence Package |
| sublicenceDelete | Allows a user to delete a Sublicence |
| licencePackageDelete | Allows a user to delete a Licence Package |
| areaLocationStatistics | Allows the user to access the Area statistics |
| licenceCustomPlanSelection | Allows the user to select a custom Plan for Licences |
| licencePackageRead | Allows the user to access Licence Packages |
| sublicenceRead | Allows the user to access Sublicences |
| userTemplates | Allows the user to customise content and formats of the User Account messages |
| licenceTemplates | Allows the user to customise content and formats of Licence messages |
| callAuthentication | Allows the user to add Call Authentication components to Portals |

## Bug Fixes

* The internal monitoring has been improved to faster detect potential database problems.
* We have revised our Location Engine and improved the MAC hashing performance.
* We have also modified the login level for the mosquitto platform component responsible for communicating with the Ruckus device.
* We have increased the sensitivity of monitoring detecting problems with the Platform availability.
* We have fixed the problem where the single Tokens table would not display when the Network used by single tokens has been deleted.
