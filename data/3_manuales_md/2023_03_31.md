# Release Version: 23.03.31\_\_stable\_\_0.91.0

### Release Date: 31/03/2023

## New Features

* Added acceptance frequency to **Service Documents**, you can now set a period after which a user will need to re accept the terms.

## Updates

### Feature Updates

* Reports are now sent using templates customised in the Sending Centre. Email customisation is no longer available in Report Manager.
* The ability to change the content of daily/weekly/monthly reports is now available in the Portal Management > Sending Centre > Email customisation.
* A navbar has been added to the report view - it displays the organisation's time zone and gives you the possibility to log out or go to the Platform.
* Now, when a user is unable to view a specific report, instead of the error page, they will see a dialog with possibility to logout or redirect to the main page.

### GUI Updates

* We have made a change to the report name length. The maximum character limit for report names is now 50 characters.
* We have removed the deprecated Token formatter

### System Updates

* Added mechanism for deleting Reports and their scheduled and delivered entities when deleting an organisation.
* Created dedicated permissions for Access Methods in REST API and used them in endpoints instead of UI ones.
* Message sender REST API is using new own permissions instead of using the ones for Organisation management.
