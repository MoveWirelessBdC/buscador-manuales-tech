# Release Version: 20.11.26\_\_stable\_\_0.30.0

### Release Date: 11/26/2020

## New Features

* We have added a new **Data Transfer** section to the Licence Package and Sublicence creators which allows you to configure data transfer limits that can be further distributed through Sublicences. You can also determine data reset intervals of those data limits with the **Data Reset** option.
* We have integrated the new **Omobio SMSC** gateway which allows you to send SMS messages to the designated recipients.

## Updates

### Feature Updates

* We have updated the **Tokens** feature with an option to set up the **Total Data Transfer** (for uploaded and downloaded data).

### System Updates

* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| totalDataTransferLimit | Allows the user to set the total data transfer (for uploaded and downloaded data) for Token Groups |
| licenceTransferLimit | Allows the user to set and modify the overall and periodic data transfer and its validity for Sublicences |

## Resolved Issues

### System Fixes

* We fixed the issue with the Location Campaigns where the system would not correctly display the count of SMS and email messages in the campaign statistics.
* We have added the new configuration for the sender number type that facilitates setting up the SMPP sender gate.
