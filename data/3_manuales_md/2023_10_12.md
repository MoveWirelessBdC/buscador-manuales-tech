# Release Version: 23.10.12\_\_stable\_\_0.105.0

### Release Date: 12/10/2023

## Updates

### GUI Updates

* We have separated Target Groups management from the Campaign creator, making it accessible in a dedicated view within the main menu under the Marketing section.
* We have improved the differentiation between own and inherited Target Groups in the Campaign creator.

### System Updates

* We have enhanced the process of extracting WiFiUserProfile data from the database for use in Campaigns.
* We have updated several third-party libraries to bolster system security and mitigate potential vulnerabilities.

## Resolved Issues

### GUI Fixes

* We have fixed the Target Groups selector in the Campaign creator to display accurate information regarding user behaviour and gender filters for each target group.
