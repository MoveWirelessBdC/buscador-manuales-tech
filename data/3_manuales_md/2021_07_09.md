# Release Version: 21.07.09\_\_stable\_\_0.46.0

### Release Date: 07/09/2021

## New Features

* We have added a statistical visualization to the area ranking map and an area ranking table in **Reporting > Location > Areas > Ranking**.
* In **Location statistics** we have added basic per area statistics for visitors and passers-by.
* We have added the possibility of choosing an area on the venue map and displaying the defined areas in the reporting module **Area** tab.

## Updates

### Feature Updates

* The order of displayed data in the **Reporting > Statistics > Raw Data > User Session** table has been changed so that the newest sessions (by the start date) are the first in the order.
* We have removed duplicate menu entries in old versions of **“User Agreements”** and **“Access Methods”**.
* We have added additional system checks to **Organization subtree management** which verifies whether the **WiFi User Accounts** created in the transferred subtree will still have access to the networks that were defined in their configuration.
* We have added a new field to **Meraki’s** configuration which allows you to set the domain to which a **CoA** request will be sent.

## Resolved Issues

### System Fixes

* We have fixed the issue with changing states of top-up requests which have already been processed when the sub-license was removed.
