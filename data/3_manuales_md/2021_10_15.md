# Release Version: 21.10.15\_\_stable\_\_0.53.0

### Release Date: 10/15/2021

## New Features

* Users can now export selected devices in the devices table by going to **Portal management** > **Structure** > **Devices**.
* The possibility of editing settings of **Flows/Portals/Forms** from the respective manager has been added without the need to go through the editor.
* We have added the possibility to **remember devices** by using a verified phone number in the **Phone Verification Component** which will **not** send SMSs to verify the device. Also the default configuration in the organisation can be changed by setting the appropriate property.
* A new **Two-step email verification login** method has been added to the portal. The verification of the email must be done from a **different device** which has access to the internet. The **emailVerificationComponent** permission is required to add components to the portal.

## Updates

* We have changed the **password reset** method in which we no longer send a temporary password. After entering the email address, the user receives a message with a **link**, in which a new password can be set. The previous two steps of resetting the password have been replaced with one. Users **must update** their email when using the **custom email content**.
* A service for assigning domains to the functionality has been added. We have started dividing the functionality of domains into two, for **Captive Portal** and for the **Administration Portal**. You can now generate links for reports and password resets for installations with different **administrative domains** and **hotspots**.

### System Updates

* We have added the following permissions to the Platform:

| Permission Name | Description |
| --- | --- |
| phoneInputRememberDeviceConfiguration | Allows the user to access the Remember Device Configuration in the Phone Number component |
| emailVerificationComponent | Allows the user to add Email Verification components to Portals |

## Resolved Issues

### System Fixes

* We have fixed an error on the **Dashboard** where the **Heatmap** size for very small venues was incorrect..
* We have added **Login Information** for **MAC** based logins for **Benu**.
