# Release Version: 23.08.04\_\_stable\_\_0.100.0

### Release Date: 04/08/2023

## New Features

* We have added an extra step "Charts palette" to the Domain customisation -> Theme customisation, allowing for customisation of each colour of the charts palette to match your brand identity and preferences. The feature is available for clients with the white-label version of the product.

## Updates

### Feature Updates

* We have added a new property: heatmapScale. Now users have the flexibility to choose the function applied to heatmap values. The available options include logarithmic, linear, square root, and cubic root scales for the heatmap. This enhancement allows for a more versatile and customizable representation of data in the heatmap visualisation.

### System Updates

* We have removed integration with the Meru device.
* As part of our ongoing efforts to improve the platform's performance and maintain up-to-date standards, we have removed several deprecated features, including:

  + The outdated Tokens system
  + Outdated Pages, Loyalty, and Bonus functionalities
  + Outdated User accounts
  + Handling of Old Landing Pages

## Resolved Issues

### GUI Fixes

* We have fixed the search function in Portal Management > Structure > Devices to improve filtering by device type. The search phrase is now matched against the type as shown in the UI instead of its internal representation.
