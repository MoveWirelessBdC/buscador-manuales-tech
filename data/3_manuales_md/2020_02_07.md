# Release Version: 20.02.07\_\_stable\_\_0.9.0

### Release Date: 02/07/2020

## New Features

* The Statistics section now includes the **Marketing Data** tab where you can find statistics on marketing agreements and categories selected by Wi-Fi users.
* The Domain Customisation section has been expanded by the **GDPR** category which allows you to customise the GDPR Panel by selecting settings of a specific organisation.
* We have added the following permissions to the platform:

| Permission Name | Description |
| --- | --- |
| testApiAccess | Allow a user to access the test API |
| marketingDataSection | Allow a user to access the Marketing Data tab in the Statistics section. |
| marketingAgreementsSubSection | Allow a user to access the What do you know about marketing agreements? section in the Marketing Data. |
| marketingCategorySubSection | Allows a user to access the Which marketing category is selected most often? section in the Marketing Data. |
| editGdprTarget | allows a user to view the GDPR section in the Sending Centre Properties |

## Updates

* We have modified the filters in the **WiFi Users** table in the Raw Data statistics, and improved filtering the results.
