# Release Version: 25.06.20\_\_stable\_\_0.149.0

### Release Date: 20/06/2025

## New Features

* We have developed a new internal tool that significantly accelerates integration with new access points. This enhancement reduces integration time and improves overall efficiency as we expand our supported device ecosystem.

## Updates

### GUI Updates

* We have changed how the date-time values are displayed in Tokens and User Accounts views.

### System Updates

* We have improved the performance and scalability of the background session reset operation by introducing batch processing and caching, which reduce database load and increase system stability.
* We have upgraded the MongoDB database to a newer version.
