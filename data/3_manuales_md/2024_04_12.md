# Release Version: 24.03.29\_\_stable\_\_0.117.0 & 24.04.12\_\_stable\_\_0.118.0

### Release Date: 12/04/2024

Note: This release includes both the 24.03.29\_\_stable\_\_0.117.0 and 24.04.12\_\_stable\_\_0.118.0 release versions.

## New Features

* We have implemented OTP (One-Time Password) authentication for WiFi access through WhatsApp Business via **TapTalk**
  integration.  
  For proper operation:
  + enable this function in the Phone number component (Advanced section) in the Captive Portal editor
  + set the following properties in the organisation:

    | Property name | Description |
    | --- | --- |
    | tapTalkWhatsAppApiKey | Secret used for TapTalk Business API authorization. |
    | tapTalkWhatsAppApiUrl | API url used for TapTalk WhatsApp Business. By default is set to: `https://onetalk-api.taptalk.io/api/integration/v1/inbox/send_templated_message_whatsappba` |
    | tapTalkWhatsAppChannelId | ChannelID used for TapTalk WhatsApp Business. |
    | tapTalkWhatsAppLanguageCode | Language used for TapTalk WhatsApp Business. |
    | tapTalkWhatsAppTemplateName | Template name used for TapTalk WhatsApp Business. |

## Updates

### Feature Updates

* We have introduced changes to the **Marketing Campaigns** feature. These include changes to the appearance of the
  campaign list and a redesign of the campaign editor to make it easier to use.  
  For more information, please visit our What’s
  New [April 2024 Update: A New Horizon in Digital Marketing](../../whats_new/2024/04.html) chapter.

### GUI Updates

* We have improved the **Troubleshooting** table by improving issue type description and recommended solution steps.

### System Updates

* We have updated the logging storage and processing system.
* In response to a discovered bug in the Meraki platform, we have enhanced our software to better manage the incorrect
  Meraki TLV (Type-Length-Value) encoding of attributes in RADIUS packets, while providing enhanced validation.

## Resolved Issues

### GUI Fixes

* We have resolved the issue where the popup failed to close after navigating away from the relevant view.
