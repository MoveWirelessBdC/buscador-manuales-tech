# Release Version: 19.11.15\_\_stable\_\_0.4.0

### Release Date: 11/15/2019

## New Features

* We have introduced the **Components Look** feature which enables the Portal theming. You can now set up the general settings (colour, background, spacing, and borders) of the components used across your Portals.
* In the **GDPR Panel**, we have added the **LinkedIn Login** option.

## Updates

* The **Export** option in the **Platform Management > Devices** section has been updated.
* We have also revised the **User Enrollment** section in the **User Guide**.

## Bug Fixes

* We have resolved several problems which have been occurring across the platform when refreshing pages and editors.
