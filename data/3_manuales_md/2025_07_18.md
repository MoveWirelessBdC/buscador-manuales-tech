# Release Version: 25.07.18\_\_stable\_\_0.151.0

### Release Date: 18/07/2025

## Updates

### Feature Updates

* We have enhanced authentication handling for Ruijie Cloud devices by implementing a default redirection URL when authentication fails.
* We have updated the format of links sent in user account confirmation and password recovery emails to be more resilient to email client behaviour.
* We have added OAuth2 support to X (Twitter) social media configuration, so user log-in can now be set up with either OAuth 1 or OAuth 2.

## Resolved Issues

### System Fixes

* We have fixed incorrect handling of missing HTTP responses, which in some cases could lead to unexpected errors.
