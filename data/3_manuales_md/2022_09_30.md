# Release Version: 22.09.30\_\_stable\_\_0.78.0

### Release Date: 30/09/2022

## New Features

* We have added a new **Date and Time** condition to the **User journey** configuration. It enables selecting the date ranges within which the user will be directed along a specific path to the next stage of the flow.

## Updates

* We have updated the integration with the **Pepwave Access Points** so that when redirecting users to the captive portal, SSIDs are identified correctly.

### Feature Updates

* We have introduced updates in the behaviour of social media end user logins in case of lack of social media configuration. Such cases are now detected and logged in the troubleshooting section, and a platform error screen is shown to the end user.
* We have added the possibility to set the amount of characters in tokens when creating token groups via GUI and API. The available range of characters is between 5 and 30.
* We have removed the old licence engine and all the related views, data, permissions, styles, translation keys and code.

### System Updates

* We have improved the security of cookies used to identify sessions and users.
* We have fixed a bug reported by the Security tests that consisted in disclosing to the user information about the names of libraries utilised by the system. Messages that may contain such information have been removed from the response returned to the user.

### Feature Fixes

* We have fixed listing of available Social Media **primary** configurations while configuring GDPR in **Portal Management > Domain customisation**.
