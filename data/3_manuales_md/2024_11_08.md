# Release Version: 24.11.08\_\_stable\_\_0.133.0

### Release Date: 08/11/2024

## New Features

* We have added a new type of device **Alcatel-Lucent Enterprise Stellar** to work with our Platform.

## Updates

### GUI Updates

* We have improved the consistency of the “Add” button display in manager views when search mode is active.
* We have updated documentation concerning [supported devices listing](../../device_configuration/supported_devices.html).
* We have revised the [Advanced Properties](../../user_guide/portal_management/adding_advanced_properties.html) section in
  the User Guide.

### System Updates

* We have enhanced the overall ecosystem by implementing updates, improving performance and security, and ensuring
  better maintainability and stability across various components.
* We have improved the security of internal communication between our services.
* We have optimised the path calculations process in venue navigation.
