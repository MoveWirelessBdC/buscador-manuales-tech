# Release Version: 22.12.22\_\_stable\_\_0.84.0 & 23.01.05\_\_stable\_\_0.85.0

### Release Date: 05/01/2023

Note: This release includes both the 22.12.22\_\_stable\_\_0.84.0 and 23.01.05\_\_stable\_\_0.85.0 release versions.

## New Features

* The number of emails per hour per email address is now limited (5 by default). This limit is to prevent abuse of the password reset feature
* Add a custom validator feature for short answer questions (forms)

## Updates

### Feature Updates

* Migrated old user accounts to the new model

### GUI Updates

* Add the possibility to set a start date for perpetual licence and for perpetual licence package
* Add anonymization and blurring to personal data in the user accounts view for users without the required permissions
* Add anonymization and blurring to personal data in the marketing campaigns sent details

## Resolved Issues

### GUI Fixes

* The Country of Origin chart in Reporting > Statistics now waits for the list of country names to load before displaying data, instead of sometimes showing the country code or "undefined" if the list did not load in time
* The Preferences tab in Account settings now works with multiple browser tabs

### System Fixes

* Handle login, logout, and view as user features when the platform is opened on multiple browser tabs
* Fix the issue with downloading CSV files in email reports not working if the user is not logged into the platform
* Fix questionnaireIds external resources in copied portals
* Token groups and single tokens no longer show detailed information about usages in organisations inaccessible to the user
* Users now need permissions to see MAC addresses (and personal information in general) in order to see IDs of devices which used a given token
* Fixed the validation missing bug on the backend when creating reports
