# Release Version: 21.05.27\_\_stable\_\_0.43.0

### Release Date: 05/27/2021

## Updates

### GUI Updates

* We have added the timezone display to the **Account Validity** column in the **List of User Accounts** table to ensure data accuracy.
* From now on, the Platform’s URL address in the **Account Registered** type of email in the **Email Customisation** feature is **not** required when you modify email formatting.

### System Updates

* We have developed the Licences activity stream that stores the history of all operations carried out in Licences, such as creation, modification and removal. Access to this feature is restricted to our support only, so please contact them if you need to review the history for your Licences.
* We have added additional system checks to the **Organisation Subtree Manager** so that moving Organisations is even less risky than it has ever been.
* The **Organisation Subtree Manager** now returns multiple errors instead of only the first encountered that may impact the moved Organisation.

## Resolved Issues

### GUI Fixes

* On some smartphones, you could have noticed the Portal background displaying incorrectly. This has been caused by an inadequate adjustment to screen dimensions. We have fixed it so that it adjusts to every device.
* We have also fixed minor bugs that caused the Text component in the Portal editor to malfunction.

### System Fixes

* The **Venue** feature would not work correctly with the **Nokia** type devices. We have fixed it, and it should not cause any more problems.
* The Marketing Campaigns **feature would not send out messages to** Own\*\* target groups (created in an Organisation or inherited from a parent Organisation) for the whole age range and when the user’s age was undefined. This has been resolved and now works as expected.
* The **Report Manager** would generate incorrect URL addresses by disregarding the white-labelling and the Organisation’s domain. We have fixed it, and it should now cause no issues.
* Some SMS gateways used TLS 1.0, which is deprecated, and therefore would fail to work. We have updated it, and the gateways now use TLS 1.2 or TLS 1.3 for a proper connection.
