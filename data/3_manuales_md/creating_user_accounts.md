# Managing a User Account

## Before Your Start

Go to the **User Enrollment > Access Methods** section, and click the **User Accounts** tile. The first time you enter this section, you may see the below information in the main window.

![create user account](../images/user_account/PP_01.png)

This information means that to create and manage User Accounts, you must first set up the appropriate property for your Organisation. To learn how to do this, contact your administrator.

After you have configured the property, again, go to the **User Enrollment > Access Methods** section, and click the **User Accounts** tile.

## Creating a User Account

1. Go to the **User Enrollment** > **Access Methods** section and click the **User Accounts** option. Then, click **+** in the bottom right corner.

   ![create user account](../images/user_account/PP_02.png)
2. In the pop-up box, select how you would like to create the User Account:

   * The **Create New** option allows you to create a new account in the Platform interface.
   * The **Upload CSV File** option allows you to import a previously prepared CSV file that contains all the account information. It also enables you to import several User Accounts in a bulk.

   This instruction continues with the in-Platform account creation.

   ![create user account](../images/user_account/user_accounts_2a.png)

   ![create user account](../images/user_account/user_accounts_2b.png)
3. In the **Create User Account** window, provide details of the new User Account.

   In the first **Settings** step, you can choose the **Registration Type** which determines the type of login credentials that will enable the user to log in to your network:

   * the **Username** option allows you to set up the user’s login and password,
   * the **Email** option can be used when you have been provided the user’s email address, and it also allows you to set up the password.
   * the **Phone Number** option can be used when you have been provided the user’s phone number, and it also allows you to set up the password.

   In the **Username** option:

   * Into the **Username** field, enter the username.
   * Into the **Password** field, enter the User Account password.
   * Into the **Contact Email** field, enter the email address by which the user could be notified about data usage.

   ![create user account](../images/user_account/PP_03.png)

   In the **Email** option:

   * Into the **Contact Email** field, enter the email address by which the user could be notified about data usage. This email will also serve as the Account’s username.
   * Into the **Password** field, enter the User Account password.

   ![create user account](../images/user_account/PP_04.png)

   In the **Phone Number** option:

   * Into the **Phone Number** field, enter the phone number by which the user could be notified about data usage.
   * Into the **Password** field, enter the User Account password.
   * Into the **Contact Email** field, enter the email address by which the user could be notified about data usage.

   ![create user account](../images/user_account/PP_05.png)
   After you have finished choosing the Registration Type and setting up the login credentials, click **Next** in the top right corner to proceed to the next step.
4. In the **Access Limits** step, you can determine the network which the user will be able to access, set up the User Account validity, and specify devices with which they can connect to your WiFi.

   In the **Network Limit** section, you can choose either the **No Limit**, or the **Select Network** option:

   * The **No Limit** option allows the user to access any network that you provide,
   * The **Select Network** option allows you to determine the network which the user will be able to access.

   The **User Account Validity** section allows you to determine for how long the user can use their account to log in to your network. To set it up, turn the switch **ON** and in the date picker, designate the expiration date after which the user will no longer be able to log in to your network using this account.

   Note

   If the switch is turned **OFF**, the user can use your WiFi for an unlimited period.

   In the **Devices Limit** section, you can specify which devices can be used by the user to log in to your network.

   * The **None** option allows the user to use any device to log in to your network.
   * The **List** option enables you to specify which devices can be used to log in to your network, by providing their MAC addresses. To add a MAC address to the list, enter it into the **MAC Addresses** field and click the **+** icon next to it.

   After you have selected the desired options, click **Next** to continue.

   ![create user account](../images/user_account/user_accounts_4a.png)

   ![create user account](../images/user_account/user_accounts_4b.png)
5. In the **Data Transfer** step, you can set up the reset interval in which the Account’s data package would be renewed, and enable notifications on data usage.

   To set up the data reset, turn the **Data Transfer Reset** switch **ON**, Then, in the below fields:

   * From the **Reset Interval** dropdown list, select the desired interval, and in the **Day** field, specify the day of the week or month on which the data transfer should be reset.
   * In the **Periodic Data Transfer** section, enter the desired amount of data and select their size from the dropdown list.

   To enable data usage notifications, turn the **Notifications** switch **ON**.

   Note

   To enable notifications for the **Username** type of User Account, you must provide the user's email address in the **Contact Email** field in step 1.

   After you have completed this step, click **Next** to proceed further.

   ![create user account](../images/user_account/PP_06.png)
6. In the **Network Parameters** step, you can limit individual network parameters for the user, or leave the default ones.

   To edit the desired parameter, turn the appropriate switch **ON**, enter the proper value into the input field, and select the suitable option from the dropdown list.

   After you have finished specifying the network limitations, click **Next** to continue to the last step.

   ![create user account](../images/user_account/user_accounts_6.png)
7. In the **Summary**, you can review the User Account settings. In case you needed to amend any of them, click the **Back Arrow** in the top left corner, go back to the desired step, and edit the appropriate option.

   To finish setting up the user account, click **Save** in the top right corner of the window.

   ![create user account](../images/user_account/PP_07.png)
8. The User Account is now created.

   ![create user account](../images/user_account/PP_08.png)

## Editing a User Account

Go to the **User Enrollment** > **Access Methods** > **User Accounts** section. Then, on the **List of User Accounts**, find the account which you would like to edit. Once you have located it, click the **More** option at the right end of the account row, and select **Edit** from the dropdown menu.

After you have edited the account settings, click **Save** in the top right corner to confirm the changes.

![create user account](../images/user_account/PP_09.png)

## Deleting a User Account

1. Go to the **User Enrollment** > **Access Methods** > **User Accounts** section. Then, on the **List of User Accounts**, find the account which you would like to delete. Once you have located it, click the **More** option at the right end of the account row, and select **Delete** from the dropdown menu.

   ![create user account](../images/user_account/PP_10.png)
2. In the pop-up box, confirm deleting the Account by typing its name in the input field, and click the confirmation button.

   ![create user account](../images/user_account/user_accounts_10.png)

## Managing the List of User Accounts

### Searching and Filtering User Accounts

You can search through the List of User Accounts by using the search field located in the upper right side of the table. You can also filter the search by the account details.

![create user account](../images/user_account/PP_11.png)

## Exporting User Accounts into a CSV File

You can export all User Accounts into a CSV file. To do this, click the **More** option next to the search field and select the **Export to CSV** option from the dropdown menu. Then, save the downloaded CSV file on your computer.

![create user account](../images/user_account/PP_12.png)
