# Changing a Portal’s Default Language

The default language (English, Polish or Russian) must be selected during the creation process. The chosen language will be the default language of the Portal, and of all untranslated texts in the Portal’s additional language versions.

You can change the default language into one of two others depending on which one was initially selected.

1. In the lower right corner of the **Portal Editor**, click the **General Configuration** icon.

   ![portal language version](../images/portal/portal_language_versions_1.png)
2. In the menu on the left, select the **Language Settings** option.

   ![portal language version](../images/portal/portal_language_versions_2.png)
3. To change the default language, you must first add the new language to the Portal. Then, select it from the **Add Language Versions** list.

   ![change portal default language](../images/portal/change_default_language_1.png)

   ![change portal default language](../images/portal/change_default_language_2.png)
4. Now, select the new language from the **Selected Default Language** list.

   ![change portal default language](../images/portal/change_default_language_3.png)
5. The default language has now been changed and the current one is indicated with the padlock icon. You can also select it in the Portal workspace preview list.

   ![change portal default language](../images/portal/change_default_language_4.png)
6. Create a new Page Flow. To learn how to create a Page Flow, read the [Creating a Portal](creating_portal.html) chapter.
