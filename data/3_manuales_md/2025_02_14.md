# Release Version: 25.02.14\_\_stable\_\_0.140.0

### Release Date: 14/02/2025

## Updates

### Feature Updates

* We have simplified the CSV User Accounts import format by reducing it to basic columns and have enhanced security by
  adding permission checks for personal data.

### GUI Updates

* We have updated the "Country of Origin" charts in Reporting > Statistics. The horizontal bar chart showing the top
  five countries has been replaced with a table to improve legibility.

### System Updates

* We have improved security of internal authentication and authorisation service.
* We have updated the build process for our platform's UI, which should reduce the amount of code initially sent to the
  browser.

## Resolved Issues

### GUI Fixes

* We have fixed the display of the Data Limit form in the Network parameters editor step.

### System Fixes

* We have fixed the process of restoring editor states after a page refresh, ensuring only the current editor state is
  now being restored.
