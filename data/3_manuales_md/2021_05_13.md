# Release Version: 21.05.13\_\_stable\_\_0.42.0

### Release Date: 05/13/2021

## New Features

* We have integrated yet another type of device with the Platform - the **D-Link** access point.

## Updates

### System Updates

* We have modified the way Token codes are generated so that they do not contain characters that may be hard to distinguish, such as `I`, `l`, `1`, or `o`, `O` and `0`.
* In Organisation Subtree Manager, we have blocked transferring Organisations that use Loyalty Programs or Payment Plans, which will not be available after the Organisation has been moved.
* We have enabled the CoA Disconnect Message support for the Ubiquiti devices.
* We have also added the CoA port customisation for devices that already support CoA requests.

## Resolved Issues

### GUI Fixes

* The autofill function in captive portals would work incorrectly and make it difficult for users to log in to WiFi. We have fixed it, and it should not disturb user flow anymore.
* We have also fixed incorrect highlighting of modified Licences.

### System Fixes

* On captive portals, when the user skipped a form that contained a dropdown list, they would receive an error page. We fixed it and forms now work correctly.
* The user's internet connection could not get automatically renewed after they were prematurely disconnected from an access point if a downgrade from `HTTPS` to `HTTP` was needed to communicate with the device. We have improved how flows are processed so that downgrading does not affect the end user.
* User Accounts with no data limits would get disconnected from the WiFi as if they exceeded their data limit, even if data limiting was disabled for the whole Organisation. This has occurred in Organisations with configured CoA for devices and should no longer happen.
* For username types of User Accounts with defined contact email addresses which have not been stored in `WiFiUserProfile`, password reset would fail to work. We have fixed it, and it should now work smoothly.
