# Adding and Deleting Multiple Portal Language Versions

When creating a Portal, select its default language: English, Polish, or Russian. You can also add additional language versions to the Portal.

## Adding a Portal Language Version

1. In the lower right corner of the **Portal Editor**, click the **General Configuration** icon.

   ![portal language version](../images/portal/portal_language_versions_1.png)
2. In the menu on the left, select the **Language Settings** option.

   ![portal language version](../images/portal/portal_language_versions_2.png)
3. From the **Add Language Versions** list, select the language which you would like to add to the Portal.

   ![portal language version](../images/portal/portal_language_versions_3.png)

   ![portal language version](../images/portal/portal_language_versions_4.png)

   ![portal language version](../images/portal/portal_language_versions_5.png)
4. You can preview the language versions in the **Portal Editor** workspace.

   Note: Remember to translate all the texts which you have used in the Portal for each additional language.

   ![portal language version](../images/portal/portal_language_versions_6.png)

   **Note: Translate all the texts for all of the added language versions**

## Deleting a Language Version from the Portal

1. In the lower right corner of the **Portal Editor**, click the **General Configuration** icon.

   ![portal language version](../images/portal/portal_language_versions_1.png)
2. In the menu on the left, select the **Language Settings** option.

   ![portal language version](../images/portal/portal_language_versions_2.png)
3. To remove a specific language version, select the **X** option next to the version.

   Note: You cannot delete the default language, which is marked with a padlock.

   ![portal language version](../images/portal/portal_language_versions_7.png)
