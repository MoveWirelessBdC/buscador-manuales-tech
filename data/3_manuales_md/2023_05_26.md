# Release Version: 23.05.12\_\_stable\_\_0.94.0 & 23.05.26\_\_stable\_\_0.95.0

### Release Date: 26/05/2023

Note: This release includes both the 23.05.12\_\_stable\_\_0.94.0 and 23.05.26\_\_stable\_\_0.95.0 release versions.

## New Features

* We have added a new security feature that temporarily suspends user sessions if there are excessive login attempts within a minute. Information about blocked sessions can be found in the troubleshooting panel.

## Updates

### GUI Updates

* We have replaced status badges with tags to make GUI more consistent
* We have updated show/hide buttons in all password fields across the application to have a consistent look and behaviour

### System Updates

* We have improved time difference calculation in licence time interval validation

As a part of removing the legacy versions of Captive Portal processing:

* We have removed the "virtual login" feature. This was an equivalent of *Preview Page Flow* for old Captive Portals, no longer functional after removal of legacy Networks
* We have removed Access Time feature and its related accessTimeEnabled property
* We have removed access to old Questionnaire editor

## Resolved Issues

### System Fixes

* We have improved validation in POST/accessMethods/userAccounts API endpoint. In the case of any errors in the example values now response code is 400 with explanation instead of 500.
