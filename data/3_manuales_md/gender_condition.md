# Configuring the Gender Conditions

The **Gender Conditions** enable the creation of different paths based on the users’ gender.

You should note that this Condition works properly only if the gender data is collected in the login process. You can collect it by using the **Forms** feature in the captive portal. To learn how to use Forms, read the [Creating a Form](../../forms/creating_questionnaire.html) chapter.

1. Add the Condition Node. To learn how to do this, read the [Adding a Condition Node](../adding_condition.html) chapter.
2. In the **Condition Editor**, select **Gender**. Then, in the upper right corner, click **Next**.
