# Release Version: 20.04.02\_\_stable\_\_0.13.0

### Release Date: 04/02/2020

## New Features

* We have added new functions to the Role creator; from now on, you can copy roles, import and export permission from the desired role, and preview permissions which are included in roles. You can also display the list of users who have been assigned to a specific role.
* We have introduced the new **Login Page** section in the **Domain Customisation**, which enables you to set up the redirect button and platform languages which users can choose while logging in to the Platform.
* In the **User Profile**, you can now determine which delimiter should be generated in the exported CSV files.
* We have introduced the new **Troubleshooting** section in the **User Enrollment** which allows you to track all the configuration issues between Access Points and Flows.
* We have added the following permissions:

| Permission Name | Description |
| --- | --- |
| locationStatistics | Allows a user to access the Behaviour section in the Dashboard |
| accountUserCondition | Allows a user to add the Account User Condition to the Flow |
| ageCondition | Allows a user to add the Age Condition to the Flow |
| apiMpesaCondition | Allows a user to add the API M-PESA Condition to the Flow |
| genderCondition | Allows a user to add the Gender Condition to the Flow |
| localeCondition | Allows a user to add the Locale Condition to the Flow |
| operatingSystemCondition | Allows a user to add the Operating System Condition to the Flow |
| propertyCondition | Allows a user to add the Property Condition to the Flow |
| roamingUserCondition | Allows a user to add the Roaming User Condition to the Flow |
| serviceDocumentCondition | Allows a user to add the Service Document Condition to the Flow |
| socialLoginCondition | Allows a user to add the Social Login User Condition to the Flow |
| timeOfDayCondition | Allows a user to add the Time of Day Condition to the Flow |
| verifiedUserCondition | Allows a user to add the Verified User Condition to the Flow |
| smsDispatchNode | Allows a user to add the SMS Dispatch node to the Flow |
| emailDispatchNode | Allows a user to add the Email Dispatch node to the Flow |
| showDevicesLimitConfigurationUserAccount | Allows a user to set limits for devices in User Accounts |
| troubleshooting | Allows a user to access the Troubleshooting section |

## Updates

* We have updated the **User Accounts** with the **User Account Validity Period** option which allows you to determine for how long a user can use your network.
* From now on, you can export your Token Groups into the CSV file, and print Token codes from the **Token List**.
