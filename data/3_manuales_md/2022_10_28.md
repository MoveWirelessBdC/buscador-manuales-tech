# Release Version: 22.10.28\_\_stable\_\_0.80.0

### Release Date: 28/10/2022

## Updates

### GUI Updates

* We have removed the old **Service documents**, **Marketing consents**, **Communication channels** and **Versions** GUI views.
* We have removed the old version of the **Ad server** feature.
* We have added extensive descriptions for all the **advanced organisation properties** which are available in **Portal management > Properties > Advanced** by clicking on the eye icon.

### System Updates

* We have introduced security fixes for handling cookies: we have removed the JavaScript access to authorization tokens by disabling the token from session storage and by adding a `httpOnly` flag to the cookies.

## Resolved Issues

### GUI Fixes

* We have fixed the range selector for the **Rush Hours** chart in **Reporting > Statistics > Wi-Fi Users** so that the values outside the selected range are now greyed out.
* We have fixed the issue with moving calibration points in **Location Management > Management > Calibration** so that any changes to their location are saved permanently.
