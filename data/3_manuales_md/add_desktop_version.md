# Adding a Portal Desktop Version

The Portal Editor’s workspace enables you to design a Portal for mobile screens, but you can also adjust it for desktop settings.

1. In the lower right corner of the Portal Editor, click the **Desktop Mode Customisation** icon.

   ![desktop version](../images/portal/desktop_version_1.png)
2. To change the number of columns featured in the desktop mode, select one of the two buttons above the Portal Editor’s workspace. You can switch to either a two- or three-column layout.

   ![desktop version](../images/portal/desktop_version_2.png)
3. You can customise the desktop version by changing the width of the columns.

   ![desktop version](../images/portal/desktop_version_3.png)
4. To return to the mobile version, click the **Mobile Mode Customisation** icon.

   ![desktop version](../images/portal/desktop_version_4.png)

## Disconnecting Desktop or Mobile Version

If you would like a specific component to be displayed only on mobile or desktop, you can set it up in the Portal workspace.

1. In the **Portal Editor workspace**, click the **More** option in the desired component. Then, depending on which mode you are editing the Portal in, select either the **Remove From Desktop Version** or **Remove From Mobile Version** option.

   ![desktop version](../images/portal/disconnect_desktop_version.png)

   ![mobile version](../images/portal/disconnect_mobile_version.png)
2. You can preview the changes in the **Preview** mode.

   ![desktop version](../images/portal/disconnect_preview_desktop.png)

   ![desktop version](../images/portal/disconnect_preview_mobile.png)
