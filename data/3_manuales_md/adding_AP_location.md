# Adding access points

Adding access points is a crucial step for location. The placement
of access points is used for calculating customer position.

Note

All changes made in this window are applied within 10 minutes from their submission.

To add access points:

1. Open the **Devices manager** panel:

   * In the **Venue map** panel, in the top left corner, click ![back button](images/back.png) and then click the **Devices manager** tile.
   * Go to **Location → Management** and click the **Devices manager** tile.
2. In the **Devices manager** pane, in the right upper corner, select the floor to
   which you want to add an access point.

   Tip

   Use the **Hide/Show grid** button to hide or show the measuring grid.
3. To add:

   * One access point:

     + Click ![Add device](images/image156.png) and place the marker point on the plan.
     + Into the pop-up window, type a MAC address of the given access point and click **Save**.
   * Many access points:

     + Click ![Add many devices](images/image157.png) and place all the access points on the plan.
     + To stop adding access points, click **Close** next to the icon.

     ![close access points addition](images/image158.png)

     + Click the placed access point and type a MAC address
       of the access point into the **MAC** field. Click **Save**. Repeat this step for all the access points.

     ![add MAC address](images/image159.png)

   Warning

   A blue marker point means that an access point lacks a MAC address. When you change the floor or go to the next procedure, all access points without a MAC address won't be saved.
4. To look for an access point, click ![search icon](images/image160.png) and type a MAC
   address of the searched access point. You have to be on the same
   floor as the searched access point.

**What to do next**:  
- If you want to gather statistics not only about the whole venue, but also about its smaller parts, then [divide the venue into areas](creating_areas.html).  
- If you want to proceed with the configuration of location, then you need to perform calibration. Start with [creating calibration](calibration/creating_calibration.html).  
- If you don't want to go through the process of calibration and you need only very rough data, then [configure the engine](calibration/configuring_engine_location.html).
