# Release Version: 25.06.06\_\_stable\_\_0.148.0

### Release Date: 06/06/2025

## New Features

* We have integrated two new types of Access Points - **Gemtek** and **Arcadyan BR440 CPE** - which can now be added to the Platform.

## Updates

### Feature Updates

* We have improved the internal login analysis feature by adding entries for CoA events.
* We have improved the user interface of internal, test-only tool for manual session disconnection.
* We have made several improvements to the forgotten-password flow in the captive portal, the most significant being the fix to front-end validation for new passwords.

### System Updates

* We have extended detection to include additional manufacturers’ captive-portal detection URLs, so end-users are no longer redirected to empty pages after logging in.
* We have improved the initial set-up of MQTT client used for device localization.

## Resolved Issues

### GUI Fixes

* We have fixed the creation date display in the campaign list view. The date in **Marketing** > **Campaigns** now respects the currently selected time zone.
