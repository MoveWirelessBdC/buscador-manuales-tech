# Release Version: 21.03.04\_\_stable\_\_0.37.0

### Release Date: 03/04/2021

## New Features

* We have added a new generic endpoint that enables counting on camera devices. This allows for integration with new types of devices, such as **Gigabyte** cameras.

## Updates

### GUI Updates

* We have modified the Licences editor so that you could manage email and Platform notifications for Client and Representative separately. As a result, notification settings now open in the full window view instead of pop-up boxes.

### Feature Updates

* You can now print data transfer reset setup along with other User Account details.
* We have changed the default setup of the Email Sending Configuration in the **Sending Centre**, and all the messaging is now **enabled** by default.
* From now on, when creating a new Platform user, you can choose to send them a welcome message. You can customise its display by changing the font and colours and personalise it with dedicated tags in the **Email Customisation** section.

  Keep in mind that all email notifications in the **Email Customisation** section use the `platformName` property. Make sure it is set up appropriately for your Organisation.

  **Note:** For security reasons, you should ensure that the new Platform user’s email address is correct to avoid sending it to an unauthorised address.

## Resolved Issues

### GUI Fixes

* When Licence Packages and Sublicences expired, their panels would not get disabled but display negative values for their validity. It has been fixed and now works as expected.

### System Fixes

* The validity time of a User Account would incorrectly change in some situations. This has been resolved, and the Account validity now works correctly.
* When exporting a Ruckus-type venue and importing it to another server, its credentials would not get carried along with it. We have resolved this issue, so no such problems should happen again.
