# Release Version: 21.09.03\_\_stable\_\_0.50.0

### Release Date: 09/03/2021

## Updates

### System Updates

* We have updated **Mongo** database to **version 4.4**.
* We have updated the **Facebook API** to version 11.0, and the basic permission required to take information from accounts.

## Resolved Issues

### System Fixes

* Improved transfer distribution for user accounts by time, including always assigning overused transfer to some pool (unless there is no pool in that time range).
* We have improved the **creating** and **editing** of the **Payment Plan** section by saving changes after reloading the site and also added header translations in Polish (PL), English (EN),Spanish (ES), French (FR) and Russian (RU).
* We have fixed the issue which did not allow creating a portal using the following languages: Indonesian (ID), Hebrew (HE) and Yiddish (YI).
* We have fixed the issue with the **Restore password** feature not working properly and added a new tag **$password\_reset\_path** which is the **$password\_reset\_link** tag without the domain.
