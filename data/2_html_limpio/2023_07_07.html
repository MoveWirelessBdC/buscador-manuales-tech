Release Version: 23.07.07__stable__0.98.0

Release Date: 07/07/2023

Updates

System Updates

  • We are continuing the process of removing old deprecated features connected with previous Captive Portal engine
  • We have improved CoA logs and debug capabilities
  • We have optimised internal statistics computation process communication to reduce database load.

Resolved Issues

GUI Fixes

  • We have fixed an issue in the Portal Editor where removing a layout component would cause the drag-and-drop mechanism to stop working

System Fixes

  • We have fixed applying limits of WiFiUserAccount when a user registers on Portal and adds top-up
  • We have fixed an issue with "Show unformatted text" Action button and Phone number inputs. Returning from the page shown by the action button would fail to restore contents of any phone number inputs on the portal, resulting in an error page being shown to the user.
