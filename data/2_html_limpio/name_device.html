Naming devices

This function enables you to assign a name to a device with a particular MAC address and then quickly find it in the venue using the Device mapper.

To name a device:

  1. Go to Location management → Management and then click the Named devices tile.

  2. Click Name device.

  3. In the Add a device name window:

    • Into the Device's MAC address field, type a MAC address of a device.

    • Into the Device name field, assign a name to this MAC address.

  4. Click Add. The entry was added to the list. Now, in the MAC tracker feature, you can search the device by typing either the MAC address or the added name into the search field.
