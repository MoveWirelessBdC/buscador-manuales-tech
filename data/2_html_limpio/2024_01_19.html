New Features

  • We have added a new payment method for the login via Payment plans - Klix payment gateway. For the proper operation of the Klix payment gateway, the following properties must be set in the organisation:
Property name Description
klixEnableIntegration Enables the option of Klix payment in the Payment Method component.
klixApiHost Defines the url for the Klix gateway.
klixBrandId Brand id for the Klix gateway.
klixSecretKey Defines the secret for the Klix gateway.
klixDefaultLanguage Defines the default language for the Klix gateway website.
klixAvailablePaymentMethods Defines the available payments methods for the Klix gateway. No value means default methods defined in Klix app. All available methods: https://portal.klix.app/api/#/Purchases/purchases_create
