Release Version: 23.04.28__stable__0.93.0

Release Date: 28/04/2023

Updates

GUI Updates

  • We have added recommended dimensions for each image in Portal Management > Domain customisation. Following these suggestions should reduce the chance that the uploaded images will be deformed or illegible when they appear in the UI.

  • We have added anonymization and blurring for MAC addresses in Token's preview (for both Token groups and Single tokens). Access to this data is now logged in the Activity stream.

System Updates

We are continuing the process of shutting down the legacy versions of Captive Portal processing, leaving the User journey features as the only implementation. In this release we have removed the following features:

  • Old type of Networks incompatible with Page flows

  • Auto login settings

  • External access to old Captive Portals by URL

  • Timed free login method

  • Ability to create, edit and copy the old captive portals

Resolved Issues

GUI Fixes

  • We have made several improvements to help prevent Cross Site Scripting attacks
