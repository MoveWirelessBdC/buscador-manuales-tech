Creating a Custom Licence Plan

Licence Plans are User Roles assigned to a Licence Package. They are sets of permissions which determine the scope of Platform access.

When creating a Licence Package, you can choose from the Predefined Plans, or create a Custom Plan according to your preferences.

To create a Custom Plan:

  1. When creating a Licence Package, select the Custom option from the Plan toggle button. Then, click the Select Plan button to choose the User Role which you would like to assign to this Licence Package as a Licence Plan.

  2. Now, in the User Roles window, you can choose an available User Role, or create a new one by clicking + in the bottom right corner.

    Note

    User Roles marked with the Licence Plan badge are the Roles which have been assigned to Licence Packages as Plans.

  3. To create a new User Role and assign it to the Licence Package, click the + button in the bottom right corner. Then, in the first step of the User Role creator:

    • Into the Name field, enter the name of the User Role
    • In the Description field, type the description of the Role (optional).

    Then, click Next in the top right corner to continue to the next step.

  4. In the second step, determine Platform access by selecting the desired permissions from the dropdown sections.

  5. In the last step, you can review the User Role setup and preview the set of permissions by clicking the Show List button.

    To finish creating the Role, click Save in the top right corner.

  6. Now, select the newly created User Role in the User Roles window, and click Select in the top right corner to add it to the Licence Package as a Custom Plan.

  7. The Custom Plan has now been assigned to the Licence Package. You can now continue creating the Licence Package.
