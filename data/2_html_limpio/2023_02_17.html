Release Version: 23.02.17__stable__0.88.0

Release Date: 17/02/2023

Updates

Feature Updates

  • Added possibility to export and import flows with custom landing page set

GUI Updates

  • The security of the list views in Platform has been improved by hiding organisation names that are not accessible

  • Table advanced search dialog allows only to filter by fields which user is allowed to access. Search is hidden when no search boxes are enabled

System Updates

  • The "Implicit Flow" view was removed after being made obsolete by the "Preview Page Flow" feature

  • Disabled support for deprecated Captive Portal processing

  • Removed access to deprecated Captive Portals mechanism and its components. Each user and role received access to current corresponding features that they had before

  • Added new permissions enabling control of access to Wi-Fi Users’ photos and dates of birth on Dashboard, Raw Data statistics and Forms results

  • Added support for Zyxel Nebula Cloud

  • Audit logs for personal data access improved

  • We have added the following permissions to the Platform:

Permission Name Description
statisticsDateOfBirthAccess Allows the user to display Users’ dates of birth
statisticsPhotoAccess Allows the user to display Users’ photos

Resolved Issues

GUI Fixes

  • Fixed bug in Base data transfer table. For Licences with a specified validity time and periodic data transfer reset, the first billing period was doubled in the table during its duration
