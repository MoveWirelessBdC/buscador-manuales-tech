Release Version: 22.03.04__stable__0.63.0

Release Date: 03/04/2022

Updates

  • We have implemented a migration which changes the LandingPageNavigation identifier in SSID from Venue name to Venue ID.
  • We have added input normalisation both for APEX and PMS standard implementation and deleted validation for small/capital letters and white spaces.

Resolved Issues

System Fixes

  • We have implemented a few small changes to the Venue creator such as name and icon changes.
  • We have added a confirmation dialog before deleting a Venue from the organisation as well as notifications after the Venue was successfully created, edited or deleted. When returning from the Venue editor, the currently selected organisation in Venues is now preserved.
  • We have removed all users of permissions manageImplicitNetworks and all Implicit networks.
  • The Role editor has been fixed so that when copying a Role, the name which was entered is not lost when going back into the preview before saving.
  • After cancelling the Discard changes pop-up, the current URL is not duplicated and shows the same dialogue as when using the back button.
