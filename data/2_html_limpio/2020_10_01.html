Release Version: 20.10.01__stable__0.26.0

Release Date: 10/01/2020

New Features

  • We have implemented a new Email Customisation feature which enables you to customise the email notifications generated by the Platform at specific circumstances.
  • You can now print User Account details in the form of a token.
  • We have added a new Login Methods over Time chart to the Wi-Fi Users statistics.

Updates

  • We have updated the process of adding Venues, so it is consistent with the rest of the Platform, and moved it to the Portal Management > Structure section.
  • You can now manage the access to the dashboards with the access Users dashboard and access Behaviour dashboard permissions. The first one allows you to access the Users dashboard, and the second enables access to the Behaviour dashboard.
  • We have moved the existing password reset email messages to the Email Customisation feature, which required changing the source of email templates. These have been updated visually, resulting in removing the restorePasswordEmailContentTemplate and restorePasswordEmailSubjectTemplatemodified properties.

Bug Fixes

  • We have fixed the problem where the Average connection duration counter would display negative values in the Users dashboard.
  • We have also resolved the issue with the Users Now table that showed different numbers than those registered by the system.
  • We have fixed the problem where the data transfer would be distributed incorrectly during sessions.
