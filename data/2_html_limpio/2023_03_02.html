Release Version: 23.03.02__stable__0.89.0

Release Date: 02/03/2023

Updates

Feature Updates

  • We made changes in the report editor:
    • A general refresh of the editor's appearance
    • Removed the time zone selection from the first step of report editor
    • Replaced adding report recipients by email with selection from the platform's user list
    • Viewing the reports now requires logging in to the Platform. Unless already logged in, users will now be automatically directed to the login page after clicking the link to the report received via email
    • Made report accessible only by its recipient
  • Added check to prevent the move of an organisation with a report after which one of the recipients would no longer have access to it

GUI Updates

  • Reset dialog backdrop to default material value

System Updates

  • Delete old captive portal related cookies data for Linkyfi Flow requests
  • Previous REST API for managing WiFi User Accounts was marked as deprecated. Please migrate to current version under Access Methods group name
  • Added support for Huawei AirEngine controller managed access points.

Resolved Issues

Feature Updates

  • The personal data access via REST API are now available in the Activity Stream view.
