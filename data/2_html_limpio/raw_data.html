Raw Data Statistics

The Raw Data Statistics provide you with non-aggregated data about individual users and their sessions. To view them, go to the Reporting > Statistics section and select Raw Data from the upper pane.

Note: The table loading time depends on several factors, including selected date range, amount of data which must be aggregated, or your internet connection speed. The average display time should be less than 5 min, and should not exceed 10 min. In case it is higher, try reloading the page, or change the date range. If the data is still not displayed, contact your administrator.

To ensure the best system performance, part of the data is stored in probabilistic structures, therefore the expected error in relation to real data can be up to 0.1%.

These data can be displayed for a specified time frame which you can define by selecting the time range in the Time Picker at the top of the Statistics panel. Then, click Show to confirm your selection.

The What Do You Know About Wi-Fi Users? Section

WiFi Users

The WiFi Users table presents the user data which have been collected during the login process, and provides detailed information about your WiFi user profiles. These data include, among others, the Device ID, the User name, the Email address, the Phone number and Gender, as well as the Organisation where users gained internet access.

You should note that not all of the fields may be filled in the table as the collection of data is determined by gathering methods. It may depend on the login path used by your organisation, the types of components collecting the data, or the login method chosen by the user to gain Internet access.

You can search through these data by a specified phrase and filter them by Devices, Emails, Phones, or Organisations. To do this, type the exact phrase into the Search field in the top right corner of the table.and choose at least one filter.

The What Do You Know About User Sessions? Section

User Sessions

The User Sessions table displays detailed information on your users’ sessions. It includes the precise start and end date and time of a user visit, the device ID, the IP Address, as well as the IDs of Access Points with which the user's device has connected. It also shows the data download and upload speed, the login method chosen by the user to gain internet access, the type of their device and its operating system, the organisation in which the session occurred, and how long it lasted.

Relation Between the Tables

The data from these two tables supplement themselves by Device ID. This means you can select a Device ID in the WiFi Users table, and search through the User Sessions table to find details about this device's activity. You should receive comprehensive information about all sessions initiated by this device in a given period.

Table View

You can manage the table view by selecting the columns which you would like to display. To do this, click the More option in the top right corner of the desired table, and select Edit Table View. Then, in the pop-up box, turn the switches OFF next to the names of the columns which you would like to hide.

Exporting the data

You can export the data to a CSV file. To do this, click the More option in the top right corner of the desired table and choose Export to CSV.
