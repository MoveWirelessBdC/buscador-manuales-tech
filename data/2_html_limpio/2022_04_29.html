Release Version: 22.04.29__stable__0.67.0

Release Date: 22/29/2022

New Features

Updates

  • We have updated the PayPal API to version 2 for API Payments in Flows.
  • New endpoints based on organisation ID (instead of venue name) have been added to API for Historical location. Old endpoints have been labeled as Deprecated.
  • The panic button and geofencing processing is now tied to the current area mapping mechanism used in the current location statistics. Previous processing of location data for the old statistics has been further disabled.

Resolved Issues

System Fixes

  • We have fixed linguistic inconsistencies in Dashboard > Behaviour and Reporting > Location > Venue.
  • We have fixed the HTTP error codes for several GUI endpoints where we previously incorrectly responded with 500 Internal Server Error, when in fact it was a bad request.
  • We have fixed an issue that during an unsuccessful attempt to update the license statuses another attempt is made after 30s.
