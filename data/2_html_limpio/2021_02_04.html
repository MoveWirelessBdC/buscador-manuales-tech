Release Version: 21.02.04__stable__0.35.0

Release Date: 02/04/2021

New Features

  • We have integrated a new Huawei access point with our Localisation Engine.

Updates

Feature Updates

  • You can now add tags to customise messages created in Message nodes in the Page Flow.

  • For the Twilio SMS gateway, we have added a sender caption that allows you to determine the sender’s name in the Originator field (e.g. The Platform).

  • Token codes with specified data limits can now be shared between multiple devices.

System Updates

  • We have added the following permissions to the Platform:
Permission Name Description
userAccountTemplates Allows the user to customise content and formats of the User Account messages
setDataTransferNotifications Allows the user to set and edit Data Transfer notifications
  • We have also modified the below permission:
Permission Name Description
userTemplates Allows the user to customise content and formats of the Platform Users messages

Resolved Issues

Feature Fixes

  • Some of the data in the Location statistics would not display for certain granularities and time zones. This has been caused by an incorrect synchronisation between time zones and Venues. We have fixed it, and the Location data now display correctly.

System Fixes

  • Some WiFi Users data would not display in the Raw Data Statistics due to the incorrect storing of the lastactivity logs in the WifiUserProfiles. This has been fixed, and the data displays as expected.

  • We have modified the IP address mapping of the Ruckus vSZ access point for situations when the controller sends its IP address from a private network to user devices. As a result, data is now sent to a proper controller.
