What’s New in March 2020

Role Creator

The new Role Manager allows you to set up new user roles which contain the permissions of your preference. You can then assign these roles to desired users in your organisation and, by that, manage their platform access.

Microsoft Login

We have added the Microsoft Login option to the Portal Editor, which allows your users to log in to your network with their Microsoft accounts.

To set it up, open the desired Portal editor, go to the Social Media section, and drag the Microsoft tile into the Portal workspace.

Permissions

We have added several new permissions to the platform. Be sure that you accordingly update them for all your platform users.

Permission Name Description
viewOrganizationId Allows a user to view the Organisation ID in the Organisation details
ruckusCustomSip Allows a user to set up and preview the Ruckus Custom SIP
ruckusCustomSipMap Allows a user to set up and preview the Ruckus Custom SIP Map
idleTimeoutNetworkParameter Allows a user to set up the Idle Timeout in the Network Parameters
userAgreementsMenu Allows a user to display the new User Agreements menu
roleManagerRead Allows a user to access the Role Manager in read-only mode
roleManagerWrite Allows a user to create, edit and remove roles in the Role Manager. (Note: Requires the 'roleManagerRead' permission to access the Role Manager)
microsoftComponent Allows a user to set up the Microsoft account login method on a Portal
setAccessibleNetworkUserAccount Allows a user to set up the Accessible Network in the User Account
setValidityTimeUserAccount Allows a user to set up the Validity Period of the User Account
sizingCustomizationSection Allows a user to access the Sizing section in the Portal editor
