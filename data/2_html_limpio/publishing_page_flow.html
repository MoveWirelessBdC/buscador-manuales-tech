Publishing a Page Flow

Note: To publish a Page Flow, you should attach it to Access Settings. If you want to learn how to create Access Settings, read the Creating Access Settings chapter.

  1. In the Network Manager, click the More option. Then, from the dropdown list, select Attach Flow.

  2. On the Page Flows Available page, select the option which you would like to attach to the Access Settings. In the upper right corner, click Select to confirm.

  3. The Page Flow is now published. You can find it in the Network Manager, in the Attached Flow section.
