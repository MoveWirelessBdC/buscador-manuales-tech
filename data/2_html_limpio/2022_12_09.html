Release Version: 22.12.09__stable__0.83.0

Release Date: 09/12/2022

New Features

  • We have added the option to export Page Flows in the tile menu. You may also export multiple selected Page Flows at once. The exported file will be in the .zip format.

  • In User Enrollment > User journey > Page Flow we have implemented a new feature that allows the user to import a previously exported Page Flow from the Platform. We have also added the ability to rename imported entities - including single renaming as well as adding a prefix to all names.

  • In Portal manager, we have added the possibility to search for portals by their names. The 'search by name' function works similarly to its counterpart in the Page Flow manager.

Updates

Feature Updates

  • We have added support for CSV-related properties (csvDefaultDelimiter, csvExportCharset, csvExportDateTimeFormat, csvExportPreference, csvLocale) when exporting CSV files in Reporting > Statistics > Raw Data, Licences and Roles > User roles > Compare roles and Licences and Roles > Licence manager > Show details > Licence distribution.

GUI Updates

  • We have changed the Polish translation for Free Login which now is rendered as Dostęp swobodny.

  • We have removed the Export option from the tile menu when no import option is available. This applies to Loyalty Programs, Service Document/Marketing Categories/Communication Channel and Payment Plans.

  • We have updated the permission tree structure for the Page Flow manager.

System Updates

  • We have standardised the File upload component so that its looks and behaviour are consistent throughout the Platform.

Resolved Issues

GUI Fixes

  • We have fixed an error occurring in the Two-Factor Authentication mechanism which might have temporarily blocked the possibility to log in to the Platform by the user.
