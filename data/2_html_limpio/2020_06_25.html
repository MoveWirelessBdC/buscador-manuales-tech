Release Version: 20.06.25__stable__0.19.0

Release Date: 06/25/2020

New Features

  • We have moved the Loyalty Programs feature to the User Enrollment > User Journey section. It has been updated and is now visually consistent with the rest of the system.
  • The Form Condition now enables you to direct your WiFi users to specific Flows based on their responses to open questions.
  • From now on, you can customise the print view of Tokens using HTML and CSS.

Updates

  • The User Agreement section has been updated and is now consistent with the rest of the system.
  • We have added a new body parameter to the Platform’s /location/management/multivenue/scheduler API method. This parameter defines the category of each venue created, which will allow for the future optimisation of the Platform's performance and the analytics of specific types of venues. Note: No need to change the type of call for this method - queries in the previous format will still work, and the venue created by them will be categorised as Other.
  • We have added the following permissions to the Platform:
Permission name Description
createFlowLoyalty Allows a user to create Loyalty Programs
editFlowLoyalty Allows a user to edit Loyalty Programs
deleteFlowLoyalty Allows a user to remove Loyalty Programs
flowTokenFormatter Allows a user to create a custom Tokens print view
verifyFlowLoyaltyToken Allows a user to verify tokens in Loyalty Programs
