Release Version: 21.08.06__stable__0.48.0

Release Date: 08/06/2021

New Features

  • We have added a new type of area heatmap to Dashboard > Behaviour > Traffic Map.
  • We have added groups of columns to the Sessions Table in Raw Data and added new columns for Organisation Address, City, Company ID and Company ID type which are only visible when the appropriate property is turned on.
  • We have added phone number and Email columns which show the used login method.
  • We have integrated DCN devices to operate the Captive Portals.

Updates

  • We have enabled CoA for Mikrotik and added support for Meraki and Aruba.
  • We have made the anonymisation of personal data going to LinkyFi logs more efficient.
  • We have added information about expiring certificates to internal alerts as part of our communication.
  • We have added the ability to specify a controller domain for the Ruckus Cloud device used for CoA requests.

System Updates

  • We have added the following permissions to the Platform:
Permission Name Description
areaTabLocationStatistics Allows the user to view the Area tab in the Location statistics
rankingTabLocationStatistics Allows the user to view the Ranking tab in the Location statistics

Resolved Issues

System Fixes

  • We have fixed the issue with the Auto-Complete option replacing already added Emails in Report Manager.
  • We have updated the permission structure for Access Method to reflect the actual structure.
  • We have improved the handling of received transfer data in Radius in case of inconsistency on the part of APs.
