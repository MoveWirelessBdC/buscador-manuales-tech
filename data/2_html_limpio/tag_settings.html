Configuring Tag Settings

Tags serve as data points for platform users and are replaced by the system with specific values. For instance, the $firstName tag serves as a data point for a user's first name. It is replaced in the final content (SMS, Email) with the user's first name. If the tag cannot find a proper value, it displays a default value which was previously set up in the system.

Note: The tags apply to text, custom code, and custom code repository components.

The full list of tags is in Tag Settings where you can configure the tags according to your preferences.

  1. In the Portal Editor, click the Tag Settings icon in the lower right corner.

  2. Type those values which you would like to be displayed as default, if the data is unknown,into the Default Value fields.

    Note: This is optional. With no value, the tag is omitted.

  3. In the top right corner, click Apply to confirm changes.
