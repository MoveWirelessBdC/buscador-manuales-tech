Release Version: 22.06.24__stable__0.71.0

Release Date: 06/24/2022

New Features

  • We have added Password as a new method of logging in to the Captive Portal. The administrator, when creating the Portal, can set a shared password that will be required to enter in order to log in and use the Wi-Fi.

Updates

Feature Updates

  • We have added the Forgot password? option for Phone number accounts in which an SMS is sent with the link to reset the password.
  • In the social media configuration for ECB the field Url (required) has been added.

System Updates

  • We have added the following permission to the Platform:
Permission Name Description
passwordComponent Allows the user to add the Password login component to Portals

Resolved Issues

System Fixes

  • We have fixed the issue in Portal Management > Sending Centre > Sending Configuration > SMS where the error description message was not shown correctly when the text contained a word longer than the width of the window. This was resolved by forcing the words to wrap.
  • The link to download the landing page navigation app no longer appears when the link is not present in the configuration.
  • We have added a uniqueness check for the name of the organisation and other entities when moving an organisation in a tree, this is consistent with the editing and creation behaviour.
  • We have corrected the behaviour when the User Account has been blocked due to the lack of logging in, then the change of the maximum time since the last logging in will not automatically unblock this account.
  • We have fixed the issue where the data is now collected correctly in the Flow, even if the user immediately leaves the node with internet access. This applies to tokens that can be fully used up after entering them in the Captive Portal and before the user gets internet access.
  • We have fixed the import/export issue for fields corresponding to mappings in the editor. An example of this field is RUCKUS_VSCG Custom SIP configuration where it was incorrectly required during import.
