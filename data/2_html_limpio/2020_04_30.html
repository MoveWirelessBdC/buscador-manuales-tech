Release Version: 20.04.30__stable__0.15.0

Release Date: 04/30/2020

New Features

  • We have introduced the new Form Condition that you can add to Page Flows. It enables you to differentiate end-users based on their answers to rating questions in a Form that has been added to the Portal.
  • Internet Access nodes in Page Flows now have a new Redirection Settings function which allows you to configure URL addresses and landing pages to which users are redirected after logging in to your network.

Updates

  • We have migrated the User Roles feature to a new section so it is consistent with the rest of the system. It is still located in the Portal Management section, and you have been automatically given access to it.
  • You can now preview images in AdServer statistics, export image and video data to the CSV file, and enter the detailed view of the image and video statistics.
  • From now on, you can search for Organisations in the Structure section by their Organisation ID.
  • We have added the Spanish language to the Portal editor so you can now create Portals with Spanish translations.
