Release Version: 23.11.10__stable__0.107.0

Release Date: 10/11/2023

Updates

Feature Updates

  • We have linked white labeling domain customisation to organisations. Users can now manage their own white labeling settings, eliminating the need for platform administrators to handle this.
  • We have introduced a new scaling option for heatmap presentation, which relies on the quantile distribution of buckets.

GUI Updates

  • We have made updates to portal styles to proactively address potential issues within the portal editor.
    • The default styles now specifically target areas where components may appear, as opposed to the editor as a whole.
    • Animations provided by the Material Components library, commonly used by portal components, have been renamed to prevent collisions.
    • Overriding default styles through the Custom code component should now be slightly more straightforward.
  • We have made subtle adjustments to the appearance of certain editors to align them more closely with the overall Platform design. These changes are implemented in the following areas:
    • User Enrollment > User Agreements: Service Documents, Marketing Categories, Communication Channels,
    • Location Management: Geofencing, Density alerting, Panic button
    • Portal Management > Licences and roles > Licence manager
  • We have updated the appearance of all multi-value selectors across the Platform.

System Updates

  • We have updated the server side of the integration with Google Sign-In on Captive Portal. No changes are required for end users or configuration.
