Release Version: 21.09.17__stable__0.51.0

Release Date: 09/17/2021

New Features

  • We have added a new and important security feature, the ability to set up and configure a Time-Based One Time Password Two-Factor Authentication when logging in to the platform. From now on, during logging into this feature can be either recommended, required or turned off. An additional option has been implemented, Remember me, which allows the user not to enter the token code every time if using the same device. The Two-Factor Authentication set-up view is available for the user until the correct code is entered for the first time. The view becomes available again when the user secret key is reset in Portal Management > Structure > User section. The option of configuring the Two-Factor Authenticationfor an organisation is possible only by our administration.

Updates

Feature Updates

  • In the Device Mapper in Dashboard > Behaviour, the activation of the Panic Button changes the device’s color to a warning color.
  • We have added Tooltips for device configuration which support CoA and informs about IP Address, Domain controller and Custom/Public SIP.
  • In the Users Now table of the Dashboard we have changed the list of all user organisations and the list of all their devices to the current device used to log in and the organisation they last logged into.

Note: Earlier data can be found in Raw Data > WiFi Users table.

  • When creating and editing a Payment Plan in the network parameters step, the option to set the total data transfer has been added.

System Updates

  • We have added the following permissions to the Platform:
Permission Name Description
resetTotpSecret Allows the user to reset the secret key for two-factor authentication

Resolved Issues

System Fixes

  • The video preview in the table in Reporting > Statistics > Ad Server is now up and running.
  • The issue with incorrect calculations of the Quota Left in the User account table has been resolved.

Note: In the Used column information has been added that the value of the exceed transfer may be higher than the total.

  • Editing a User account defined in the child of the currently selected organisation is now working properly.
  • We have optimised the processing for Captive Portals which in turn results in fewer queries to the database.
