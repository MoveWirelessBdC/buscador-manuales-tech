Release Version: 21.11.12__stable__0.55.0

Release Date: 11/12/2021

New Features

  • We have added the option to remove or export more than one device as well as the option to change the items per page.
  • In the image slider we have added the possibility to set-up the time range and days active for the displayed images.
  • We now support the Xovis cameras, which count two-way passes on the lines defined in the webcam. This data is visible in the Location statistics section of the Platform.

Updates

  • We have changed the access to Localisation views where all users were migrated to the new localisation statistics.
  • We have updated Swagger, and now it follows OpenAPI Specification 3.0.

Resolved Issues

System Fixes

  • We have improved the search option in troubleshooting where, fragments regardless of case sensitivity, are searched.
  • The minimal portal width is now 883px for all portals that use desktop components to support the MAC OS CNA.
  • The organisation names of entities from organisations to which the user has no access have been hidden in the grid views.
  • We have fixed the issue with missing or incorrect messages in the Platform’s UI after a new release, caused by outdated versions of translation files getting loaded from the browser’s cache.
  • We have fixed the issue with Remember device feature while using custom codes.
