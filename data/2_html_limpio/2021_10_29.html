Release Version: 21.10.29__stable__0.54.0

Release Date: 10/29/2021

New Features

  • We have added a new Two-step email verification login method to Portals where you can use two different login types, Email Verification and Email Authorisation. With Email Verification, the address provided by the user during logging in is confirmed via a message which they receive, whereas with Email Authorisation, the provided email belongs to an employee who receives a message in their inbox and then gives access to the guest.
  • Payment integration with Coral Commerce has been added and we have made Coral Commerce payments available through the Captive Portal.
  • We have added a mock-up data generation functionality for presentation purposes, which imitates user login by creating profiles with false personal and demographic information. It currently supports the following logging types: Google, Facebook, free, autologin, questionnaire, token, phone number/call authentication, email address and user account login. This functionality also allows this data to be viewed in Dashboard and Statistics. Currently this configuration is done from the administrative level.

Updates

Feature Updates

  • In Accounts Settings we have added an additional configuration option for setting the date and time format. The format is saved in the database and the new pattern will be integrated in the upcoming sprints.

GUI Updates

  • The feature select all/deselect all has been added to Portal management > Structure > Devices section which allows you to select multiple devices.

System Updates

  • We have added the following permissions to the Platform:
Permission Name Description
emailVerificationComponent Allows the user to add Email Verification components to Portals
emailInputLoginConfiguration Allows the user to access the Login Configuration in the Email component in Multi-step login

System Fixes

  • The order of reading transfer octets for Teltonika devices has been changed, the reverse count of upload and download in new sessions is now counted correctly.
  • We have fixed the username case-sensitivity inconsistencies.
  • We have resolved the performance issue when entering the Token group panel, now for organisations with a large number of token groups and tokens, the panel opens noticeably faster.
  • The preview flow URL now uses the domain configured for portals, now you can properly display the preview flow which is on a different domain.
