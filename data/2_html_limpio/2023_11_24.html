Release Version: 23.11.24__stable__0.108.0

Release Date: 24/11/2023

New Features

  • We have introduced a new display option in the Traffic Map section under Reporting > Location > Venue: the Spatial heatmap. This feature provides a more dynamic 2D heatmap visualisation, serving as an alternative to the already present grid layout. The availability of both the Grid format and the new Spatial Density Map can be customised via the newly added organisation property "heatmapTypes".

Updates

Feature Updates

  • We have enhanced the validation process for Venue import files to ensure consistency with other file validation procedures.

GUI Updates

  • We have made subtle adjustments to the appearance of specific editors to better align them with the overall design of the platform. These modifications have been implemented in the following areas:
    • Portal Management > Domain Customisation
    • Portal Management > Structure
    • Portal Management > Sending Centre
    • Portal Management > Properties > Internet Access properties
    • User Enrollment > Access methods
  • We have improved colour transitions in the Traffic map.
  • We have updated the branding for X (previously Twitter), including logos, colours and labels.
