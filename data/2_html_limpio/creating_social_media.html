Managing a Social Media configuration

Before Your Start

Go to the User Enrollment > Access Methods section, and click the Social Media tile. In the Social Media manager there are two tabs:

  • All configurations - shows all (own and parent organisations), allows to create new, edit existing and delete configurations

  • Primary Configurations - shows which configurations are automatically used to log in on the Captive Portal. To learn more, read the Setting Primary configuration chapter.

Creating a Social Media configuration

  1. In the Social Media manager, in the All configurations tab, click the + button in the lower right corner to create a new configuration.

  2. In the first step, enter the name of your new configuration and choose the Social Media platform from the dropdown list.

  3. In the second step, you have to enter additional information such as: Client ID, Client Secret, Redirect URI.

    Note

    Depending on which Social Media platform is chosen the additional information required may vary.

  4. In the Summary section you may see all the configuration details entered in the previous steps. Next, click the Save button, and the configuration is now created.

  5. After creating a configuration it will appear in the Social Media manager list.

  6. To see more details you may click on the configuration itself, or the expand icon in the far right section of the bar.

Important

In order for the configuration to be automatically applied as Primary in the Captive Portal, it must be set manually by going to the Primary tab configuration.

To learn more, read the Setting Primary configuration chapter.

Editing a Social Media configuration

  1. Go to the User Enrollment > Access Methods > Social Media section. Find the configuration which you would like to edit. Once you have located it, click the three dot action button at the right of the bar, and select Edit from the dropdown menu.

  2. After you have edited the configuration settings, click Save in the top right corner to confirm the changes.

Note

You cannot change the Social Media platform for the existing configuration.

Deleting a Social Media configuration

  1. Go to the User Enrollment > Access Methods > Social Media section. Find the configuration which you would like to delete. Once you have located it, click the three dot action button at the right of the bar, and select Delete from the dropdown menu.

  2. In the pop-up box, confirm the deletion of the configuration by clicking the Delete button.

Note

You cannot delete a configuration which is used as Custom on the Captive Portal or is set as the Primary.
