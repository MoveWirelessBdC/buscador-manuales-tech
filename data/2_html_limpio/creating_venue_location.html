Creating a venue

The basic step in the location configuration is to create a venue. In this step, you insert the name of your venue along with its ID and choose the mode of operation.

To create a venue:

  1. Go to Location Management → Management and click .

  2. In the Create new venue panel:

    • Into the Name field, type the name of your venue.

    Note

    The venue name is set only once. After you create the venue, you won't be able to change its name.

    • From the Devices list, select the type of devices used in the venue.

    Note

    Depending on the type of devices used, you may need to provide different type of data.

    • From the Mode list, select Location.

  3. Click Save.
