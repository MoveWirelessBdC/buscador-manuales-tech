Topping Up a User Account

The Platform allows you to add a data transfer to User Accounts which have used up their entire transfer before the determined reset time.

To top up a User Account:

  1. In the User Accounts feature, find the account which you would like to top up in the List of User Accounts table.

    Then, on the right side of the desired account, click the More option and select Show Top-Ups from the dropdown menu.

  2. In the new window, click the + button in the bottom right corner to add a data transfer.

  3. Now, in the pop-up box:

    • In the Data Transfer section, specify an additional amount of data that you would like to assign to this Account, and select the size of data from the dropdown menu.
    • In the Validity Time section, determine how long those additional data should be valid by selecting the desired start and end dates from the date pickers.

    To finish adding a top-up to the account, click the Top Up button in the bottom right corner of the pop-up box.

  4. The selected User Account has now been topped up.
