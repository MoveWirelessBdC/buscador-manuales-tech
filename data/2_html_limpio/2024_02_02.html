Release Version: 24.02.02__stable__0.113.0

Release Date: 02/02/2024

Updates

Feature Updates

  • We have updated venue import - area import no longer includes disabled areas, and area creation date is properly set to import time.
  • We have removed flags responsible for Account Holder and Data Administrator from Organization Properties. Those settings are still accessible via Organization edit view.

GUI Updates

  • We have made spacings in platform views more consistent.

System Updates

  • We have added the possibility to enhance radius validation. Enabling this validation is optional, and the scope depends on the types of access points.

Resolved Issues

Feature Fixes

  • We have fixed LinkedIn integration to correctly work with newly created applications using OpenID Connect, we now allow users to configure custom scopes that LinkedIn is required to give.
