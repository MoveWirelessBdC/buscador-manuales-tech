Release Version: 22.11.14__stable__0.81.0

Release Date: 14/11/2022

Updates

Feature Updates

  • We have added a new csvLocale property which defines the locale used for formatting numbers in exported CSV files.
  • We have added support for CSV-related properties (csvDefaultDelimiter, csvExportCharset, csvExportDateTimeFormat, csvExportPreference, csvLocale) when exporting CSV files in Reporting > Statistics and User Enrollment > Access Methods > Tokens & User Accounts.

GUI Updates

  • We have removed the old Billings feature along with the related services, views, styles, and UI texts.

System Updates

  • We have refactored activity logging for Social media so that the missing types of operations are also logged to the database (e.g. setting social media default configuration, deleting a configuration).

  • We have fixed communication issues with PMS servers to prevent potential thread leaks.

  • We have improved cleanup of configuration elements left when deleting an organisation.

  • We have improved cleanup of licence configuration elements left when deleting an organisation.
