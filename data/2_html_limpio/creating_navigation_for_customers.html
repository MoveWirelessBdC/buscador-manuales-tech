Create navigation for customers

If you have the location function, you can offer your customers navigation around your venue. It takes some configuring but it's worth it because they provide you with useful behaviour data.

What you need:

  • Platform account
  • 25 minutes

To create navigation for customers:

  1. Create categories of premises
  2. Add premises
  3. Mark areas
  4. Mark connection between floors
  5. (Optional) Place cashpoints and toilets
  6. Draw navigation lines
