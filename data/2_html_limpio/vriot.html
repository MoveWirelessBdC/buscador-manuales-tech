vRiot Configuration Guide

Note

Before you start configuring the vRiot device, you should ensure it is connected with your Ruckus vSZ device.

  1. To begin the configuration process, log in to the Ruckus IoT Controller interface:

    • Into the Username field, enter your username.
    • Into the Password field, enter your password.

    Then, click Login to enter the interface.

  2. In the Ruckus interface, select the Admin option from the top bar menu.

  3. In the Admin window, select the Plugins option from the left menu.

    Then, from the Active Plugin List, select iBeacon.

  4. Now, in the pop-up box:

    • Into the API URL field, enter the URL address to your API.
    • In the Port field, type the server’s port. For this instruction, it is 80.
    • Into the API Endpoint field, enter the API endpoint address with the correct Venue name.

    After you have provided all the details, click Update to finish the configuration.
