Release Version: 24.06.07__stable__0.122.0

Release Date: 07/06/2024

New Features

  • We have added a new type of device Unifi v7.4 or above to work with our Platform. We have also renamed the device type Ubiquiti to Unifi v7.3 or below.

Updates

Feature Updates

  • We have improved handling of implicit networks during organisation relocation and updates to token and user account filters. Implicit networks are now ignored during relocation and automatically removed if access is lost. Additionally, implicit networks can no longer be added to tokens or user accounts, ensuring they remain invisible to users without proper permissions.
  • We have added a new configuration guide for Ruckus One devices.

Resolved Issues

Feature Fixes

  • We have fixed an issue where, in rare cases, users might receive an Error Page instead of the proper Portal Page after the initial redirect when using multiple browser tabs.
