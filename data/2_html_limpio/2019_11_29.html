Release version: 19.11.29__stable__0.5.0

Release Date: 11/29/2019

New Features

  • We have introduced the Account Holder function which enables you to set the organisation as the Data Administrator, and by that, manage your WiFi user accounts.
  • From now on, you can import devices into the system through the Import CSV File option in the Devices section. For correct preparation of the file and successful completion of the importing process, this option allows you to download a sample CSV file for a specified device.

Updates

  • The Token Groups and the Payment Plans views and creator windows have been updated, and are now up to date with other system features.
  • Platform users are now able to edit their profiles, and access them via both the Users section and the Profile button from the navigation bar.
  • We have revised the Statistics chapter of the user guide.

Bug Fixes

  • The Dynamic Properties now display correctly for a selected organisation.
  • The organisations no longer disappear from the organisation tree when using the search option.
  • The Portal views now display as expected when deleting an organisation.
