What’s New in February 2021

Notifications For User Accounts

Setting Up User Account Notifications

We have introduced notifications to the User Accounts feature, which allows you to send your WiFi users automatic email notifications when they reach the specified threshold of assigned data transfer.

Note: This type of notifications works only for User Accounts with specified email addresses. You can enable them for each user in the User Account editor and manage their settings from the List of User Accounts table.

You can enable this option:

  • when creating a new User Account
  • while editing an already existing User Account
  • from the List of User Accounts table (for Accounts with already specified contact emails).

For more information on enabling this option, read the Managing a User Account chapter in the User Guide. To learn how to manage enabled notifications, read the Managing User Account Notifications chapter.

Customising User Account Notifications

As with every other type of notifications, you can customise User Account notifications in the Email Customisation feature. To do this, go to the Portal Management > Sending Centre > Email Customisation section and adjust the desired notification in the User Accounts section.

To learn how to customise email notifications, read the Email Customisation chapter in the User Guide.
