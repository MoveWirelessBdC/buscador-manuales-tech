User Journey Overview

User Journey is a platform feature which allows you to create a personalised login path to your Wi-Fi. To access it, go to the User Enrollment → User Journey section

In this section, you can see four components with which you will design a personalised user login path. These are: Page Flow, Portal, Access Settings, Form, and Loyalty Programs. Each of them has their own editors.

Page Flow

A Page Flow (also called a Flow) is a graphic illustration of a login path. As was previously mentioned, you may shape it according to your needs.

The Flow can be very simple, with one Portal (a login page) and Internet Access. Or, it can be very complex as well. See the images below.

Portals

Portals are the pages which are displayed to users. They have a variety of uses in the login path. The Portal, which plays a key role in the Flow is the login page, where the users gain internet access. The Portals, however, may also be used to authenticate users, display marketing content, or communicate with WiFi users.

To learn how to create and edit a Portal, go to the Portals chapter.

Access Settings

The Access Settings feature is your network manager. Essentially, it is the most important part of the User Journey because it makes the Page Flow visible to the users. It allows you to configure a network which you will provide to your venue. You may create it, give it a name which will be displayed on the users’ devices with other WiFi networks, and then connect the Page Flow to it.

To find detailed instructions on how to manage the Access Settings, read the Creating Access Settings chapter.

Forms

Forms are questionnaires which you can use on the Portals. They are not required in the User Journey process, but are a great tool to gather user data. For instance, you may use a Form on your login page and collect gender, age, and email information from those users who log into your WiFi. You can also create custom survey questions according to your needs. Creating a Form is similar to creating a Portal.

To learn how to create and edit a Form, go to the Forms chapter.

Loyalty Programs

Loyalty Programs enable you to launch marketing campaigns that allow users to collect stamps and receive token codes which they can redeem for rewards. It is a useful strategy to encourage users to shop or use your services regularly.

To start building a Page Flow, read the Page Flow Overview.
