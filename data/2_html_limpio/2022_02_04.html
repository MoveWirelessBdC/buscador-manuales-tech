Release Version: 22.02.04__stable__0.61.0

Release Date: 02/04/2022

New Features

  • We have integrated with the Platform a new type of AP, Mist. Due to the lack of Radius we have added a new mechanism for gathering transfer statistics for Mist sessions as well as a Disconnect Message support.
  • In Portal Management > Structure we have added a new controllers tab. Cambium Controller is the first available controller, it collects the settings that would need to be duplicated in all Cambium devices in the system connected to one controller. Also, we have added the possibility to choose Cambium Controller in Device type WAG Access Point (Cambium).

Updates

  • We have introduced memory cache for devices which will reduce database queries about devices which will speed up processing in several places such as the logging in process.

System Updates

  • The ability to delete all collected location data from the administrative level has been added. We have also fixed missing cleanup of some localisation configurations when removing a venue or organisation and from now on the history of deleted venues or areas will be collected.

  • We have added the following permission to the Platform:

Permission Name Description
previewFlowTokenGroup Allows the user to preview the Token Group and download token data
structureReadWriteControllers Allows the user to access the Controllers configuration

Resolved Issues

System Fixes

  • A check has been added for the moving of the organisation to ensure that this would not result in duplicate network names. If so, the transfer is blocked.
  • Moving an organization shows all the SSIDs that would be orphaned, not only the first encountered one.
  • We have fixed the issues with permissions, mainly in Token group, not allowing the correct passage through the editor and saving the entity in certain permission settings. The permission tree for Token groups has been improved to reflect what permissions are actually used.
