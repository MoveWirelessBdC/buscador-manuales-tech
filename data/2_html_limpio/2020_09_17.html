Release Version: 20.09.17__stable__0.25.0

Release Date: 09/17/2020

New Features

  • You can now set up confirmation emails in the Payment Methods component of the Portal Editor which would be sent to users when the payment is registered.

Updates

  • We have added a new DELETE endpoint to the Single Token API to allow you to delete Tokens by using token’s code and the organisationID.
  • We have also modified the POST endpoint which now returns created DTO instead of tokenID.
  • We have made the necessary modifications in the WifiUserProfiles to allow you to access PayPal’s transaction data via API.
  • You can now find an Organisation in which the specific Role has been created, by using the Role name filter in the advanced search (the roleManagerRead permission is required).
  • We have added the following permissions to the Platform:
Permission name Description
readWiFiPaymentsData Allows the user to use API to access PayPal transaction data

Bug Fixes

  • We have fixed an issue where Portal would be stuck in limited edition mode even after the Page Flow using it has been deleted.
  • Some tables in the Users dashboard have displayed negative values for session duration. This has been resolved, and the numbers display correctly.
