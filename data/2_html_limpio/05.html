What’s New in May 2020

New Dashboard

We have introduced the brand new Dashboard, which is now divided into two sections: Users and Behaviour and displays live insights about your users.

The Users Dashboard

The Users dashboard provides you with insights on how users use your network, just like it did before. It is divided into two subsections: How do users use your WiFi and Who are your currently logged in users?.

The Behaviour Section

Behaviour is a new dashboard that gives you live information on how users move around your venue. The numbers in this section are updated live and compared to the same moment of the previous day. They are also divided into four subsections: What do you know about Passers-By and Visitors?, What do you know about New and Returning Visitors?, What do you know about the dwell-time of Visitors?, and Where are your users now?.

Permissions Tree

We have updated the Permissions Tree which now reflects the feature structure more accurately and, by that, allows you to easily select desired permissions. You can access this Tree either during the creation of a new user, or in the Edit mode of the existing one.

Roaming User Condition

We have also updated the Roaming User Condition that now allows you to differentiate Returning Users based on the type of login method which they have selected while logging in to your WiFi.

Redirecting to Landing Pages

The Internet Access nodes in Page Flows have a new Redirection Settings function which allows you to configure URL addresses and landing pages to which users are redirected after logging in to your network.

To set it up, click the More option in the Landing Page section of the Internet Access node, and select the Redirection Settings from the dropdown menu. Then, set the redirection options according to your preferences in the pop-up box.

Permissions

We have added several new permissions to the platform. Be sure that you accordingly update them for all your platform users.

Permission Name Description
createSingleToken Allows a user to create single Tokens
readSingleToken Allows a user to view single Tokens
deleteSingleToken Allows a user to remove single Tokens
