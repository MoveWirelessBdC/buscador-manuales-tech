New Features

  • We have added a new payment method for the login via Payment plans - Fiuu payment gateway. To properly configure the Fiuu gateway, the following properties must be set in the organisation:
Property name Description
fiuuEnableIntegration Enables the Fiuu payment option in the Payment Method component.
fiuuApiHost Defines the URL for the Fiuu gateway.
fiuuMerchantId Defines the Merchant ID for the Fiuu gateway.
fiuuVerifyKey Defines the Verify Key for the Fiuu gateway.
fiuuSecretKey Defines the Secret Key for the Fiuu gateway.
fiuuExtendedPaymentVerificationFormat Enables the extended format for Verify Payment for the Fiuu gateway.
fiuuInstantPaymentNotification Enables Instant Payment Notification for the Fiuu gateway.
