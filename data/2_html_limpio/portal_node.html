Adding a Portal Node

Portal nodes enable you to set up Portals through which users can be redirected to designated landing pages.

Adding a Portal Node as the First Node

  1. In the Page Flow Editor, click + to create the first node. Then, from the list, select the Portal option.

  2. On the Portals Available page, select the Portal which you want to add to the Page Flow. In the upper right corner, click Select to confirm your choice.

Adding a Portal node as the Follow-Up Node

  1. In the Page Flow Editor, click the More option in the last node. From the list, select Add Node, and from the next sub-list, select the Portal option.

  2. On the Portals Available page, select the Portal which you would like to add to the Page Flow. In the upper right corner, click Select to confirm your choice.

Adding a New Portal to the Page Flow

  1. On the Portals Available page, click the pink + button in the lower right corner.

  2. Type the name of the new Portal and select its language. In the upper right corner, click Select to confirm.

  3. You will now be redirected to the Portal Editor where you can design the new Portal. To learn more about creating a Portal, read the Creating a Portal chapter.

  4. After you have finished creating a new Portal, save it. You will then be automatically redirected to the Portals Available page. Choose the newly created Portal and click Select in the upper right corner in order to add it to the Page Flow.

  5. To finish the process of adding a new portal to the Page Flow, click Save to save the changes which were made to the Page Flow.

    Note: The Page Flow must be completely finished before it is saved and all nodes must be fully configured in order to conclude the process.
