Release Version: 22.11.25__stable__0.82.0

Release Date: 25/11/2022

New Features

  • We have added the automated suspend/resume action for licence packages. The action will be applied hierarchically for individual licences from a package.

Updates

Feature Updates

  • We have added a new maxVideoSize property (default 2MB) to define the maximum video size that can be uploaded in the video component in Portal editor. The maximum size cannot exceed 50MB.

  • We have enhanced the configuration of redirect URIs in the Social media editor. The user no longer needs to provide a redirect URI, but instead a list of domains for which the application should be configured. On this basis the system generates redirect URIs which the user pastes into the social media application settings.

GUI Updates

  • The file upload button in the Portal import view now suggests only files with the supported extension.

  • The Page Flow manager now supports multiple selection and deleting several flows at a time.

Resolved Issues

Feature Updates

  • We have fixed a bug that caused the Ad Server statistics for full video views to be counted incorrectly.

System Fixes

  • We have fixed a security issue which allowed accessing the platform’s User Guide without the required 2FA token.
