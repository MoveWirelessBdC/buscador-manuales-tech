Adding a venue plan

Now that you created your venue, you can upload the plans of all the floors and set the scale of those plans.

To add a venue plan:

  1. Go to the Location Management menu, (Location → Management), and click the Venue map tile.

  2. On the right, click Add floor.

  3. In the Add floor window:

    a. Click Select floor map and upload a plan of one of the floors of the venue in the PNG format.
    b. Into the Floor number field, type the floor number of the uploaded plan.

    c. Click Add floor. As a result, the plan uploads and a black marker point appears on it.

  4. Set the origin point by clicking and, on the plan, dragging the marker to a new position. Next to the icon, click Save.

    Info

    The origin point is a point according to which all positions are going to be expressed. It must be in the same spot on all floors.

  5. To set the plan scale:

    a. Click and then the plan. As a result, marker points A and B are added.
    b. Drag the point B marker point as far as possible from the point A (large distance positively influences the engine accuracy).
    c. Into the pop-up window, type a real-life distance between points A and B. (Use a period to insert a decimal number, for example, 1500.5 [metres].)

    d. Click Save. Then, the system recalculates the distance and adjusts the grid. The grid is expressed in metres.

    Note

    After you add access or calibration points, it is impossible to change the scale. If you want to make any changes to the scale, make them now.

  6. Repeat this procedure for all the floors of the venue.
