Release Version: 19.12.13__stable__0.6.0

Release Date: 12/13/2019

New Features

  • We have implemented the WiFi Users listing panel which allows you to manage the User Accounts and preview their details.
  • We have added the Download All Data button to the Statistics section, which enables the download of all the data in CSV files compressed into a .zip file.
  • In the Engagement statistics, we have implemented the Devices per Type table which provides detailed information on the devices which have logged in to the WiFi in the designated period, broken by their types.
  • From now on, users with too many unsuccessful login attempts, or a too-long inactivity period can be blocked automatically from accessing the platform. The user blocking can also be carried out manually in the Users section of the Portal Management.

Updates

  • The Payment Plans views and creator windows have been fully updated and are now up to date with other system features. We have also updated the Payment Plans component in the Portal Editor which is now compatible with the new Plans views.
  • The timeline tables in the Statistics section have been updated with granularity, and now allow you to display data by hour, day, or week.

Bug Fixes

  • We have resolved the issue in the Form Results which now preview as expected.
  • The Impressions table has been fixed, and is now displaying data correctly.
