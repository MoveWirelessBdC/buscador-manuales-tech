What’s New in January 2020

Devices Settings in Read-only Mode

From now on, you do not need to enter the Device Editor to preview its settings. We have implemented the Read-Only mode, which allows you to preview these settings easier and faster. To use it, click the More option of the desired Device, and select Preview Settings from the menu.

Advanced Search

We have expanded the Search option in the Structure section with the Advanced Search. It allows you to search the desired phrase in a specific category: User, Device, Network, or Venue*.

Preview Time Interval in Condition Nodes

In the Condition Nodes that use the Time Interval setup, you can now preview settings without entering the Editor mode. To do this, go to the appropriate Page Flow. Then, in the desired Condition Node, click the More option, and select Preview Time Interval from the menu.

Tokens

The Tokens feature has been updated and is now visually consistent with the rest of the platform. It also includes several new options which you may find useful:

Token Counter

In the Token Groups Manager, we have added the Tokens Counter to the Token Groups tiles. It provides you with a quick insight into the number of Token codes in a Group and their current usage.

Token Groups Details

We have also implemented the Token Group Details list where you can view the full list of the Token codes which the Token Group contains. To view it, click the More option on the desired Token Group tile, and select Show Token Group List from the menu.

Network Parameters for Token Groups

The Token Group creator now allows you to limit your network for users who access it via Tokens by setting up the time, speed, and data restrictions. You should note that such setup applies to all of the Tokens in a Group and cannot be set selectively.

Network Parameters for User Accounts

From now on, you can also set up the Network Parameters selectively for each network user. You can apply it for new users during the user account creation, or by editing the already existing users.

Permissions

We have added several new permissions to the platform. Be sure that you accordingly update them for all your platform users. To learn how to apply roles and permissions to a user, read the ... chapter in the User Guide.

Permission Name Description

structureReadDevices Allow a user to preview list of Devices, and download them into a CSV file

testApiAccess Allow a user to access the test API
radiusVendorSpecificAttributes Allow a user to access and configure the RADIUS attributes in the Network Parameters
displayInheritedFlows Enable the display of inherited Page Flows in the Page Flow Manager
