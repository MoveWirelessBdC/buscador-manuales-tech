Configuring the engine

Only for advanced users: This step of the configuration is only for advanced users.

To configure the engine:

  1. Go to Location Management → Management and then click the Engine tile.

  2. In the Edit configuration section:

    • If you do not have permission to configure the engine, the panel is empty. It means that you cannot implement any changes to the engine.

    • If you have permission to configure the engine, type the appropriate parameters into the Engine parameters field.

  3. Click Save.
