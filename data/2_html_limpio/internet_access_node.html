Adding and Configuring the Internet Access Node

The Internet Access Node allows you to configure the Internet Access settings, specifically the network parameters and the redirection page.

Adding an Internet Access Node as the First Node

  1. In the Page Flow Editor, click + to create the first node. From the list, select the Internet Access option.

  2. On the Network Parameters page, set up the network settings. To confirm changes, click Save in the upper right corner.

  3. To finish configuring the node, select the Add Landing Page option. Now, redirect users to the portal or website of your choice.

Adding an Internet Access Node as the Follow-Up Node

  1. In the Page Flow Editor, click the More option in the last node. From the list, select the Add Node option, and from the sub-list select Internet Access.

  2. On the Network Parameters page, configure the network settings. To confirm changes, click Save in the upper right corner.

  3. To finish the configuration process, choose the Add Landing Page and redirect users to either a portal of your choice or to a website.

Redirection to a Portal

  1. From the dropdown list, select the Portal option.

  2. On the Portals Available page, select the Portal which you would like to add to the Page Flow. In the upper right corner, click Select to confirm.

    Note: When choosing a landing page, only portals without submit buttons can be selected and displayed on the Portals Available page.

  3. When the Portal is added to the Page Flow as the landing page the Internet Access node will be fully configured.

Redirection to a Website

  1. From the list, select Website.

  2. Type the website link in the pop-up box and click Add.

  3. The website is now added to the Portal as the Landing Page and the node is completely configured. You can continue the path or close it, according to your preferences. To learn how to do this, read the Continuing and Closing the Page Flow Path chapter.

  4. To finish the configuration process, save the Page Flow by clicking Save in the upper right corner.

    Note: The Page Flow must be completely finished before it is saved and all nodes must be fully configured in order to conclude the process.

Removing an Internet Access Node

To remove an Internet Access Node from the Page Flow, click the More option on the desired Portal Node and select Remove Node from the menu.

Note: If you remove a node, some nodes can be left disconnected from the Page Flow. You should note that it is necessary to connect all nodes before saving and using a Page Flow. A Page Flow with disconnected nodes can only be saved as a Draft.

To learn more about removing nodes, read the Connecting, Disconnecting and Removing Nodes chapter.
