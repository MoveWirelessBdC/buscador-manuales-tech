Release Version: 20.11.12__stable__0.29.0

Release Date: 11/12/2020

New Features

  • We have reviewed and updated the process of adding Venues to the Platform, which is now visually consistent with the rest of the Platform interface. We have also moved it to the Portal Management > Structure section; it is now located in the Structure upper bar to facilitate managing Venues in Organisations.

  • We have introduced the new type of Timeout in the Page Flow nodes - Hour - that allows you to specify the exact hour after which user sessions would reset.

Updates

Feature Updates

  • You can now filter Licence Packages when selecting the one from which you would like to distribute Sublicences.

GUI Updates

  • We have updated texts displayed during the password reset process, which are now more informative.

System Updates

  • We have implemented the new mechanism which controls data transfer used by WiFi users and terminates user sessions when the determined limits are reached.

    In the process, we have updated the transfer counting per user which now, apart of counting transfers per sessions, is based on the UserAccountingEvent events. Data transfers will also be checked when users log in to the network; if it is used up, users will not be able to log in to your WiFi.

    Note: To limit data transfers, you should enable the userAccountTransferLimitsEnabled property for the desired Organisations by changing its status to true.

    Data transfers for all user accounts can now be previewed in the List of User Accounts table in the Access Methods > User Accounts section.

    To ensure that data limits are working correctly, we recommend using devices which support transfer limits and configure them accordingly. Devices supported by the Platform include: CISCO, Ruckus controller, Meraki, Ruckus SZ/vSZ/vSCG, Ruckus SCG 3.2-3.4, RUCKUS_VSCG_CLOUD, and other.

    For more configuration details, see the Device Configurations chapter in the User Guide.

  • We have added the following permissions to the Platform:

Permission Name Description
licenceApLimit Allows the user to set and modify the AP capacity for Sublicences
structureReadVenue Allows a user to access Venues in the Structure panel
createVenue Allow a user to create, edit and delete Venues

Resolved Issues

System Fixes

  • The Users Now table in the Dashboard statistics would have problems with displaying data for Organisations with large numbers of active users. It has been fixed, and the numbers are now displayed as expected.
