Release Version: 21.04.01__stable__0.39.0

Release Date: 04/01/2021

New Features

  • The Data Transfer option in the Licences feature now allows you to set up an automatic billing option for your Clients to request a top-up and pay for it instantly.

  • We have implemented time zone support for User Account, which makes them more precise and allows you to manage their data transfer top-ups more accurately.

Updates

GUI Updates

  • In the Marketing Categories creator, we have renamed the:Display Offer dropdown list to Offer Frequency. We have also renamed the Never option to "Once" to avoid confusion. The previous name implied the category would not be displayed at all when in reality, it would be displayed once and then never re-offered.

System Updates

  • To improve the system performance, we have introduced a new efficient encoding in our analytics for the most common location events. For certain events, the message size has reduced by 50-60%, and the encoding/decoding speed has increased by up to 20 times.

Resolved Issues

GUI Fixes

  • The Licence Details view would take too long to load. We have improved it, and it should now load far more quickly.

System Fixes

  • We have changed the marketing campaign's implementation to reach a more diverse group of users than it used to. Before, when an Organisation wanted to send marketing offers to a thousand users out of 1 million held, the system would select the first thousand users from the list. Now, it chooses them arbitrarily from the whole set.

  • Until now, the CoA packages would be sent only to the IP address defined in the Device's IP field. We have extended it so that CoA packages are also sent to all values defined in devices’ custom SIP maps.

  • In the Properties section, we have restricted the visibility of Organisation names for users who do not have access to preview them. As a result, information on an Organisation from which properties are inherited is by default hidden.
