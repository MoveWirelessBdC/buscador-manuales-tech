Release Version: 22.08.05__stable__0.74.0

Release Date: 08/05/2022

New Features

  • We have added the possibility to block the addition of a device when the organisation does not have a valid licence or has a used up licence. This includes adding devices via import, standard GUI and API.
  • Information about errors caused by licencing problems has been added to the troubleshooting view. This information will be collected from the update.

Updates

Feature Updates

  • In Portal Management > Structure > Organisations editor we have moved the explanations for additional options from tooltips to pop-ups. In case of changing significant fields (Data Administrator, Account Holder, Email sending administrator, SMS sending administrator, Time zone), we have also added an additional confirmation window.

GUI Updates

  • We have renamed Sublicence to Licence in all instances in the UI and emails in order to avoid misunderstandings.
  • We have updated informational texts for multi-step logging for better clarity.

Resolved Issues

System Fixes

  • We have fixed the SMS and email configuration administrator being enabled when editing the existing organisation while using an inherited configuration.
  • We have fixed REST API endpoints related to radiusVendorSpecificSchema. A field type (string/number/predefined) has been added to the RadiusVendorAttributeSchemaDto schema to distinguish the actual type.
