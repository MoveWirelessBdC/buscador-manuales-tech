Release Version: 23.09.15__stable__0.103.0

Release Date: 15/09/2023

New Features

  • We have introduced a new login method via TikTok, providing users with an exciting and convenient way to access Wi-Fi.

Updates

Feature Updates

  • We have upgraded the version of the Facebook API we use.

GUI Updates

  • We have significantly improved the user experience when configuring the Landing Page URL, making it more user-friendly and intuitive.

System Updates

  • We have reviewed third-party libraries used by the platform's UI and updated them to their latest versions. Several libraries have been completely removed, resulting in reduced browser resource usage and a lower risk of future security vulnerabilities.

Resolved Issues

GUI Fixes

  • We have resolved an issue with the "Show unformatted text" Action button. Previously, Marketing categories components and User login components with phone numbers did not retain their values upon return. This issue has been fixed to ensure a seamless user experience.
