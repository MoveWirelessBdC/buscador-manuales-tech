Managing a Data Transfer Package (for Representatives)

The Data Transfer tab enables Representatives to create Data Transfer Packages, which are predefined data bundles used to create and top up Licences. Those Packages enable both Representatives and the Clients to apply and request, respectively, additional data transfers for Licences.

They can be used in two ways:

  • Representatives can use them to top up their Clients’ data transfers.
    To learn more about topping up a Licence, read the Topping Up a Licence chapter.

  • Clients can request top-ups by selecting the desired Data transfer Package from the list of available ones.
    To learn more about requesting a top-up, read the Requesting a Top-Up chapter.

Creating a Data Transfer Package

  1. Go to the Licences and Roles > Licence Manager section, and click the Data Transfer tab in the upper bar. Then, click the + button in the bottom right corner.

  2. Next, in the new window:

    • In the Name field, type the name of the Data Transfer Package.
    • Into the Quota field, enter the desired amount of data and select the appropriate data unit.
    • In the Price field, specify the price of the Data Transfer Package.

    Note

    To enable setting up prices for Data Transfer Packages, you should first set the dataTransferPackageCurrencyIsoCode property to the desired currency.

    Then, click Save in the top right corner to finish creating the Data Transfer Package.

  3. The Data Transfer Package is now created and ready for use.

Editing a Data Transfer Package

To edit a Data Transfer Package, click the More option on the desired Package, and select Edit from the dropdown menu. Then, in the new window, adjust its name and/or its quota and save it to confirm your changes.

Deleting a Data Transfer Package

To delete a Data Transfer Package, click the More option on the desired Package, and select Delete from the dropdown menu. Then, confirm deleting the Package in the pop-up box by clicking the Delete button.
