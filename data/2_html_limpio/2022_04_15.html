Release Version: 22.04.15__stable__0.66.0

Release Date: 04/15/2022

New Features

  • We have reorganised the tile view in Portal Management > Properties:
    • Now for the old Advanced and Dynamic sections there is one common fullscreen Advanced view.
    • The tile for Dynamic has been removed, and these properties are displayed in Advanced in the Dynamic group.
    • We have also added new and clear permissions which give access to individual sections in this view.
  • The new Advanced properties view has been completely overhauled.
    • The main view has been divided into two parts.
    • On the left side is the folder view - here the properties have been divided into groups according to their functionality and reference, and there is a search box which allows a folder to be found.
    • On the right is a table displaying properties from the currently selected folder.
    • The new table is divided into 5 sections:
      • Key is displayed for each property.
      • Value which is currently set.
      • Group in which the property is located.
      • Origin of the property and whether the value is default or own.
      • Action displays the property description as well as the options to set, edit or reset the property.
    • A search box for the table allows you to search for properties by their key or value.
    • An additional option of filtering by Origin value has been added where you may choose to only display ** own ** / ** default ** / ** all properties **.
    • In the Action section the “Eye” icon allows you to see a more detailed description of the property via a popup. Here the key of the property is shown as well as whether the property is propagable or not propagable. Detailed description of the property is also shown and is only available in English.
    • Old and deprecated properties have been hidden via permissions.
  • We have added additional information to logs about sending messages, so far,there was only an indication of the specific organisation for which the sending took place, but now the full organisation path upto the root has been added.

Updates

  • When editing the own Platform account details (email, name, phone number, etc.) in Account settings > Profile, the current password must be provided for verification. Incorrectly entering the password works the same as when logging in and failed attempts may cause temporary blocking of the accounts which is set to 5 tries as the default setting.
  • The Aruba Central Rest API has been integrated with the Platform, specifically the Disconnect User action.
  • We have improved the processing of localisation events for Visible Wifi User Profiles which uses mechanisms related to current Localisation Statistics.
  • We have set the enableFlowTokens property to true as the default so that the new tokens work correctly in each new organisation without the need for additional settings changes.
  • We have added the possibility to change the colour palette for the Traffic Map in Dashboard > Behaviour > Traffic Map and in Reporting > Location > Venue > TrafficMap. In the heatmapPalette property (group / Reporting / Location) you can set a list of colour values separated by commas.
