Release Version: 21.12.10__stable__0.57.0

Release Date: 12/10/2021

New Features

  • We have added an active link pointing to the flow in Access Settings for the Network in order to easily navigate to the Flows section and selecting the required flow.
  • We have added a search by name in the Page Flow Manager. The redirection finds all Page Flows that match the name of the associated Flow.
  • In User Enrollment > User journey > Portal we have added the possibility to select and remove more than one Portal at the same time. We have also updated the appearance of the Portal manager and tile views.

Updates

Feature Updates

  • We have added more visual customisation for Service Documents by implementing a Collapsible document and Checkbox position options.
  • Mac address processing has been optimised for Location Engine, Portal processing and Statistics processing.

Resolved Issues

System Fixes

  • For step editors, when an error occurs while saving, the snackbar is displayed with the message unexpected error and the spinner on the button is stopped.
  • We have fixed the issue with scroll heights and now the preview text is displayed in its entirety in the Communication Channels.
