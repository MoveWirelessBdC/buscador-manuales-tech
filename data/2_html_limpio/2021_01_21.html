Release Version: 21.01.21__stable__0.34.0

Release Date: 01/21/2021

New Features

  • We have introduced the new License option, which allows your Clients to request additional Data Transfer for their Sublicences. Such a request is then sent out to their Representatives for acceptance.
  • You can now suspend the desired Sublicences and by that prohibit your Clients from using them.

Updates

Feature Updates

  • We have updated the CSV file template for User Accounts which now includes Data Transfer reset specifications.

System Updates

  • We have added the following permissions to the Platform:
Permission Name Description
licenceDataPackageUse Allows the user to use predefined Data Transfer Packages when creating and topping up Sublicences
suspendLicence Allows the user to suspend and resume a Sublicence
licenceDataRequestResolve Allows the user to accept and reject requests

Resolved Issues

Feature Fixes

  • We have improved performance of the Users Now table in the Users Dashboard which now loads notably faster.
  • We have made the necessary changes to the Sublicence editor to improve the validation of Data Transfer and AP capacity when deriving a Sublicence from a Licence Package.

System Fixes

  • We experienced some Location statistics errors, resulting in the incorrect aggregation of statistic results; it has been fixed, and the numbers display as expected.
  • As part of the system cleanup, we have removed the old dwell time processor used for localised devices. This should not affect your current Location statistics, and improve the system efficiency for installations with a large number of Venues instead.
