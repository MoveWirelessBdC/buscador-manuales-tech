Previewing User Agreement Versions

The changes made to the User Agreement documents are saved in the Platform as Versions. This feature allows you to view the changes and details, such as the time of changes and their author.

To access Versions, go to the User Enrollment → User Agreements section and select the Versions option.

Now, navigate the upper tabs to preview changes made to the Service Documents, Marketing Categories, and Communication Channels.

You can preview the latest version of a User Agreement, and display its history of changes. To access these options, click the More option in the top right corner of the desired User Agreement**, and select the desired one from the dropdown menu.

By selecting the Show Changes History option, you can preview the details of the changes, such as publish and removal dates and the user who has modified it.
