Creating and Managing Tokens

Tokens are vouchers which contain codes that enable users to gain internet access. Such access is limited to users who have been provided with Token codes. This makes Tokens a useful solution to grant selective network access, for instance, during conferences or fairs.

Creating a Token Group

To create a set of Tokens, you must create a Token Group in which Token codes are contained. It allows you to specify the number of Tokens which you would like to issue and set up network limits.

  1. Go to the User Enrollment → Access Methods section and click the Tokens option.

  2. In the bottom right corner of the page, click the + button to start creating a new Token group.

  3. Now, in the Settings step:

    • In the Name field, type the name of the Token Group;

    • Into the Number of Tokens In Group field, enter the number of Tokens that you would like to issue.

    Then, click Next in the upper right corner to go further.

  4. In the Access Limits step, you can specify the network and period in which users can access your WiFi via Tokens.

    The No Limit option in the Network Limit section enables Token holders to access any network that you provide. The No Validity Period option in the Token Validity Period section allows them to access your WiFi regardless of the time.

    To designate a network which Token holders can access, choose the Select Network option in the Network Limit section. Then, click the Select Network button and select one of your preference.

    Note: You may choose only from networks which are already added to the platform.

    To specify the validity period, choose the Specified option in the Tokens Validity Period section. Then, select the desired date from the time picker.

    After you have finished providing the access details, click Next in the top right corner to proceed to the next step.

  5. In the Network Parameters step, you can specify your WiFi’s limits. These will apply to each connection established via the Tokens. You can limit the connection time, data usage and network speed.

    To do this, turn the switch of the preferred section ON, and provide the details. Then, click Next in the top right corner to move further.

  6. In the Summary step, you can review all of the Token Group details. To change any settings, click the Back Arrow in the top left corner, and move back to the step which you would like to amend.

    To finish creating the Token Group and generate Tokens, click the Generate button in the top right corner of the page.

  7. The Token Group is now created as your Own Group. You can preview its Total Use and check the Group's status.

    Token Groups have three statuses which you may notice depending on Tokens usage. These are: Active, Used, and Expired:

    • The Active status which means that the Token Group is active, and its Token codes can be used. Active Token Groups are highlighted blue;

    • The Used status which means that all Token codes in the Group have been used. Therefore it is no longer active;

    • The Expired status which means that the Token codes might not have been fully used, but the Group's validity period has ended. Hence the Tokens can no longer be used.

    Note: If you are a sub-organisation, you may inherit Token Groups from your parent organisation. They will be visible in the Inherited section.

Managing a Token Group

You can manage a Token Group by previewing its summary, showing Tokens list, and removing the Group.

Previewing a Token Group Summary

To preview the Token Group Summary, click the More option on the desired Token Group, and select the Preview Token Group Summary option.

Showing Tokens List

You can preview the list of Token codes which has been generated for the specific Token Group. To do this, click the Show Tokens List option in the dropdown menu.

In the Tokens List table, you can see the Token usage details:

  • The Date of Use which indicates when the Token code was used;

  • The Device on which the Token code has been used;

  • The Network which has been accessed via the Token code;

  • The Page Flow which the user went through to log in to the network;

  • The Portal through which the user gained internet access;

  • The Token Status which indicates the Token's state of usage.

There are two statuses which Tokens can have:

  • The Active status which means that the Token has not yet been used;

  • The Inactive status which means that the Token has been used, and therefore is no longer active.

Removing a Token Group

To remove a Token Group, click the More option on the Group which you would like to remove, and select the Remove option from the dropdown menu.
