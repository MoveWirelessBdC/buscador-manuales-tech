Release Version: 21.07.23__stable__0.47.0

Release Date: 07/23/2021

New Features

  • We have added a map showing area ranking.
  • We have added an area selection in the Location Statistics displaying the details of the area, the possibility of locating the selected area and either calculating or displaying statistics for the selected area.
  • We have added a validation of VLAN + SSID uniqueness for Benu Controllers.

Updates

  • We have improved the appearance of the List of Users Accounts table.

Feature Updates

  • We have added access to the Questionnaire results new permissions and anonymization of personal data.

System Updates

  • We have added the following permission to the Platform:
Permission Name Description
seeQuestionnaireResults Allows the user to display the results of questionnaires

Resolved Issues

GUI Fixes

  • We have fixed a problem with sessions not being terminated correctly by the radius disconnect message. Now, logged out users are not included in the Users Now table.
  • Unauthorized users should no longer see an "Authorization missing from the request" error when trying to access the User Guide. Instead, they will be shown the login page and redirected back to the guide upon successful login.
