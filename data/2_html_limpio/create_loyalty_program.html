Creating a Loyalty Program

The Loyalty Programs feature enables you to launch marketing campaigns that allow users to collect stamps and receive token codes which they can redeem for rewards. It is a useful strategy to encourage users to shop or use your services regularly.

  1. Go to the User Enrollment > User Journey section, and select the Loyalty Programs tile.

  2. In the Loyalty Programs Manager, click the + button located at the bottom right corner to create a new Loyalty Program.

  3. Firstly, type the name of the Program in the Name field. Then, click Next in the top right corner to proceed to the next step.

  4. In the following step, determine the terms of the Program:

    • Select the number of stamps that users must collect to receive rewards by moving the Number of Stamps slider right or left
    • To set the minimum time which must pass before obtaining another stamp, turn the Min. Time Between Stamp Collection switch ON, and specify the period in the input and dropdown fields
    • To determine how much time users have to collect all the stamps, turn the Max. Stamps Collection Period switch ON, and define the period in the input and dropdown fields
    • To determine how much time users have to redeem their token codes for rewards, select the Token Validity Upon Receipt switch ON, and specify the period in the input and dropdown fields
    • From the Number of Token Codes toggle button, select how many times users can redeem their token codes for rewards: the Unlimited option enables the unlimited number of redeems, and the Specified option allows you to determine it.

    After you have finished determining the Loyalty Program's setup, click Next in the top right corner to continue to the last step.

  5. Finally, in the Summary, you can review the Loyalty Program's setup. Then, click Save in the top right corner to finish creating the Loyalty Program.

  6. The Loyalty Program is now created. To launch it, you must add it to the desired Portal. To learn how to do this, read the Adding a Loyalty Program to a Portal chapter.
