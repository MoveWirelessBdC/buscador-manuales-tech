Release Version: 20.03.06__stable__0.11.0

Release Date: 03/06/2020

New Features

  • We have added the following permissions:
Permission Name Description
viewOrganizationId Allows a user to view the Organisation ID in the Organisation details
ruckusCustomSip Allows a user to set up and preview the Ruckus Custom SIP
ruckusCustomSipMap Allows a user to set up and preview the Ruckus Custom SIP Map
idleTimeoutNetworkParameter } Allows a user to set up the Idle Timeout in the Network Parameters
userAgreementsMenu Allows a user to display the new User Agreements menu

Updates

  • We have updated the Roles and Permissions feature with the search option which allows you to quickly search through permissions.
  • We have added the Organisation ID to the Organisation details.
  • We have implemented the Idle Timeout option in the Network Parameters which allows you to specify the maximum time of inactivity after which a user is disconnected from the network.
  • The RADIUS Parameters Properties have been updated; they are now visually consistent with the rest of the platform, and allow you to define RADIUS’ Network Parameters and attributes.
  • We have removed the permissions which provided access to the old Organisation views:
Permission Name Description
organizationManagement replaced with structureReadOrganization
organizationUsers replaced with structureOrganizationUsers
organizationDevices replaced with structureReadDevices and structureWriteDevices
