Release Version: 20.09.03__stable__0.24.0

Release Date: 09/03/2020

Updates

  • We have improved the integration with the OpenMarket messaging platform. As a result, from now on, you can set up the Sender caption for text messages.
  • We have updated the WifiUserProfile model so it contains historical WiFiUserProfile's IDs, which have been replaced during the merging process.

Bug Fixes

  • Time zones, such as Astrakhan and Volgograd, that showed incorrect time have been updated adequately.
  • The Token codes used to log in to the network are now displayed in Raw Data Session table for each tokens system version, i.e. Single Token API, new Tokens Panel, old Tokens Panel.
