Creating, Editing and Removing a User

The Users section allows you to add additional platform users to manage your organisation. You can grant them different levels of access and limit it to a specific level or a sub-organisation, according to your preferences.

There is no limit to the number of users which you may add to an organisation.

Creating a User

  1. Go to the Portal Management → Structure section and select Users from the navigation bar.

    Note: When creating a user for a particular organisation, you should note that they will be given access to all of the organisation's subsidiaries. In case you would like to limit their access to a distinct sub-organisation, switch to it before creating a user. To learn how to switch between organisations, go to the Creating, Editing and Removing an Organisation chapter.

  2. Click + in the bottom right corner to create a user.

    ]

  3. In the Settings step of the user creator, enter the user credentials:

    • Into the Login field, type the username,
    • In the Password field, you can either enter a password or use the generated one (a password must contain at least 8 characters including an uppercase letter, a lowercase letter, a digit and a special character)
      Note: The password must be copied and passed on to the user.
    • Into the Email field, type the user’s email address (required),
    • In the Name field, enter the user’s name (optional),
    • In the Surname field, enter the user’s surname (optional),
    • In the Phone number field, enter the user’s phone number (optional).

    Then, click Next in the top right corner to proceed.

  4. The Roles and Permissions step allows you to manage the user’s access to platform features. You can choose a Role which is a defined set of permissions, or select proper permissions from the Permissions list.

    After you have finished defining the user’s access, click Next in the top right corner to proceed.

  5. In the Summary step, you can preview the user details. To confirm them, click Save in the top right corner.

Editing a User

  1. From the List of Users, select the one which you would like to edit. Then, click the More option on the right and select Edit from the dropdown menu.

  2. Modify the user credentials and click Save to confirm the changes.

Removing a User

  1. From the List of Users, select the one which you would like to delete. Then, click the More option on the right and select Remove from the dropdown menu.

    Note: If you remove a user, they will not be able to log in to the platform.
