Release Version: 22.01.05__stable__0.59.0

Release Date: 01/05/2022

Note: This release includes both the 21.12.23__stable__0.58.0 and 22.01.05__stable__0.59.0 release versions.

New Features

  • The possibility of exporting the terms of use, marketing categories and communication channels from the system has been added, as well as exporting Loyalty Programs, Payment Plans and Portals with the appropriate permission.
  • We have added the possibility to import forms with the appropriate permission.
  • We have added the ability to send payment confirmation emails for the Coral Commerce gateway.
  • We have added two new columns, Transaction ID and Payment method, to Statistics > Raw data > User sessions table. The data is displayed for logins using payment gateways
  • We have added the ability to set different background settings for desktop and mobile versions of the portal. Setting a different background is optional, by default the desktop version will use the same settings as the mobile version. This applies to existing portals as well.
  • When adding, removing, stopping or renewing sublicenses - the status of the organization and its subsidiaries is immediately updated.
  • Three new endpoints have been added to the ** REST API, returning the same data as in the charts in the location statistics**:
    • Reporting > Location > Venue > Passerby and Visitors
    • Reporting > Location > Venue > New & Returning Visitors
    • Reporting > Location > Venue > Dwell-time distribution of Visitors
  • We have added endpoint to the REST API to check device state - this corresponds to the data from the Location Management > Management > Devices State view.

Updates

  • We have optimized anonymisation and parameter logging performance when handling the request as part of Captive Portal handling.
  • We have implemented status checking for WAG Access Point (Cambium) which also obtains the IP address and serial number of the device.
  • For Roles in Portal Management > Licences and roles > User roles and Users in Portal Management > Structure > Users, when creating and editing, it is no longer required to select at least one permission.

Feature Updates

  • Extreme Network devices have now been integrated into the Platform which use the same mechanics as Aerohive devices.

System Updates

  • We have added the following permissions to the Platform:

Resolved Issues

GUI Fixes

  • We have fixed the visibility of two buttons, remove selected and import, when managing devices in the organization structure.

System Fixes

  • The Nigerian Naira has now the correct currency breaks.
