Release Version: 25.05.23__stable__0.147.0

Release Date: 23/05/2025

Updates

Feature Updates

  • We have added support for Disconnect Message (CoA DM) in the EnGenius Cloud REST API integration.

GUI Updates

  • For devices that support CoA, we have added a switch in the editor that makes the IP address field - used for sending CoA requests - mandatory.

System Updates

  • We have improved Captive Portal handling on certain access points to cover rare cases involving incorrectly encoded parameters.
  • We have enhanced the platform’s ecosystem by applying numerous updates that boost performance, strengthen security, and improve maintainability and stability across components.

Resolved Issues

GUI Fixes

  • We have fixed an issue that prevented the Domain customisation editor from updating under specific conditions.
  • We have added proper URL validation for the "endpoint" notification type in the Geofencing, Panic Button, and Density Alerting editors.
  • We have fixed an issue where age groups with no data were not displayed in age charts.
