Managing a Condition Node

You can manage Condition Nodes by editing and removing them, and previewing their settings.

Editing a Condition Node

To edit the Condition Node settings, click the More option on the desired Condition Node and select Edit Condition from the menu. Then, select the appropriate Condition in the Condition Editor, and make the desired changes.

To learn more about setting up Conditions, read the Adding a Condition Node chapter.

Previewing Time Interval

For Conditions which use the Time Interval in their settings, you can preview their setup in the Page Flow. To do this, click the More option on the desired Condition Node and select Preview Time Interval from the menu.

Removing a Condition Node

To remove a Condition Node from the Page Flow, click the More option on the desired Portal Node and select Remove Node from the menu.

Note: If you remove a node, some nodes can be left disconnected from the Page Flow. You should note that it is necessary to connect all nodes before saving and using a Page Flow. A Page Flow with disconnected nodes can only be saved as a Draft.

To learn more about removing nodes, read the Connecting, Disconnecting and Removing Nodes chapter.
