Continuing and Closing the Page Flow Path

Continuing the Page Flow Path

  1. In the upper right corner of the node which you want to extend, click the More option. Then, from the dropdown list select Continue Path.

  2. Click the More option in the node and select the Add Node option from the dropdown menu. Then, from the sub-menu choose the kind of a node which you would like to add to the Page Flow.

Closing the Page Flow Path

  1. On the right side of the node, click More. Then, from the dropdown list, select Close Path.
