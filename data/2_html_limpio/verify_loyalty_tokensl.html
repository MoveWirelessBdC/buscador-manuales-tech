Verifying Loyalty Program Token Codes

When a user collects the required number of stamps, they receive a token code which they can redeem for a reward. The Platform allows you to verify this token code to ensure its validity.

  1. To do this, click on the More option on the desired Loyalty Program and select Verify Token Code from the dropdown menu.

  2. Now, enter the token code provided by the user into the Token Code field, and click Verify to confirm its validity.

    The Loyalty Program token code may be invalid due to several reasons:
    - It may be incorrect
    - It might have been used too many times
    - Its validity has expired.
