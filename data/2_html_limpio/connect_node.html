Connecting, Disconnecting, and Removing Nodes

Connecting Nodes

  1. In the Page Flow Editor, click the More option in the specific node which you wish to connect with another.

  2. From the dropdown menu, select the Connect Nodes option.

  3. Hover your mouse over the node which you would like to connect with the initial node. A blue line will connect the two nodes. Click the second node to confirm the connection.

Disconnecting Nodes

  1. Now, click the small, blue circle in the beginning node. From the dropdown menu, select the Disconnect Nodes option.

Removing a Node

Note: If you remove a node, some nodes can be left disconnected from the Page Flow. Note that it is necessary to connect all nodes before saving and using a Page Flow. A Page Flow with disconnected nodes can only be saved as a Draft.

  1. In the top right corner of the node which you would like to remove, click the More option. Then, from the dropdown list, select Remove Node.
