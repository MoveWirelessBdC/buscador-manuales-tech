Release Version: 21.04.15__stable__0.40.0

Release Date: 04/15/2021

New Features

  • We have implemented new columns to the Sublicence Distribution table in the Licence Package details window to provide you with even more complete reporting on the Package’s usage.

  • We have also added new columns to the Sublicence Top-Ups table so that it provides you with more information on each top-up that has been made for a Sublicence.

  • We have changed how data transfer requests are organised for Representatives. From now on, you can find all incoming requests in the Pending tab. Once you accept or reject one, it is then moved to the Resolved tab where you can display the history of all accepted and rejected requests.

Updates

GUI Updates

  • In the Permission Tree, we have improved the list of permissions for the Location Management section so they better reflect its structure.

  • We have updated access to the User Journey and Access Methods features which are now managed with user permissions. To do this, we have added new permissions to the Platform which you can find in the System Updates section below. Please ensure they are accordingly updated for all your users.

System Updates

  • We have optimized the way Kafka data is processed that decreased the communication overload between nodes. This includes data processing for dashboards and loading yesterday live records to compare them with today ones.

  • We have improved our data security by anonymising all social media logs.

  • We have re-used the current mechanism of blocking logins and IP addresses of users who would exceed the allowed number of incorrect login attempts on the Platform to block the API. The configuration of this mechanism is built on the same properties and is common for portal-API operations.

  • We have added and modified the following user permissions:

Resolved Issues

System Fixes

  • For Licences that had enabled Licence Plans but were suspended, user permissions based on Plans would not work correctly. This would make certain Platform views inaccessible and - in some cases - resulted in a lack of access to the entire Platform. We have fixed it, and it should not cause any more problems.
