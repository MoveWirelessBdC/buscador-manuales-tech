Release Version: 21.02.18__stable__0.36.0

Release Date: 02/18/2021

New Features

  • We have introduced a new type of email notifications in the Email Customisation feature - User Accounts. It allows you to send your WiFi users automatic email notifications when they have reached a specified data level.
    Note: This type of notifications works only for User Accounts with specified email addresses. You can enable them for each user in the User Account editor and manage their settings from the List of User Accounts table.

  • We have also integrated a new SMS gateway with our system - Orange Contact Everyone.

Updates

Feature Updates

  • Due to the changes to the Instagram Data Policy, we have had to disable the Portal editor's Instagram login component. As for the moment, we suggest using the Facebook login component instead

  • We have made some improvements to the List of User Accounts table and added a new Creation Date column. Also, from now on, newly created User Accounts appear at the top of the list.

  • We have added a new column to the User Sessions table in the Raw Data statistics - Username. It shows the username or email address of the user who logged in to your WiFi with given User Account credentials.

  • You can now use tags to customise messages in Message Nodes in the Page Flow.

  • Also, Message Nodes now allow you to send email and SMS messages to users who logged in to your WiFi but did not confirm their email addresses or phone numbers.
    Note: To enable this option, you should change the default value of the requireConfirmedEmailInMessageNode or requireConfirmedPhoneNumberInMessageNode properties to false.

Resolved Issues

GUI Fixes

  • We have fixed the scrolling panel in the Organisation Tree, which now moves you automatically to the currently selected Organisation.

System Fixes

  • Some temporary session data would not be cleared for users who did not gain internet access, impeding logging in again to WiFi for some of them. This has been fixed and should cause no problems now.

  • There was an issue where users would not get redirected to the portal after using their token data. This has been fixed and works as expected.
