Release Version: 22.01.21__stable__0.60.0

Release Date: 01/21/2022

New Features

  • We have added the option to export Portals in the tile menu. You may also export multiple selected portals at once. The exported file will be in a .zip format.
  • In Portal editor, we have added the possibility of configuring a single column view for the desktop version in which you may also adjust the width.

Updates

  • When navigating from Network manager to an attached flow, the current organisation gets remembered and is restored when going back.
  • Users who have never logged into the platform are blocked after 24 hours of creating the account. The default time frame is 24 hours but can be specified by using the property userFirstLoginHoursSinceUserCreationToBlock property.
  • Deep-copy capability for portal / flow copy to draft has been implemented.

GUI Updates

  • We have changed the appearance of the tile for creating/editing settings/copying flows, portals, networks and forms.
  • The General Appearance section in the Portal editor is now available not only in the lower right hand corner but also in the Select category menu.
