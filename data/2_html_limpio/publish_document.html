Publishing a User Agreement Document and Adding It to a Portal

All User Agreement documents are initially created as Drafts. Before they can be added to the Portal, they must be published.

Publishing a User Agreement Document

Below, look at an example of publishing a Service Document.

Note: This procedure is also used for all other User Agreements.

  1. Go to the User Enrollment → User Agreements → Service Documents section and select the Service Document which you would like to publish.

  2. In the selected Service Document panel, click the More option and select Publish from the dropdown menu. Then, confirm publishing the Document in the pop-up box.

  3. The Document’s status has now been changed to Published.

Adding a User Agreement Document to the Portal

  1. Enter the Portal Editor of the selected Portal where you would like to place the Service Document. Then, select the Basics option from the menu on the left. Now, drag the Service Document tile to the Portal workspace and drop it inside.

  2. Enter the Portal Editor of the selected Portal in which you would like to place the document. Then, select the Basics option from the menu on the left. Now, drag the Service Document tile to the Portal workspace and drop it inside.

  3. In the menu on the left, select the needed document from the dropdown list.

  4. The document now appears as the Service Document placeholder.

  5. Save the Portal to confirm changes.
