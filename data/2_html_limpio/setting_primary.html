Setting Primary configuration

  1. In order to set the Primary configuration click on the Primary configuration tab in the Social Media manager.

  2. Find the configuration which you would like to set as Primary and click on the three dot action button and click Set own configuration.

  3. In the pop-up box select which configuration you would like to set as Primary and click Save. Your configuration is now set as Primary.

  4. When the configuration is set as Primary you may revert back to the original settings by clicking the three dot button and selecting Restore original settings.
