Release Version: 21.08.20__stable__0.49.0

Release Date: 08/20/2021

Updates

  • We have added an alert to inform that certificates used in internal communication will expire at a specific time in the future.
  • We have added the possibility to specify the domain of the controller for the Ruckus Cloud device used for CoA requests.
  • We have optimised the storage of activity logs, resulting in less RAM memory usage in the database.
  • We have added a Disconnect Message support for TP-Link Standalone and TP-Link Controller devices

Resolved Issues

System Fixes

  • We have fixed the issue with creating a new Internet Access Node which replaces the previously edited one.
  • We have fixed the issue in which the used transfer is allocated to the appropriate sub-license. Now the exceeded transfer goes to the sub-license base with the nearest expiry.
  • We have improved the anonymisation of content logging for sent messages.
