Release Version: 20.12.10__stable__0.31.0

Release Date: 12/10/2020

New Features

  • In the Licences feature, you can now top data transfers of the desired Sublicences and view their top-up history.
  • The Licences feature also contains a new Data Transfers tab where you can create and manage Data Transfer Packages.
  • You can now deny or allow certain devices to access your WiFi by designating the desired MAC Addresses in the new Confirmed Devices Condition.
    Note that some of the current devices use randomised MAC addresses. This means they may change MAC addresses per Network that they connect with, which may impact the effectiveness of this Condition.

Updates

Feature Updates

  • The Call Authentication component in the Portal editor now allows you to set up both the phone number to be displayed on a Portal, which users would dial, and the number set up in the gateway to which users would then be redirected.
  • We have prepared new notifications for data transfers. You can customise them according to your preferences in the Sending Centre > Email Customisation section.

System Updates

  • From now on, when a data transfer assigned to an Organisation is used up, users from this Organisation and all of its Sub-Organisations will be unable to log in to your WiFi.

  • We have added the following permissions to the Platform:

Permission Name Description
deviceIdInListCondition Allows the user to add the Confirmed Devices Condition to Page Flows
licenceDataPackageRead Allows the user to access the Data Transfer tab in the Licences section
licenceDataPackageWrite Allows the user to create and edit Data Transfer Packages
licenceDataPackageDelete Allows the user to delete Data Transfer Packages

Resolved Issues

System Fixes

  • The Call Authentication feature had a bug which would be triggered when users closed their browsers before they dialled the number displayed on a Portal. We made some necessary changes so that they would be immediately redirected to the next node in the Page Flow after establishing a connection with the number.
