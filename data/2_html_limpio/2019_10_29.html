Release Version: 19.10.29-0.3.0

Release Date: 10/29/2019

New Features

  • In the Portal Editor, we have implemented the Image Submit component. This feature allows you to place a clickable image into the Portal and use it as the Submit Button to redirect the users to the desired stage of the login path.
  • We have introduced the Customise Landing Page feature which enables customisation of the landing pages inherited from parent organisations. This feature can be accessed from the Page Flow’s context menu in the Page Flow Manager.
  • Additionally, we have added 2 charts to the WiFi Users statistics; the Login Methods chart provides you with the percentage breakdown of the login methods which users selected to log in to the WiFi, and the Total Sessions Duration chart gives you insight into the total duration of all user sessions.

Updates

  • We have updated the User Accounts section which now allows you to create and edit user accounts easily, and assign them with specific roles and permissions.
  • From now on, the users can also manage the Communication Channels in their WiFi user accounts.

Bug Fixes

  • We have improved the responsiveness in the Statistics section; the statistic tables now adapt their size and location to the browser resolution.
  • The issue of searching for user logins with special characters in the Raw Data statistics has been resolved.
  • From now on, you can also change the background colour of all the Portal components at the same time.
