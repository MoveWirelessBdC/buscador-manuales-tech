Importing and Exporting Devices

The Import and Export options allow you to save time by uploading and downloading devices from and to a CSV file.

Importing Devices

To import devices, you must first prepare a CSV file in a specific format, and then upload it to the platform. Such CSV file can be downloaded for a given device type, or contain various types of APs.

  1. In the List of Devices panel, click the More option next to the Search field, and select Import from the dropdown list.

  2. In the pop-up box, you should specify the kind of device for which you would like to generate a sample CSV file. Then, click the Download Sample CSV File button.

  3. Open the downloaded file and fill it in accordingly; to prepare it correctly, make sure that all device IDs are unique. Then, click the Upload CSV File button, and select the file to upload. To finish the importing process, click the Import Devices button.

  4. The devices are now uploaded to the platform.

Exporting Devices

In the List of Devices panel, click the More option next to the Search field, and select Export from the dropdown list. The file is downloaded automatically.
