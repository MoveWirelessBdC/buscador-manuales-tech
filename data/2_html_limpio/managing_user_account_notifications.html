Managing User Account Notifications

You can notify your WiFi users when they reached a certain level of data usage by sending them email or SMS notifications. You can set it up for your organisation in the User Accounts tab, and manage the notification settings in the Notification tab.

Setting Up Notifications For a User Account

To receive notifications, a User Account must have a specified Contact Email in their Account settings:

  • For the Username and Phone Number type of User Account, it is a separate Contact Email field in the User Account editor’s first step.- For the Email type of User Account, it is a Contact Email field in the User Account editor’s first step.
  • For the Email type of User Account, it is a Contact Email field in the User Account editor’s first step.

  • Next, in the Data Transfer step, you can enable the Notifications or leave this option disabled and turn it ON later from the List of User Accounts table.

Creating Notifications for an Organisation

In order to create notifications, go to the Notifications tab in User Enrollment > Access methods > User accounts > Notifications. Next click on the + icon to create a new notification.

  • In the Notification Settings section you can name your notification as well as choose the form of sending, either by SMS, Email, or both.

  • In the Remaining value notification field you may set the value of the notification and choose either percentages or data amount.

  • After setting up the notifications click the Save button. Now your notification is ready.

Changing Notification Settings

To modify the data usage threshold, go to the List of notification settings table and follow the below steps:

  • Select the desired notification from the List of notification settings table and click the three-dot More option on the right side. Then, select Edit from the dropdown list.

  • Now, in the pop-up box, you can modify the parameters of the chosen notification.

Deleting Notifications

To delete a notification, go to the List of notification settings table and follow the below steps:

  • Select the desired notification from the List of notification settings table and click the three-dot More option on the right side. Then, select Delete from the dropdown list.

  • Confirm the deletion of the notification by clicking the delete button. Now, the notification has been deleted.

    Note

    If only one notification remains you will not be able to delete it.
