Release Version: 22.08.19__stable__0.75.0

Release Date: 08/19/2022

New Features

  • We have added the possibility to download survey results via the REST API. Two new endpoints have also been added:
    • GET/forms/{organizationId}formsIds to get the names and IDs of all questionnaires from the specified organisation.
    • GET/forms/{organizationId} to get the answers set for selected questionnaire and interval (and optionally for a specific organisation, flow, portal). Response is limited to 100000 entries.

Updates

  • We have made the appearance of the organisation card consistent with the current editor.

System Updates

  • We have added the following permission to the Platform:
Permission Name Description
readQuestionnaireResults Allows the user to download survey results via Rest API

Resolved Issues

System Fixes

  • We have fixed the issue in Portal editor where the Use in desktop version option did not work if the desktop version was set to single column.
